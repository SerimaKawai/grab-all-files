Onde o Grab All Files é a escolha certa

  • ✓Você precisa fazer login para ver as páginas e já consegue abri-las no seu navegador.
  • ✓As páginas são montadas por JavaScript e um download simples vem vazio.
  • ✓Você quer os PDFs e arquivos do Office listados primeiro, para conferir e guardar só alguns.
  • ✓O trabalho é um conjunto limitado de páginas, ou uma longa lista de arquivos em poucas páginas.

Onde é a escolha errada

  • –Um site inteiro com milhares de páginas, copiado de uma só vez.
  • –Uma cópia que você atualiza toda semana, buscando só os arquivos que mudaram.
  • –Vídeo transmitido por streaming, e não ligado como arquivo.
  • –Páginas que você não consegue abrir no seu próprio navegador.

Por que o método importa

Grande parte da diferença na tabela vem de onde a ferramenta roda e do que ela consegue ver de lá.

Usando mais de um

Os métodos não são rivais. Uma divisão comum: use um copiador de sites para computador em um site público grande e o Grab All Files na área com login do mesmo site, ou para os PDFs espalhados por algumas páginas. A lista de arquivos do Grab All Files também pode ser exportada como CSV, com a URL de cada arquivo, se você quiser passá-la a outra ferramenta.

Perguntas frequentes

O Grab All Files é um copiador de sites?

Não no sentido usual. Ele salva páginas uma de cada vez dentro do seu navegador e pode gravar a organização de pastas de um site no seu computador. Serve para um conjunto limitado de páginas. Para milhares de páginas, use um copiador de sites para computador.

Qual método funciona em um site em que preciso fazer login?

Uma ferramenta que roda dentro do seu navegador, porque ela usa o login que você já tem. O Grab All Files e as extensões que salvam uma página funcionam assim. Os copiadores para computador muitas vezes exigem uma configuração extra para isso.

Posso atualizar uma cópia salva e baixar só o que mudou?

Não com o Grab All Files. Ele tem um relatório de mudanças em Markdown que compara com a sua última coleta do mesmo site, mas salva as páginas de novo. Um copiador de sites para computador é o método feito para atualizar.

Como ele é diferente de um gerenciador de downloads?

Um gerenciador de downloads recebe uma lista de links de arquivos e os busca bem. O Grab All Files primeiro encontra os arquivos, inclusive os que uma página carrega por script, mostra-os em uma lista para conferência e também pode salvar as páginas como HTML.
