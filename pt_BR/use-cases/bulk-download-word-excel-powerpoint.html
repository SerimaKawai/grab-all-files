Baixe de uma vez todos os arquivos Word, Excel e PowerPoint de uma página.

Três categorias e as extensões de cada uma

No painel de filtros, as categorias se chamam “Documentos”, “Planilhas” e “Apresentações”. Estes são exemplos do que cada uma abrange, e não uma lista completa. Arquivos csv e tsv contam como Planilhas.

CategoriaExtensões típicasO que você costuma encontrar

Planilhasxls, xlsx, xlsm, xlsb, ods, csv, tsvTabelas de preços, tabelas de dados, modelos
Apresentaçõesppt, pptx, pptm, pps, pot, odp, keySlides de aulas, apresentações de resumo

Como fica a lista

Passo a passo

  1. 1Abra a página que tem os links para os arquivos. Se quiser arquivos de páginas a um clique de distância, defina a profundidade da varredura como “Profundidade 1” em vez de “Apenas esta página”.
  2. 2Abra o Grab All Files, use o “Baixador de arquivos” e escaneie a página.
  3. 3Reduza a lista à categoria de que precisa, ou a uma única extensão. Você também pode pesquisar por nome de arquivo ou título e ordenar por tamanho ou data.
  4. 4Percorra a lista, desmarque o que não quer e clique no botão de salvar. Escolha uma pasta nas configurações de salvamento se quiser os arquivos separados por tipo ou por site.
  5. 5No plano gratuito, clique de novo para os 10 seguintes. O Pro salva de uma vez tudo o que você marcou.

Arquivos idênticos são salvos só uma vez no caminho dos arquivos ligados. O texto dentro dos arquivos do Office não é colocado no HTML; o HTML apenas tem links para eles.

Limites que vale a pena conhecer

A lista de arquivos mostra aquilo para o que a página tem links ou que ela carrega. Arquivos que só aparecem depois de um botão, uma pesquisa ou uma etapa de login exigem que essa etapa seja feita antes, no mesmo navegador; veja o guia de login para saber como a sessão se comporta.

O Grab All Files não abre nem converte arquivos do Office. Se você quer o conteúdo de muitas planilhas em um só lugar, salve-as primeiro e depois combine ou analise com a ferramenta que preferir.

Perguntas frequentes

Dá para baixar só os arquivos Excel de uma página?

Sim. Filtre a lista por Planilhas, ou por uma única extensão como xlsx, e salve apenas esses.

Ele acha .docx e .pptx além dos antigos .doc e .ppt?

Sim. Tanto os formatos antigos quanto os novos, e os formatos OpenDocument como odt, ods e odp, são detectados.

Quantos arquivos do Office posso salvar no plano gratuito?

Em uma página com 50 formulários, o plano gratuito os salva em cinco rodadas de 10: selecione os próximos e clique em salvar de novo. O Pro salva os 50 de uma vez.

Ele salva os arquivos do Office junto com as páginas que têm links para eles?

Sim. O Juntar páginas em HTML pode salvar junto com as páginas os PDFs e arquivos do Office ligados: 10 por execução no plano gratuito, 100 no Pro.

Meus arquivos são enviados para algum lugar?

Não. Os arquivos são gravados direto do site para o seu computador.
