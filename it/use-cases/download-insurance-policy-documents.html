I documenti che di solito raccogli per un prodotto

Condizioni di polizza

Il PDF lungo con tutte le condizioni. A volte è diviso in condizioni generali e clausole speciali, ognuna in un file a sé.

Brochure

Il dépliant commerciale. Un prodotto può averne una sola, oppure una per ogni piano o garanzia aggiuntiva.

Documento informativo

La spiegazione degli aspetti importanti. Alcune compagnie pubblicano un file per ogni canale di vendita o fascia d’età.

Sintesi del contratto

La scheda riassuntiva del contratto, dove la compagnia ne pubblica una.

Avvisi di revisione

Un elenco o una pagina di modifiche con le date, pubblicati come PDF o come normali pagine web.

Moduli e guide

Moduli di denuncia sinistro, di cambio indirizzo e guide alle procedure, collegati dalla stessa pagina prodotto.

Passaggi

  1. 1Apri la pagina prodotto della compagnia, o la pagina che elenca i documenti di un prodotto. Se l’elenco dei PDF richiede prima una ricerca, esegui la ricerca e apri la pagina dei risultati.
  2. 2Apri Grab All Files e usa «Downloader di file». Scansiona la pagina. Lascia «Solo questa pagina» se tutti i file sono in quella pagina, oppure scegli «Profondità 1» se i PDF sono nelle pagine collegate da essa.
  3. 3Nell’elenco, restringi per tipo ai PDF e controlla titoli e dimensioni. Togli quelli che non servono, come i moduli di altri prodotti.
  4. 4Imposta il nome file sul titolo del PDF (il pulsante recupera i titoli dei PDF selezionati) e scegli come ordinare le cartelle. Salva i file selezionati.
  5. 5Premi il pulsante del CSV con le informazioni sui file. Aprilo in un foglio di calcolo e aggiungi colonne tue per edizione e data di revisione.

Confrontare le revisioni

Il modo più semplice per confrontare due edizioni è tenere entrambi i PDF nella stessa cartella del prodotto, con l’edizione o la data nel nome, e aprirli affiancati. La colonna «Modificato» nel CSV con le informazioni sui file è la data che il server indica per il file. Non è la data di revisione stampata dalla compagnia, quindi non usarla come tale.

Se la compagnia pubblica gli avvisi di revisione come normale pagina web, puoi salvare quella pagina con «Unisci pagine in HTML» a ogni visita. Il rapporto delle modifiche confronta poi l’ultima raccolta dello stesso sito con la precedente completata, per URL, titolo e testo. Confronta pagine web, non l’interno dei PDF.

FAQ

Posso scaricare condizioni di polizza e brochure da molte pagine prodotto in una volta?

Scansioni una pagina alla volta, oppure segui i link da una pagina iniziale con «Profondità 1» fino a «Profondità 5». L’elenco mostra ogni PDF trovato e scegli quali salvare. Nella versione gratuita un salvataggio è limitato a 10 file selezionati; Pro non ha limiti per salvataggio.

Mi dice di quale edizione delle condizioni è un PDF?

No. Il CSV con le informazioni sui file contiene nome file, titolo, dimensione, la data che il server indica per il file e la pagina in cui è stato trovato. L’edizione e la data di revisione sono cose che leggi nel documento e annoti.

Si accorge da solo quando una compagnia rivede le condizioni?

Non da solo. Riapri tu la pagina degli avvisi o la pagina prodotto e salvi ciò che è cambiato. Per le normali pagine web, il rapporto delle modifiche confronta l’ultima raccolta con la precedente dello stesso sito.

Nomina i file per prodotto?

Può usare il titolo del PDF come nome file e ordinare le cartelle per tipo o per sito. Un nome di prodotto che non è nel titolo o nel nome del sito lo aggiungi tu, rinominando dopo o nel tuo foglio.

Qualcosa sulle polizze viene inviato ai vostri server?

No. I file vanno dal sito della compagnia al tuo computer e il lavoro avviene nel browser. Solo il controllo della licenza e le statistiche d’uso facoltative, se le attivi, arrivano allo sviluppatore.
