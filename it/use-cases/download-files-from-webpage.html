Schermata reale dell’estensione — File da una pagina

Ideale per

  • ✓Pagine con molti link a documenti, contenuti multimediali o archivi.
  • ✓Pagine in cui i file compaiono tramite JavaScript, visualizzatori o richieste in background.
  • ✓Verifiche che richiedono un CSV con URL, dimensioni e pagine di origine.
  • ✓Raccolte occasionali per cui configurare un crawler sarebbe eccessivo.

Flusso

  1. 1Apri la pagina in Chrome, Edge o Firefox e fai clic sull’icona di Grab All Files nella barra degli strumenti. L’elenco dei file riguarda la pagina aperta.
  2. 2Fai clic su «Scansiona». Per includere le pagine collegate, aumenta prima la «Profondità» («Solo questa pagina» controlla solo questa); i link vengono seguiti solo all’interno della cartella della pagina di partenza.
  3. 3Restringi l’elenco con i tipi di file, la casella di ricerca per nomi e titoli e «Dettagli» (dimensione minima, «Salva come»). Seleziona i file che ti servono.
  4. 4Fai clic su «Salva i selezionati». ZIP, «Unisci PDF», «Organizza» ed «Esporta info file in CSV» si trovano in «Altre azioni». La versione gratuita salva fino a 10 file per download.
  5. 5Per un elenco lungo, seleziona i file successivi e fai di nuovo clic su «Salva i selezionati». Le righe non riuscite mostrano il motivo: correggi l’accesso e riprova.

FAQ

Quali tipi sono supportati?

PDF, Office, immagini, ZIP, CSV e altre risposte scaricabili accessibili al browser. Rileva anche set di archivi divisi / multivolume come .001, .r00 e .z01.

Posso scegliere solo alcuni file?

Sì. Filtra per tipo, nome, titolo o dimensione, ordina per qualsiasi colonna e seleziona solo le righe che ti servono. Non viene salvato nulla finché non premi un pulsante di salvataggio.

La versione gratuita ha un limite?

La versione gratuita salva fino a 10 file selezionati per download e lo stesso limite vale per ZIP, «Unisci PDF» ed esportazione CSV. Per continuare, seleziona i file successivi e premi di nuovo il pulsante: non viene bloccato nulla. Pro ($19.99, una tantum, fino a 3 dispositivi) elimina il limite per download.

Non ha trovato nulla, o meno file del previsto. Cosa posso fare?

Per le pagine che caricano altro contenuto mentre scorri, apri «Opzioni di scansione», attiva «Scorri e carica tutto prima della scansione» e ripeti la scansione. Se i file sono in pagine collegate, aumenta la «Profondità». Sospendi i blocchi pubblicitari per quel sito. Se i download vengono avviati dal JavaScript della pagina, usa «Cattura attiva» quando viene proposta.

La pagina richiede l’accesso. Cosa devo fare?

Accedi prima al sito nello stesso browser, poi avvia la scansione. Grab All Files usa la sessione che hai già; con profondità 1 o superiore apre le pagine collegate con lo stesso accesso. Non accede mai al posto tuo né aggira le restrizioni. Le righe con «Accesso richiesto» vanno ritentate dopo aver effettuato di nuovo l’accesso.

Funziona su pagine HTTP?

Sì. Scansiona HTTP e HTTPS che il browser può aprire.
