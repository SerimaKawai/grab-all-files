Ideale per

  • ✓Riconoscere più facilmente i PDF di un manuale o di un elenco di documenti pubblici.
  • ✓Separare per formato un insieme misto di PDF, fogli di calcolo e altri file.

Flusso

  1. 1Scansiona la pagina che elenca i PDF, filtra i risultati per PDF e seleziona i file da salvare.
  2. 2Controlla i titoli. «Recupera titoli dei PDF selezionati» legge il titolo dal PDF stesso. Fai doppio clic su un titolo, premi F2 o usa la matita («Modifica titolo») per cambiarlo; «Reimposta titoli» annulla le modifiche.
  3. 3Apri «Dettagli» e scegli «Salva come»: «Automatico (titolo se utilizzabile)», «Titolo» o «Nome file originale». Per dividere in cartelle, apri «Altre azioni» e in «Organizza» scegli «Per tipo», «Per dominio» o «Nessuna cartella».
  4. 4Fai clic su «Salva i selezionati» o crea uno ZIP (gratis: fino a 10 file per download). Controlla nomi, estensioni e cartelle; in Firefox i file vanno in Downloads/GrabAllFiles.

FAQ

Trova sempre il vero titolo del PDF?

No. Metadati o intestazioni disponibili possono mancare o essere generici. Controlla il titolo recuperato; la modalità automatica può usare il nome file originale quando non trova un titolo utile.

Il raggruppamento per tipo capisce l’argomento dei documenti?

No. Raggruppa per tipo di file o dominio di origine, non per un argomento dedotto. Un insieme di soli PDF resta un unico formato.

Posso scegliere qualsiasi cartella in ogni browser?

La destinazione dipende dal browser e dalle sue impostazioni di download. I browser Chromium possono offrire la scelta della cartella; Firefox usa il percorso Downloads/GrabAllFiles. Controlla la destinazione effettiva.

Posso rinominare un insieme grande gratis?

Sì. «Salva come», la modifica dei titoli e «Organizza» funzionano nella versione gratuita, che salva fino a 10 file selezionati per download. Per continuare, seleziona i file successivi e fai di nuovo clic su «Salva i selezionati». Pro ($19.99, una tantum, fino a 3 dispositivi) elimina il limite per download.
