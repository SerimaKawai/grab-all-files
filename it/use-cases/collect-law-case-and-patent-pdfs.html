Only the PDF's title can be applied as the file name automatically (or the original name). Court, date, case number and publication number are not added for you: rename by hand, or keep them in a sheet next to the file-information CSV. Check a few titles before you rely on them.

From a result page to a tidy folder

Narrow the list before you save, then choose how the files come out.

Steps

  1. 1Run your search in the database in your browser and set the display so that the result page shows as many rows as it allows.
  2. 2With the result page open, start “Bulk File Download” and scan. If the PDF is not on the result page but on each detail page, choose “Depth 1”.
  3. 3Narrow the list to PDF. Free reads only what is on the screen, so scroll a long result list to the end before scanning. Pro can scroll and follow the list's “Next” pages for you, by default up to 100 pages per scan.
  4. 4Choose the file name “PDF title”, and a folder sort that suits the work: by type, by site, or none.
  5. 5Save the selected files. On Free, one save takes up to 10 files; select the next ones and press save again.
  6. 6Export the file-information CSV. It has the URL, file name, title and the page each file came from, which you can keep as your source list.

When to use the provider's own route instead

  • ✓Tens of thousands of documents, or a full year of decisions: look for a bulk download or an API.
  • ✓Text you need as structured data rather than PDFs: the provider's data files are better.
  • ✓Anything that must stay up to date: the extension does not watch for changes.
  • ✓Whether a text is in force or how it applies: that is for a qualified person and the original source.

Terms of use and what the file is

Public databases set their own rules about automatic access, copying and re-use. Read them before you collect in volume, and keep the load modest by saving in batches. Grab All Files does not break through logins or CAPTCHAs.

A PDF you save is a copy of what the site served on that day. Write the date you saved it next to the title in your list, and go back to the source when exact wording matters.

FAQ

Can I download all search results as PDFs?

Most of the PDFs the scan finds on the pages it reads can be saved. PDFs behind DRM or inside a browser's built-in PDF viewer cannot. On Free, one save takes 10 selected files, so a long result list goes in rounds; Pro has no limit per save and can scroll and follow “Next” pages. For very large sets, use the provider's bulk download or API.

Will the PDFs be named by title?

You can set the file name to the PDF's title. The title comes from the PDF itself, so check a few. If a PDF has no title, the file name is used.

Does it tell me whether a law or a case is current?

No. It saves files. Whether a text is in force, correct or relevant to your matter is not something it decides, and nothing on this page is legal advice.

Which databases does it support?

It is not built for one site. It finds files that a page links to or loads, so it often works on pages you can open in your browser. Some files, such as those inside DRM or built-in PDF viewers, cannot be saved, and each site has its own rules for automated access.

Can I keep a source list for citations?

Export the file-information CSV. Its Source page column shows where each PDF was found. The CSV has no column for the date you saved it, and your own identifiers such as case or publication numbers are not filled in, so add them in the sheet.
