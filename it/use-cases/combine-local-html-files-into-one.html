Schermata reale dell’estensione — File HTML locali in uno

Ideale per

  • ✓Un sito web salvato o copiato anni fa (index.html e decine di pagine) che vuoi conservare, leggere o cercare come un solo file.
  • ✓File della guida, manuali di prodotto o documentazione esportati come cartella di pagine HTML.
  • ✓Condividere un documento HTML di più pagine come un solo allegato, o stamparlo in PDF in un colpo solo.
  • ✓Passare a uno strumento di IA un intero insieme di documenti locali come pacchetto Markdown o di dati con la fonte di ogni pagina.

Flusso

  1. 1Apri Grab All Files, scegli «Unisci pagine in HTML» e cambia l’origine in «Da una cartella del computer».
  2. 2Scegli la cartella o un file ZIP, oppure trascinalo sulla pagina. I file .html, .htm e .xhtml sono elencati nell’ordine in cui il sito li collega a partire da index.html; le pagine senza link seguono, per nome.
  3. 3Controlla l’elenco: mantieni o rimuovi pagine, passa a «Ordine per nome file», limita a «Solo questa cartella» o usa «Escludi (uno per riga)». Scegli uno scopo: «Conservare il sito», «Condividere come un solo file», «Stampare o creare un PDF» o «Darlo a un’IA».
  4. 4Crea l’HTML. Controlla il rapporto: file che non è stato possibile leggere, link a pagine che hai escluso e immagini che non è stato possibile incorporare.

FAQ

Posso provarlo gratis?

Sì, con una pagina: in modalità cartella il piano Free converte un file HTML scelto per esecuzione in un HTML autonomo con le immagini locali incorporate. Unire più file HTML in uno con un indice condiviso richiede Pro ($19.99, pagamento unico).

I miei file vengono caricati da qualche parte?

No. La cartella o lo ZIP vengono letti nel tuo browser e l’HTML unito viene creato sul tuo dispositivo. Non serve alcun permesso per il sito, e le immagini online a cui le pagine fanno riferimento restano link e non vengono scaricate.

Le vecchie pagine giapponesi appariranno con caratteri illeggibili?

Le pagine senza dichiarazione di charset, o dichiarate UTF-8 ma in realtà scritte in Shift_JIS, EUC-JP o ISO-2022-JP, vengono rilevate automaticamente e lette correttamente. Se tutte le pagine hanno lo stesso <title>, l’indice usa l’intestazione di ciascuna pagina.

Che cosa succede a immagini, PDF e link tra le pagine?

Le immagini locali PNG, JPEG, GIF, WebP e AVIF vengono incorporate. I link tra le pagine unite diventano salti all’interno del file. I file collegati, come PDF, Office o ZIP, possono essere «Copia accanto all’HTML» (predefinito), «Incorpora nell’HTML» (20 MiB per file e 100 MiB in totale per impostazione predefinita) oppure «Lasciali come link».

Quali file può leggere?

File .html, .htm e .xhtml in una cartella o in uno ZIP. Le pagine con «Layout a frame» (frameset) sono escluse per impostazione predefinita, mentre le pagine dentro i frame sono incluse. I file MHT e i file della guida CHM non vengono letti direttamente; estrai prima il CHM in HTML.

In che cosa è diverso dall’unire le pagine di un sito web?

La modalità «Pagina del browser» raccoglie pagine correlate da un sito online. La modalità cartella lavora solo con file già presenti sul tuo computer, quindi è adatta a siti archiviati, manuali offline e documenti non più online.

Perché nel risultato manca una pagina o un’immagine?

Controlla il rapporto dopo aver creato l’HTML: elenca i file non leggibili, i link a pagine escluse e le immagini che non è stato possibile incorporare. Le pagine fuori dalla sottocartella scelta o in percorsi esclusi non vengono incluse, le immagini online restano link e le pagine a frame (frameset) sono saltate per impostazione predefinita, mentre le pagine dentro i frame vengono mantenute.
