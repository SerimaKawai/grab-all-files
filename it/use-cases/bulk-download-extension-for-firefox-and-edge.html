Bulk download extension for Chrome, Edge and Firefox: where to get it and what differs on Firefox.

Grab All Files runs in Chrome, in Edge (Chromium 111 or later) and in Firefox 128 or later. The core is the same in all three. On Firefox, four things work differently or are missing, and they are listed below so you can decide before installing.

What Firefox cannot do

These four differences were checked in the extension's code, version 5.8.54. This page does not claim that nothing else differs.

Chrome and EdgeFirefox
Choosing the folder to save intoYou can choose the destination folder.You cannot. Files go into a GrabAllFiles folder inside your Downloads folder, created automatically.
“Site copy in a folder”Available. It writes the pages into a folder you pick, in the same folder layout as the site.Not available. Use “Separate HTML pages (ZIP)” for a copy whose saved pages link to each other offline.
Active Capture (downloads started by JavaScript)Available. It clicks each download that a script starts and catches the file.Limited. Downloads started by JavaScript cannot be captured automatically. Files that the scan finds as direct links can still be downloaded.
How Combine pages into HTML reads a pageReads fetched pages in a hidden page of the extension.Switches to reading from the page as rendered in a tab.

Site copy or ZIP: it depends on the browser

“Combine pages into HTML” has four forms of saved file. Three are available in every browser; this one is Chrome and Edge only, and the ZIP is the usual replacement on Firefox.

Firefox is enough when

  • ✓You save files into the usual Downloads folder and do not need to pick a folder each time.
  • ✓You can take a ZIP of separate HTML pages instead of a site copy in a folder.
  • ✓The files you want are linked directly on the page, so the scan finds them without capturing a script-started download.

Chrome or Edge fits better when

  • –You want to choose the folder, for example a shared folder on a drive.
  • –You want the site's own folder layout written to disk, to browse it by clicking links.
  • –The download is started by a button that runs JavaScript, with no normal link to the file.

License and languages

One Pro license can be activated on up to 3 devices. It is a one-time purchase of US$19.99 with no subscription. The screens are available in 10 languages: English, Japanese, Spanish, French, German, Italian, Korean, Portuguese (Brazil), Simplified Chinese and Traditional Chinese.

Pages and files are processed in your browser on your computer. Only the license check, and usage statistics if you turn them on, reach the developer's server.

FAQ

Does Grab All Files work in Firefox?

Yes, in Firefox 128 or later. Four things differ: you cannot choose the save folder, “Site copy in a folder” is not available, downloads started by JavaScript cannot be captured automatically, and Combine pages into HTML reads pages from a rendered tab.

Where does it save files in Firefox?

In a GrabAllFiles folder inside your Downloads folder. Firefox does not let you pick the destination folder in this extension.

Which Edge versions are supported?

Edge on Chromium 111 or later, installed from Microsoft Edge Add-ons. Chrome is supported on the same Chromium version.

How many devices can one license be used on?

Up to 3 devices. It is a one-time purchase of US$19.99, with no subscription.
