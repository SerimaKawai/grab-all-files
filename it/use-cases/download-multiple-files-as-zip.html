Passaggi

  1. 1Apri la pagina e scansionala con il «Downloader di file».
  2. 2Filtra l’elenco e spunta i file che vuoi. Guarda le dimensioni: sommale se sei vicino a 200 MB.
  3. 3Premi «ZIP». Conferma se chiede della dimensione.
  4. 4Apri lo ZIP nella cartella dei download. Versione gratuita: per altri file, seleziona i successivi e premi di nuovo ZIP.

Lo ZIP è una buona scelta quando

  • ✓Vuoi inviare o archiviare un insieme come un unico file.
  • ✓L’insieme è di qualche decina di file, ben sotto i 200 MB.
  • ✓Vuoi un unico file ordinato invece di tanti download sparsi.

Salva invece in una cartella quando

  • –Il totale è vicino o superiore a 256 MB: video, disegni grandi, libri scansionati.
  • –Vuoi i file ordinati per tipo o per sito, in cartelle separate.
  • –Vuoi aprire o rinominare subito i singoli file.

ZIP è una delle varie uscite

La stessa selezione può anche essere salvata come file separati, unita (PDF) o esportata come elenco di file (CSV). Tutto viene elaborato nel tuo browser.

Da non confondere con «Pagine HTML separate (ZIP)»

«Pagine HTML separate (ZIP)» appartiene a «Unisci pagine in HTML», l’altro strumento. Conserva le pagine web salvate come un file HTML per pagina, con un index.html, dentro uno ZIP. Il pulsante ZIP del Downloader di file impacchetta file come PDF e documenti Office così come sono. Le due funzioni sono distinte, e i limiti di questa pagina sono i numeri del pulsante ZIP.

FAQ

Come scarico molti file di una pagina in un unico ZIP?

Scansiona la pagina con il Downloader di file, spunta i file e premi ZIP. Ottieni un unico archivio.

Quanti file possono entrare in un ZIP gratis?

10. Un insieme di 30 report diventa tre file ZIP da 10: seleziona i 10 successivi e premi di nuovo ZIP.

Qual è lo ZIP più grande che può creare?

256 MB in totale. Sopra 200 MB chiede conferma. Non divide i file in più ZIP.

Come si chiama il file ZIP?

Il nome host del sito e la data, per esempio docs.example.com_2026-11-17.zip. Un www. iniziale viene omesso.

La mia selezione è troppo grande per uno ZIP. Cosa faccio?

Seleziona meno file per ogni ZIP, oppure salva in una cartella invece di creare uno ZIP.
