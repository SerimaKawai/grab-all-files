Fine to do

  • ✓Save lecture slides, handouts and reading PDFs of a course you are enrolled in, for your own study.
  • ✓Save the syllabus pages and course schedules of courses you are considering, if they are public.
  • ✓Keep the materials from before the course ends, in case access closes.
  • ✓Check each course's rules: some teachers say not to copy or pass on the files.

Do not do

  • –Share, post or sell the files to people who are not in the course.
  • –Collect materials from courses you are not enrolled in by using someone else's sign-in.
  • –Treat “I can download it” as permission to re-use it. The provider's terms decide.
  • –Expect it to open video lectures that are streamed rather than linked as files.

Three kinds of place, three ways of working

Learning-management system

Sign in with your own account in the same browser, open the course page, and scan. It uses your signed-in state and does not read or send your password. Details for portals in general are in the guide for internal portals.

A teacher's own site

Usually a plain page of links to PDFs and slides. Start from the course page. A depth setting follows links from that page, and only within the folder of the page you started from.

Study and tutorial sites

Pages with handouts, problem sets and worked answers. Scan the page for linked files; if the page is long, scroll it before scanning on Free.

The file list on a sample training page

Depth on a teacher's site

The depth setting decides how many links away from the start page the scan looks. It stays inside the folder of the start page, so a start page at /courses/networks/ will not wander into /courses/databases/.

Steps

  1. 1Sign in to the learning-management system in your browser, if needed, and open the course page.
  2. 2Open Grab All Files, use “Bulk File Download” and scan. Narrow the list to Presentations, Documents and PDF.
  3. 3Set the file name to the PDF's title or keep the original name. Folder sorting is only by type or by site, so create one save folder per course yourself and choose it when you save.
  4. 4Save. On Free, one save takes up to 10 files, so save a week at a time. Pro saves the whole selection at once.
  5. 5If the session ends while you are saving, the rows show that you were signed out. Sign in again and retry the failed ones; the saved files stay.

Syllabi as pages

A syllabus is often a web page and not a file. If you want to keep it, use “Combine pages into HTML” to save that page as HTML, or as Markdown if you want to read it in a notes app. On Free, a run saves one page you choose from the candidate list; Pro saves several in one run.

FAQ

Can I save lecture slides from my school's learning system?

Yes, if you can open the course page in your browser. It uses the account you are signed in with.

Does it get past a sign-in or a paywall?

No. It does not log in for you, break a CAPTCHA or open pages you cannot already view.

Can it go through the whole university website?

It can: depth has an Unlimited setting, and a scan reads up to 100,000 pages. That is rarely what you want. Start at the course page and use a small depth, because the scan stays inside the start page's folder anyway.

How many files can I save for free?

Up to 10 selected files per save. Select the next ones and save again. Pro has no limit per save.

Can I save video lectures?

Only videos that are linked as plain files such as mp4. Streamed lectures, where the page plays video in a viewer, are not saved.

Does it make one folder per course?

No. You choose the save location each time, so create a folder per course yourself. The built-in folder sorting is only by type or by site, and there is no option to name folders by course.
