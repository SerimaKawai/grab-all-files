Dove Grab All Files è la scelta giusta

  • ✓Devi accedere per vedere le pagine e puoi già aprirle nel browser.
  • ✓Le pagine sono costruite con JavaScript e un normale download torna vuoto.
  • ✓Vuoi che PDF e file Office siano elencati prima, per controllarli e tenerne solo alcuni.
  • ✓Il lavoro riguarda un insieme limitato di pagine, o un lungo elenco di file su poche pagine.

Dove è la scelta sbagliata

  • –Un intero sito di migliaia di pagine, copiato in un colpo solo.
  • –Una copia che aggiorni ogni settimana, scaricando solo i file cambiati.
  • –Video trasmessi in streaming invece che collegati come file.
  • –Pagine che non puoi aprire nel tuo browser.

Usarne più di uno

I metodi non sono rivali. Una divisione comune: usa un copiatore di siti desktop per un grande sito pubblico e Grab All Files per l’area con accesso dello stesso sito, oppure per i PDF sparsi su poche pagine. L’elenco dei file di Grab All Files si può anche esportare in CSV, con l’URL di ogni file, se vuoi passarlo a un altro strumento.

FAQ

Grab All Files è un copiatore di siti?

Non nel senso usuale. Salva le pagine una alla volta dentro il browser e può scrivere sul computer la struttura di cartelle di un sito. È adatto a un insieme limitato di pagine. Per migliaia di pagine usa un copiatore di siti desktop.

Quale metodo funziona su un sito a cui devo accedere?

Uno strumento che viene eseguito dentro il browser, perché usa l’accesso che hai già. Grab All Files e le estensioni per salvare una pagina funzionano così. I copiatori desktop spesso richiedono configurazioni aggiuntive.

Posso aggiornare una copia salvata e scaricare solo ciò che è cambiato?

Non con Grab All Files. Ha un rapporto modifiche in Markdown che confronta con la tua ultima raccolta dello stesso sito, ma salva di nuovo le pagine. Un copiatore di siti desktop è il metodo pensato per l’aggiornamento.

In cosa è diverso da un download manager?

Un download manager prende un elenco di link a file e li scarica bene. Grab All Files prima trova i file, compresi quelli che una pagina carica tramite script, li mostra in un elenco da controllare e può anche salvare le pagine come HTML.
