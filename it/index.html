Scarica file in blocco. Riunisci le pagine in un solo HTML.

Grab All Files è un’estensione del browser con due strumenti. Il download in blocco dei file trova i file scaricabili di una pagina (PDF, immagini, documenti Office, ZIP) e salva quelli che selezioni. Unisci pagine in HTML salva una pagina web in un unico HTML ricercabile; con Pro, più pagine correlate in un solo file. Versione gratuita: fino a 10 file per download e una pagina scelta per esecuzione. Pro ($19.99 una tantum): nessun limite di file e unione di più pagine. Tutto viene elaborato sul tuo dispositivo.

Unisci pagine in HTML

Trasforma le pagine web correlate in un unico file HTML facile da leggere.

Parti dalla pagina aperta nel browser. Grab All Files trova le pagine correlate, ti consente di controllare quali verranno incluse e unisce la tua selezione in un unico file HTML con indice, ricercabile e stampabile.

Trova e controlla le pagine

Usa il rilevamento automatico per iniziare subito oppure i controlli avanzati per menu, percorsi, sitemap ed elenchi di URL incollati. Prima della raccolta, controlla i titoli e rimuovi o riordina le pagine come preferisci.

Salva un unico documento portatile

Incorpora le immagini per la lettura offline oppure mantieni i riferimenti online per ridurre le dimensioni del file. PDF, file di Office e altri documenti collegati possono essere salvati insieme al file HTML.

Esportazione opzionale pronta per l’IA

Genera Markdown con fonti tracciabili, JSONL, un manifest e dati tabellari per l’analisi. La raccolta delle pagine e la generazione del file HTML avvengono localmente sul tuo dispositivo; il contenuto delle pagine non viene caricato sui nostri server.

La versione gratuita trova e mostra le pagine correlate e salva l’unica pagina che scegli. Le immagini di quella pagina non hanno limiti numerici legati al piano; i file collegati direttamente da essa vengono salvati 10 alla volta e «Salva i prossimi 10» nella schermata dei risultati salva il resto. Pro seleziona più candidate e ne unisce il contenuto principale in un HTML. In entrambi i casi si applicano i limiti di sicurezza e del sito di origine.

🔎

Trova file nascosti

Supporta 708 tipi di file (estensioni). Rileva PDF in iframe, immagini a caricamento differito (lazy loading), risposte fetch/XHR, URL blob, percorsi di download CMS, valori nascosti dei moduli e 39 attributi data-* che i semplici estrattori di link ignorano. Arriva persino nello Shadow DOM / Web Components, nei dati di hydration delle SPA (Next.js, JSON-LD), in Cache Storage / OPFS / IndexedDB e negli URL firmati di cloud storage (Cloudflare R2, Firebase, Supabase, Vercel Blob).

⚙️

Filtri sui risultati

Filtra i risultati per estensione, dimensione del file, nome del file, titolo della pagina o data di modifica. Ordina, riordina manualmente e copia gli URL come testo semplice.

🕸️

Crawl dello stesso sito

Scegli una profondità (0–5 o illimitata) e visita i link nella cartella della pagina iniziale (parti dalla radice del sito per coprire l’intero sito) per far emergere i PDF nelle sottopagine, gli URL dei viewer e i percorsi dei documenti CMS — fino a 100.000 pagine per esecuzione. Legge anche sitemap.xml / robots.txt e segue i link dei menu JavaScript (javascript:/onclick), dei frameset, delle image map e dei moduli GET di ricerca/paginazione, raggiungendo pagine senza link HTML normali.

Raggruppa i file selezionati in un unico ZIP per distribuirli, archiviarli o condividerli in ordine — generato interamente nel tuo browser.

Esportazione CSV

Esporta URL, nomi, dimensioni, tipi e titoli in CSV per documentazione, audit, inventari o automazioni successive.

🔐

Scansiona pagine autorizzate

Usa la sessione attuale del browser per esaminare intranet, portali/LMS e pagine riservate che sei già autorizzato ad aprire. Non raccoglie credenziali né aggira i controlli di accesso.

🛡️

Funziona su pagine complesse

Gestisce SPA renderizzate con JavaScript (React, Next, Nuxt, Vue), percorsi di viewer e moduli protetti da CSRF quando fanno parte di pagine a cui sei autorizzato ad accedere. Conferma il tipo di file dalla firma, non solo dall’estensione, e può scansionare anche vecchi siti HTTP.

⚙️

Pensato per grandi lavori

Scansiona molti URL insieme o esegui il crawl di un intero sito, poi controlla i download paralleli, pausa/ripresa, riprova gli errori, organizza in cartelle per tipo o dominio e rinomina i file dal titolo del PDF.

Quando usarlo

Come Grab All Files si integra con altri strumenti

Grab All Files si concentra su due attività: trovare file in pagine complesse o protette da login e riunire le pagine scelte in un HTML leggibile. Download manager e copiatori di siti coprono altre parti del flusso.

🔎

Trovare file su pagine complesse o con login

PDF, immagini e documenti nascosti dietro iframe, viewer, JavaScript, login e percorsi CMS. Grab All Files li rileva, permette di filtrare e selezionare, poi scarica in blocco, unisce i PDF, crea ZIP ed esporta CSV, tutto localmente.

🚚

Scaricare molte URL note o file enormi

Per file molto grandi o lunghi lavori in batch non presidiati con gestione della coda e ripresa, un download manager dedicato (JDownloader, aria2) è l'ideale. Grab All Files trova i file ed esporta l'elenco di URL; il lavoro pesante lo lascia al download manager.

🗺️

Ti serve una copia offline esatta di un intero sito web?

Usa un programma per copiare siti web, come HTTrack, quando ti serve una replica navigabile che conservi pagine, link e struttura originali. Grab All Files, invece, riunisce il contenuto leggibile delle pagine selezionate in un unico file HTML con indice; non crea una copia visivamente identica del sito.

FAQ

Quali tipi di file sono supportati?

Grab All Files supporta 708 tipi di file (estensioni), tra cui PDF, Word, Excel, PowerPoint, immagini, ZIP e CSV. Rileva anche sequenze di archivi divisi / multivolume (.000/.001…, WinRAR .r00/.s00, WinZip .z01) e le raggruppa come archivi compressi. Filtra per estensione, seleziona ciò che ti serve e scarica tutto con un clic.

È gratis?

Sì. La versione gratuita scarica fino a 10 file per download e trova le pagine correlate, tra cui sceglierne esattamente una da salvare come HTML. Le immagini di quella pagina non hanno limiti numerici legati al piano; i suoi file collegati direttamente vengono salvati 10 alla volta e «Salva i prossimi 10» nella schermata dei risultati salva il resto. Restano i limiti di sicurezza e del sito. Pro costa $19.99 una tantum, rimuove il limite dei file e unisce il contenuto di più pagine in un HTML.

Cosa succede quando raggiungo il limite di 10 file?

Non si blocca nulla. La versione gratuita salva fino a 10 file per download. Al termine, seleziona i file successivi nell’elenco e fai di nuovo clic su «Salva i selezionati»; ripeti finché non hai tutto. Pro rimuove il limite per download.

Posso unire più pagine web in un unico file HTML?

Sì, con Pro. La versione gratuita trova e mostra le pagine correlate, ma salva solo la pagina scelta. Pro consente di selezionare più candidate e unisce il loro contenuto leggibile in un HTML con indice comune, ricerca e stampa.

Quanto costa Pro?

$19.99 USD, pagamento una tantum. Licenza a vita, nessun abbonamento. Attivabile su un massimo di 3 dispositivi; un dispositivo è un profilo del browser su un computer, e puoi liberare un posto rimuovendo un dispositivo dalla schermata della licenza nell’estensione.

Come attivo Pro dopo l’acquisto?

La chiave di licenza viene mostrata nella pagina di conferma subito dopo il pagamento e ti arriva anche via e-mail. Apri l’estensione, fai clic su «Gratis» in alto a destra (oppure apri il menu ⋯ e scegli «Pro e chiave di licenza»), incolla la chiave e fai clic su «Attiva». Quando l’etichetta in alto a destra diventa «Pro», hai finito.

Invia i miei dati di navigazione?

No. I file vengono scaricati direttamente dal sito sorgente al tuo dispositivo. Solo la verifica della licenza e statistiche d’uso pseudonime facoltative raggiungono i nostri server. Le statistiche sono disattivate per impostazione predefinita e vengono inviate solo dopo consenso esplicito; ogni evento contiene un ID di installazione casuale, la versione dell’estensione, il tuo piano e conteggi o etichette approssimativi (ad esempio quanti file sono stati trovati), mai il contenuto delle pagine, gli URL o i nomi dei file. Dettagli in Sicurezza e permessi.

Google Chrome e Microsoft Edge (Chromium 111 o successivo) e Mozilla Firefox (128 o successivo).

Come prodotto digitale consegnato immediatamente, i rimborsi non sono accettati in linea di principio. La versione gratuita consente di verificare la compatibilità e provare l’HTML di una pagina e i download da 10 file prima di Pro. Se un difetto tecnico ne impedisce l’uso, contattaci entro 30 giorni dall’acquisto per un rimborso completo.

Funziona sui siti protetti che richiedono l’accesso?

Sì. L’estensione usa la tua sessione del browser esistente per scansionare le pagine a cui sei già autorizzato ad accedere, come intranet, portali LMS e aree riservate ai membri. Non raccoglie credenziali né aggira i controlli di accesso.

Come scarico tutti i file di una pagina web in una volta?

Installa Grab All Files per Google Chrome, Microsoft Edge o Mozilla Firefox, apri la pagina (o incolla il suo URL) e l’estensione elenca ogni file rilevabile, compresi quelli nascosti dietro iframe, visualizzatori, lazy loading, risposte fetch/XHR, URL blob e percorsi di download CMS. Seleziona i file che vuoi e scaricali tutti con un clic.

Come posso scaricare tutti i PDF di un sito web?

Grab All Files rileva ogni PDF di una pagina, anche quelli incorporati in iframe e gli URL dei visualizzatori PDF, e può esplorare i link dello stesso sito fino a 100.000 pagine per esecuzione. Filtra i risultati per PDF, seleziona tutto, poi scaricali in blocco o uniscili in un unico PDF localmente nel browser.

Qual è la migliore estensione di Chrome per scaricare file in blocco?

Grab All Files è uno strumento di download in blocco per Google Chrome, Microsoft Edge e Mozilla Firefox. Trova PDF, documenti Office, immagini, ZIP e CSV scaricabili che i normali estrattori di link non vedono, poi salva i file selezionati con un clic, unisce i PDF, crea archivi ZIP ed esporta un CSV degli URL dei file. La versione gratuita salva fino a 10 file per download; la licenza Pro da $19.99 una tantum rimuove questo limite.

Come salvo tutte le immagini di una pagina web?

Grab All Files rileva le immagini, comprese quelle in lazy loading, le immagini di sfondo CSS e gli URL blob. Filtra i risultati per tipo di immagine, selezionale e scaricale tutte insieme, oppure esporta l’elenco degli URL delle immagini in CSV.

Posso unire PDF senza caricarli su un server?

Sì. Grab All Files unisce i PDF selezionati localmente nel browser. Non viene caricato nulla: i tuoi file non lasciano mai il dispositivo.

Gestisce download grandi o di lunga durata, con pausa e ripresa?

Sì. Grab All Files include un download manager integrato con parallelismo regolabile, pausa e ripresa, nuovo tentativo automatico e nuovo tentativo con un clic per i file non riusciti, così i lotti grandi proseguono anche se la connessione cade. Per file singoli molto grandi o lavori lunghi non presidiati, puoi anche esportare l'elenco di URL e passarlo a un download manager dedicato.

Posso usarlo insieme a un download manager come JDownloader o aria2?

Sì, si completano a vicenda. Grab All Files è il migliore nel trovare file su pagine complesse o protette da login (dietro iframe, viewer, JavaScript e percorsi CMS). Esporta i risultati come CSV o elenco di URL e passali al tuo download manager per il download di massa: la scoperta in Grab All Files, il lavoro pesante nel tuo download manager.

Funziona su app JavaScript, pagine con login e siti protetti dai bot?

Sì. Legge le SPA renderizzate in JavaScript (React, Next.js, Nuxt, Vue) dopo la costruzione della pagina, usa la tua sessione del browser esistente per le pagine che puoi già aprire, segue i moduli di download protetti da CSRF e rileva i bot-wall di Cloudflare/WAF per guidare il recupero. Conferma i tipi di file tramite firma, non solo tramite estensione, e non elude mai i controlli di accesso o le protezioni di sicurezza.
