자주 묻는 질문

파일 목록 CSV와 같은 기능인가요?

아니요. 파일 목록 CSV는 파일 URL과 정보를 나열합니다. 이 절차는 수집기의 AI 출력에서 HTML 표 데이터를 추출합니다.

모든 표가 CSV가 되나요?

페이지별 또는 전체 패키지 출력에서 표 내보내기를 켜면 의미 있는 HTML 표를 지원 한도 안에서 추출합니다. 레이아웃 표는 제외되며 이미지나 PDF 화면 표의 변환은 보장하지 않습니다.

XLSX를 바로 출력하나요?

이 절차는 CSV·JSON을 만듭니다. CSV는 직접 Excel로 열거나 가져오며 XLSX 직접 출력으로 안내하지 않습니다.

무료로 시작할 수 있나요?

Free는 선택한 1페이지, Pro는 여러 본문을 수집합니다. 파일은 기기에서 준비하고 Excel이나 외부 AI에 직접 전달합니다.
