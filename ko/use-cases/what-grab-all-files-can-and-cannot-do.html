Grab All Files로 할 수 있는 일과 할 수 없는 일을 숫자와 함께.

Grab All Files는 Chrome, Edge, Firefox용 브라우저 확장 프로그램입니다. 웹 페이지의 파일을 찾고, 페이지를 HTML로 저장합니다. 이 페이지는 제한, 무료와 Pro에서 달라지는 것, 저장할 수 없는 페이지와 파일, 그리고 그런 경우에 쓸 도구의 종류를 정리합니다.

제한

Pro는 US$19.99이며 한 번만 결제하고 구독은 없으며, 라이선스 하나로 최대 3대의 기기에서 쓸 수 있습니다. 무료는 신용카드가 필요 없습니다.

항목숫자무엇을 세는가무료와 Pro
한 번에 저장하는 파일(파일 다운로드)무료 10개. Pro는 상한 없음1회 저장을 위해 선택한 파일: 다운로드, ZIP, PDF 병합, CSV. 무료는 다음 10개를 선택해 버튼을 다시 누릅니다.파일 다운로드에서 두 플랜이 다른 점입니다.
1회에 저장하는 페이지(페이지 수집)무료 1개. Pro는 선택한 만큼HTML에 저장되는 페이지. 무료는 후보를 하나 고르며, 지난번에 저장한 HTML에 페이지를 하나씩 추가할 수 있습니다.Pro에서 100페이지를 넘으면 100페이지마다 일시 정지할지 먼저 묻습니다.
HTML과 함께 저장하는 링크된 파일무료 10개. Pro 100개(1회당)저장한 페이지가 링크하는 PDF, Word, Excel 등의 파일. 결과 화면의 버튼으로 다음 묶음을 저장합니다.Pro는 링크된 것이 100개를 넘으면 먼저 묻습니다.
수집 1회의 페이지 수100,000파일이나 후보 페이지를 찾을 때 한 번의 수집이 읽는 페이지 수. sitemap.xml과 robots.txt도 읽습니다.두 플랜이 같습니다.
수집 깊이이 페이지만, 깊이 1~5, 또는 무제한시작 페이지에서 링크를 몇 단계까지 따라가는지. 깊이는 시작 페이지가 있는 폴더 안에서 작동합니다.두 플랜이 같습니다.
ZIP 하나의 크기256MB합계가 200MB를 넘으면 확인 창이 나타납니다. ZIP을 여러 개로 나누지는 않습니다.무료는 ZIP에도 10개 제한이 있습니다.

기기3대Pro 라이선스 하나를 최대 3대의 기기에서 활성화할 수 있습니다.Pro 전용.

Pro의 '100'이 무엇이고 무엇이 아닌지

Pro에는 다운로드하는 파일 수의 제한이 없습니다. 100은 '페이지를 HTML로 합치기'에서 1회에 HTML 옆에 저장되는 링크된 파일의 수입니다. 저장한 페이지가 가리키는 PDF와 Office 파일입니다. 무료는 1회에 그것을 10개 저장합니다. 더 많이 링크되어 있다면 결과 화면에 다음 묶음을 위한 버튼이 있습니다.

혼동하기 쉬운 숫자가 두 개 더 있습니다. 100,000은 수집 1회의 페이지 한도이고, 100은 가장 긴 '스크롤 시간' 설정에서 Pro 스캔이 따라가는 '다음' 페이지 수이기도 합니다. 세 가지는 서로 별개의 설정입니다.

무엇자세히
페이지의 파일을 목록으로 보여 주고 고른 것을 저장38개 분류의 708가지 파일 유형을 찾으며, iframe 안의 PDF, 지연 로딩 이미지, fetch/XHR이나 blob URL로 불러오는 파일도 포함합니다. 저장하기 전에 목록을 거르고, 정렬하고, 검색합니다.
Office 파일, 동영상 파일, 오디오 파일 저장Word, Excel, PowerPoint 파일과, 페이지가 직접 링크하는 동영상·오디오 파일. 무료와 Pro가 같습니다.
링크를 따라가 더 많은 파일 찾기이 페이지만에서 무제한 깊이까지, 수집 1회에 최대 100,000페이지.
ZIP 만들기, PDF 병합, 파일 목록 내보내기모두 브라우저에서 처리합니다. 주요 CSV 열은 URL, 파일 이름, 제목, 유형, 크기, 각 파일을 찾은 페이지입니다.
페이지를 HTML로 저장네 가지 저장 형태와 두 가지 모양('읽기 쉽게 정리' 또는 '원래 모양 그대로'). 저장한 각 페이지에 출처 URL과 수집 시각을 남길 수 있습니다.
로그인한 뒤 보이는 페이지와 JavaScript로 만든 페이지 저장브라우저에 표시된 내용을 이미 로그인된 상태로 저장합니다. 비밀번호를 저장하지 않으며 CAPTCHA는 통과하지 않습니다.
확인된 사이트에서 피드를 끝까지 읽기확인된 사이트(X의 게시물과 답글, YouTube 댓글, Reddit, Bluesky, Yahoo! 뉴스 댓글)에서는 타임라인과 댓글 목록을 게시물 수 상한 없이 끝까지 스크롤하며, 1,000개마다 계속할지 묻습니다. 그 밖의 페이지는 기본적으로 최대 10회 스크롤하고 멈춥니다.
내 컴퓨터에서 작동페이지와 파일은 원본 사이트에서 내 컴퓨터로 갑니다. 개발자의 서버로는 전송되지 않습니다.

저장할 수 없는 것과 대신 쓸 도구

첫 번째 열은 Grab All Files가 저장하지 않는 것입니다. 마지막 열은 제품이 아니라 도구의 종류입니다.

저장할 수 없는 것어떻게 되나알맞은 도구의 종류
브라우저 내부 페이지(chrome://), Chrome 웹 스토어와 Edge 추가 기능 페이지, file:// 페이지그곳에서는 실행되지 않습니다.이미 내 컴퓨터에 있는 HTML 파일은 페이지를 HTML로 합치기의 '컴퓨터 폴더에서' 옵션이 폴더나 ZIP을 읽습니다. 그 밖에는 브라우저 자체의 '페이지 저장'.
DRM이나 암호화된 뷰어 안의 파일파일을 읽을 수 없습니다.게시한 쪽이 제공하는 다운로드가 있다면 그것.
브라우저 내장 PDF 뷰어 안, 닫힌 Shadow DOM 안의 텍스트, 캔버스에만 그려진 텍스트텍스트를 텍스트로 읽을 수 없습니다.화면을 이미지로 저장하거나 브라우저의 PDF 인쇄.
허용하지 않은 다른 도메인의 iframe허용하기 전에는 읽지 않습니다. 허용하면 읽을 수 있습니다.다른 도구는 필요 없습니다. 브라우저가 물으면 그 사이트를 허용하세요.
스트리밍 동영상(HLS .m3u8, DASH .mpd), blob: 재생, 파일 확장자가 없는 재생 URL, 스트리밍 사이트의 동영상저장하지 않으며, DRM이나 워터마크를 우회하지 않고, 스트림을 녹화하지도 않습니다.동영상을 게시한 쪽이 제공하는 다운로드 기능이 있다면 그것.
로그인할 수 없거나 볼 권한이 없는 페이지브라우저의 접근 권한을 쓰며 그것을 늘릴 수는 없습니다.소유자에게 파일을 요청하거나 제공처의 일괄 다운로드나 API를 쓰세요.
수천 페이지, 또는 지난번 이후 바뀐 파일만브라우저 안에서 페이지를 하나씩 처리하므로 그 규모에서는 느리고, 업데이트만 받는 모드는 없습니다.PC용 웹사이트 복사 프로그램.
대량의 논문이나 공공 데이터작은 묶음은 가능하지만 전체 자료를 모으는 데 알맞은 도구는 아닙니다.출처의 일괄 다운로드나 API(있는 경우).

자주 묻는 질문

무료 플랜에서는 한 번에 몇 개까지 다운로드할 수 있나요?

저장 1회에 10개입니다. 선택한 것으로 만드는 ZIP, PDF 병합, CSV에도 같은 제한이 적용됩니다. 이어서 하려면 다음 10개를 선택해 버튼을 다시 누르세요. Pro는 파일 수 상한이 없습니다.

Pro는 다운로드가 100개로 제한되나요?

아니요. Pro의 파일 다운로드에는 파일 수 상한이 없습니다. 100은 '페이지를 HTML로 합치기'를 1회 실행할 때 HTML 옆에 저장되는 링크된 파일의 수입니다. 결과 화면의 버튼으로 다음 묶음을 저장합니다.

몇 페이지까지 수집할 수 있나요?

수집 1회에 최대 100,000페이지이며, 깊이는 '이 페이지만', 1~5, 무제한입니다. sitemap.xml과 robots.txt도 읽습니다.

ZIP은 얼마나 클 수 있나요?

256MB입니다. 합계가 200MB를 넘으면 확인 창이 나타납니다. ZIP을 여러 파일로 나누지 않으므로 한도에 걸리면 파일을 줄여 선택하세요.

스트리밍 동영상을 저장할 수 있나요?

아니요. .mp4나 .webm처럼 페이지가 직접 링크하는 동영상 파일을 저장합니다. HLS나 DASH 스트림, blob: 재생, 스트리밍 사이트의 동영상은 저장하지 않습니다.

수천 페이지의 사이트에는 무엇을 써야 하나요?

PC용 웹사이트 복사 프로그램입니다. Grab All Files는 브라우저 안에서 한 번에 한 페이지씩 읽습니다. 그래서 로그인 뒤의 페이지와 JavaScript로 만든 페이지를 저장할 수 있고, 사이트가 수천 페이지가 되면 느려지는 것도 같은 이유입니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
