ZIP 버튼의 위치

숫자로 보기

ZIP
무료의 ZIP당 파일 수최대 10개로, 다운로드 1회와 같습니다. 다음 10개를 선택해 ZIP을 다시 누르면 보관 파일이 하나 더 생깁니다.
Pro의 ZIP당 파일 수개수 제한은 없지만 아래의 크기 제한은 계속 적용됩니다.
ZIP 이름사이트의 호스트 이름과 오늘 날짜입니다. 예: docs.example.com_2026-11-17.zip(앞의 www.는 뺍니다).
확인합계가 200MB를 넘으면 확인 창이 나타납니다.
상한합계 256MB.
한도를 넘으면여러 ZIP으로 나누지 않습니다. 파일을 줄여 선택하거나, 대신 폴더에 저장하세요.

순서

  1. 1페이지를 열고 '파일 일괄 다운로드'로 스캔합니다.
  2. 2목록을 거르고 원하는 파일을 체크합니다. 크기를 확인하세요. 200MB에 가깝다면 합계를 더해 봅니다.
  3. 3'ZIP'을 누릅니다. 크기에 대해 물으면 확인합니다.
  4. 4다운로드 폴더에서 ZIP을 엽니다. 무료: 더 받으려면 다음 파일을 선택해 ZIP을 다시 누릅니다.

ZIP이 알맞은 경우

  • ✓한 묶음을 파일 하나로 보내거나 보관하고 싶을 때.
  • ✓묶음이 수십 개 파일이고 200MB를 한참 밑돌 때.
  • ✓낱개 다운로드 여러 개 대신 깔끔한 파일 하나를 원할 때.

대신 폴더에 저장하는 경우

  • –합계가 256MB에 가깝거나 넘을 때: 동영상, 큰 도면, 스캔한 책.
  • –파일을 유형별이나 도메인별로 폴더를 나누어 정리하고 싶을 때.
  • –개별 파일을 바로 열거나 이름을 바꾸고 싶을 때.

ZIP은 여러 출력 방법 중 하나

같은 선택을 낱개 파일로 저장하거나, 병합(PDF)하거나, 파일 목록(CSV)으로 내보낼 수도 있습니다. 모든 처리는 브라우저에서 이루어집니다.

'페이지별 HTML(ZIP)'과 혼동하지 마세요

'페이지별 HTML(ZIP)'은 다른 도구인 페이지를 HTML로 합치기에 속합니다. 저장한 웹 페이지를 페이지마다 HTML 파일 하나와 index.html로 ZIP 안에 담습니다. 파일 일괄 다운로드의 ZIP 버튼은 PDF나 Office 문서 같은 파일을 그대로 묶습니다. 두 기능은 별개이며, 이 페이지의 제한은 ZIP 버튼에 대한 숫자입니다.

자주 묻는 질문

페이지의 여러 파일을 ZIP 하나로 다운로드하려면 어떻게 하나요?

파일 일괄 다운로드로 페이지를 스캔하고, 파일을 체크한 뒤 ZIP을 누르세요. 보관 파일 하나가 만들어집니다.

무료로 ZIP 하나에 몇 개까지 넣을 수 있나요?

10개입니다. 보고서 30개라면 10개짜리 ZIP 세 개가 됩니다. 다음 10개를 선택해 ZIP을 다시 누르세요.

만들 수 있는 가장 큰 ZIP은 얼마인가요?

합계 256MB입니다. 200MB를 넘으면 확인을 요청합니다. 파일을 여러 ZIP으로 나누지는 않습니다.

ZIP 파일 이름은 어떻게 되나요?

사이트의 호스트 이름과 날짜입니다. 예: docs.example.com_2026-11-17.zip. 앞의 www.는 뺍니다.

선택한 것이 ZIP으로 만들기엔 너무 큽니다. 어떻게 하나요?

ZIP당 파일을 줄여 선택하거나, ZIP 대신 폴더에 저장하세요.
