페이지별 정리

페이지별 Markdown을 주제로 묶고 조사·글쓰기 노트에서 각 출처를 연결합니다.

적합한 용도

  • ✓관련 글에서 출처 있는 조사 노트를 만들기.
  • ✓작성 중인 글이나 직접 만든 노트 옆에 참고 본문 두기.
  • ✓필요한 Markdown을 골라 외부 AI에 질문하기.

작업 흐름

  1. 1저장이 허용된 페이지를 열고 “페이지를 HTML로 합치기”를 시작합니다. 관련 후보를 확인해 필요한 페이지만 선택하세요. 무료 버전은 선택한 한 페이지를 HTML로 저장하고 Pro는 여러 페이지 본문을 결합합니다.
  2. 2수집 전에 “AI 분석용 데이터(출처 포함 Markdown)”를 활성화합니다. 읽기용은 “하나의 Markdown”, 개별 노트는 “페이지별 Markdown”, 구조화 자료도 쓸 때는 “전체 패키지”를 선택합니다.
  3. 3결과 화면에서 제목, 링크, 중요한 본문을 원본 페이지와 견주어 보고 실패 항목도 살펴보세요. 목차와 본문 검색을 쓰려면 HTML도 저장합니다.
  4. 4“AI 분석용 ZIP 저장”을 사용해 ZIP을 풀고 지원 편집기에서 Markdown을 엽니다. source_url·captured_at을 남기고 주제 이름과 확인일을 메모에 추가합니다.
  5. 5노트 도구에 지원 파일을 직접 복사·가져옵니다. 외부 AI에는 필요한 파일과 “AI 요청문 복사”로 준비한 요청문·질문을 수동으로 전달하고 답변을 본문과 최신 출처로 확인합니다.

자주 묻는 질문

Obsidian이나 Notion과 자동 동기화되나요?

먼저 파일을 내보낸 후 대상 도구가 지원하는 방법으로 직접 복사·가져옵니다. 제목·표·링크를 확인하세요. 확장 기능은 보관함이나 작업 공간을 자동 동기화하지 않으며 가져오기 지원은 도구에 따라 다릅니다.

이미지와 동적 콘텐츠도 그대로 남나요?

Markdown은 이미지를 원래 URL로 참조할 수 있으며 이미지 파일이 항상 패키지에 포함되는 것은 아닙니다. 사이트 전체 복제는 아니므로 중요한 이미지와 조작이 필요한 내용은 원본에서 확인하세요.

25MB 설정이 패키지 전체 크기를 제한하나요?

기본 25MB는 Markdown 본문의 분할 기준입니다. ZIP 전체 크기나 다른 도구의 수용을 보장하지 않습니다. ZIP을 풀고 대상 도구 제한에 맞춰 파일을 선택하거나 나눕니다.

연결된 PDF·Word는 어떻게 되나요?

선택한 지원 문서에서 추출에 성공한 본문은 AI 출력에 포함될 수 있습니다. 필요한 원본은 따로 보관하고 읽지 못한 부분·누락을 확인하세요. 스캔 문서 추출은 보장되지 않으며 문서 본문은 읽기용 HTML에 합쳐지지 않습니다.

내보내면 AI로 전송되나요?

아닙니다. 기기에서 파일을 준비하고 사용자가 외부 서비스를 골라 지원 파일과 질문을 직접 전달합니다. 답변을 확인할 때는 남겨 둔 source_url과 captured_at을 참고하세요. 취득 시각이 출처의 현재 내용을 보장하지는 않습니다.

무료로 사용할 수 있나요?

예. 무료 버전은 한 번에 선택한 1페이지를 저장합니다. 그 페이지의 이미지에는 플랜 제한이 없고, 직접 링크된 파일은 결과 화면의 “다음 10건 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 선택한 여러 페이지를 하나의 HTML로 합칩니다.

로그인이 필요한 페이지는 어떻게 되나요?

수집은 브라우저의 로그인 상태를 그대로 사용하며 인증 정보를 수집하지 않습니다. “로그인 필요”로 표시되면 “사이트를 열어 로그인”을 누르고 열린 탭에서 로그인한 뒤 “재개”를 누르세요. 계속 로그인이 필요한 페이지는 저장되지 않으며, 남은 페이지 수가 결과에 표시됩니다.

저장한 페이지에서 본문 일부가 빠지는 이유는요?

스크롤하거나 클릭한 뒤에야 본문을 보여 주는 사이트가 있습니다. “페이지에서 본문이 빠질 때: 내용 및 JavaScript 설정”을 열고 “‘더 보기’를 눌러 이어지는 내용 포함”을 켠 뒤 다시 수집하세요. 페이지의 다른 부분이 저장되었다면 그곳의 “화면에서 선택”으로 본문 범위를 지정할 수 있습니다.
