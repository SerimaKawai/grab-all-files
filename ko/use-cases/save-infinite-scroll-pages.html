직접 확인할 것

  • –일반 목록 페이지는 기본적으로 10회 스크롤 뒤에 멈추므로, 긴 상품 목록은 잘릴 수 있습니다.
  • –캔버스에만 그려진 텍스트나 닫힌 Shadow DOM 안의 텍스트는 읽지 않습니다.
  • –다른 도메인의 프레임은 허용한 뒤에만 읽습니다.
  • –내 브라우저에서 열 수 없는 페이지, 예를 들어 내게 없는 로그인이 필요한 페이지.

긴 타임라인이나 댓글란 저장하기

  1. 1로그인이 필요한 페이지라면 로그인한 브라우저 탭에서 페이지를 엽니다.
  2. 2Grab All Files를 열고 “페이지를 HTML로 합치기”로 바꿉니다. 현재 페이지만 선택합니다.
  3. 3모양과 저장 형태를 고르고 저장을 시작합니다. 페이지가 저절로 스크롤됩니다.
  4. 41,000개마다 계속할지 묻습니다. 답하거나 그냥 두세요. 10분 동안 답이 없으면 지금까지 읽은 것을 저장합니다.
  5. 5저장된 파일을 열어 마지막 항목을 실제 페이지의 끝과 비교하고, 페이지가 항목 수를 표시한다면 그 수와도 비교합니다.

긴 페이지의 파일 목록

무료에서는 페이지 끝까지 직접 스크롤한 뒤 스캔을 누릅니다. 스캔은 불러온 것을 읽습니다.

“맨 끝까지”를 약속하지 않는 이유

페이지가 항목을 더 불러오는 방식은 사이트마다 다릅니다. 위의 제한은 작업이 끝나게 해 주는 장치이지, 모든 항목에 도달했다는 보증이 아닙니다.

그래서 마지막 확인이 중요합니다. 저장한 파일의 끝을 실제 페이지의 끝과 비교하세요. 잘렸다면 다시 실행하거나, 파일 쪽에서는 더 스크롤한 뒤 다시 스캔하세요.

자주 묻는 질문

무한 스크롤 페이지를 맨 끝까지 저장할 수 있나요?

확인된 사이트(X, YouTube, Reddit, Bluesky, Yahoo! 뉴스)에서는 타임라인이나 댓글란 같은 피드를 끝날 때까지 스크롤합니다. 그 밖의 페이지는 기본적으로 10회 스크롤 뒤에 멈춥니다. 항상 저장한 파일의 끝을 실제 페이지와 비교하세요.

읽는 댓글이나 게시물 수에 제한이 있나요?

확인된 사이트의 피드에는 없습니다. 1,000개마다 계속할지 묻고, 10분 동안 아무도 답하지 않으면 지금까지 읽은 것을 저장합니다.

직접 스크롤해야 하나요?

페이지를 저장할 때는 아니요. 무료 플랜에서 파일을 스캔할 때는 네, 화면에 있는 것을 읽습니다. Pro의 스캔은 페이지를 대신 스크롤합니다.

Pro 스캔은 몇 페이지까지 따라가나요?

“스크롤 시간” 설정(45초, 90초, 180초)에 따라 6, 20, 100페이지입니다. 고르지 않으면 100페이지입니다. 버튼으로 다음 100페이지를 읽습니다.

댓글과 타임라인은 어느 사이트가 확인되었나요?

X의 게시물과 답글, YouTube 댓글, Reddit, Bluesky, Yahoo! 뉴스 댓글입니다. 다른 사이트에서도 될 수 있지만 이 목록에는 없습니다.
