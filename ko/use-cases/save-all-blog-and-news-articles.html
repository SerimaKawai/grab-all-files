기사를 찾는 세 가지 방법

사이트맵

사이트가 사이트맵을 공개하고 있다면 거기에 나열된 URL이 후보가 됩니다. 후보 수는 사이트가 나열하는 페이지 수를 대략 가늠하는 기준이 됩니다.

같은 경로

블로그의 목록 페이지에서 시작해 같은 경로 아래의 페이지(예: 블로그 폴더 아래 전부)를 수집합니다. 사이트의 나머지는 제외합니다.

목록 페이지의 '다음' 링크

next, '다음', '이전 글' 같은 링크를 인식합니다. 목록을 한 페이지씩 따라가며 후보를 찾습니다. 후보는 최대 100,000개까지 찾습니다.

후보, 모양, 저장 형태

후보는 각각 어떻게 찾았는지와 함께 나열됩니다. 그 아래에서 모양과 네 가지 형태 중 하나를 고릅니다.

블로그 전체를 저장하는 순서

  1. 1블로그의 목록 페이지, 즉 개별 기사가 아니라 최신 기사가 나열된 페이지를 엽니다. 사이트가 요구한다면 먼저 로그인합니다.
  2. 2Grab All Files를 열고 '페이지를 HTML로 합치기'로 바꿉니다. 어디서 수집할지에서 사이트맵, '같은 경로', '이 페이지의 링크를 따라가기' 중 하나를 고릅니다.
  3. 3후보 목록이 나올 때까지 기다립니다. 필터와 제외 입력란으로 기사가 아닌 페이지(태그 페이지, 카테고리 페이지, 작성자 페이지, 소개 페이지)를 뺍니다.
  4. 4Pro라면 기사를 선택하고 원하는 순서로 정렬합니다. 최신순이 보장되지는 않으므로 순서를 확인하세요.
  5. 5모양과 저장 형태를 고르고 저장합니다. 저장된 파일을 열어 첫 기사와 마지막 기사, 개수, 그리고 중간에 있다고 아는 구절을 검색해서 확인하세요.

이 도구가 맞지 않는 경우

Grab All Files는 브라우저 안에서 기사를 하나씩 읽으므로, 수천 개의 기사를 처리하면 시간이 오래 걸리고 파일도 매우 커집니다. 그 규모의 뉴스 아카이브라면 서버에 직접 페이지를 요청하는 PC용 웹사이트 복사 프로그램이 더 알맞습니다. 다만 로그인이 필요한 페이지는 볼 수 없습니다.

'다음' 링크가 아니라 스크롤하면 항목이 더 불러와지는 목록은 다른 경우입니다. 시작하기 전에 무한 스크롤 가이드를 읽어 보세요.

관련 가이드

  • 페이지를 HTML로 합치기후보 목록, 모양, 네 가지 저장 형태의 작동 방식.
  • 웹 자료를 Markdown으로페이지별 출처가 붙은 Markdown 출력.
  • 무한 스크롤 페이지 저장페이지 넘김 대신 스크롤하면 늘어나는 목록.

자주 묻는 질문

블로그의 모든 글을 한꺼번에 저장하려면 어떻게 하나요?

블로그의 목록 페이지를 열고 사이트맵, '같은 경로', '이 페이지의 링크를 따라가기' 중 하나를 고른 뒤, 후보 목록에서 기사가 아닌 페이지를 빼고 Pro로 1회에 저장합니다. 무료 플랜은 1회에 기사 1개를 저장하고 나머지는 하나씩 추가합니다.

'다음'이나 '이전 글' 링크도 따라가나요?

네. next, '다음', '이전 글' 같은 링크를 인식해 따라가며 후보를 찾습니다. Pro에서는 이어지는 페이지를 전부 1회에 저장할 수도 있습니다.

모든 기사를 PDF로 만들 수 있나요?

'세로로 이은 HTML(인쇄용)'로 저장해 브라우저에서 열고, 인쇄 대화상자에서 PDF로 저장하세요. 인쇄하면 기사마다 새 페이지에서 시작합니다.

저장한 모든 기사를 가로질러 검색하려면 어떻게 하나요?

'목차·검색 기능이 있는 HTML'로 저장하세요. HTML 파일 하나에 목차와, 브라우저에서 오프라인으로 작동하는 검색창이 들어 있습니다.

댓글도 포함되나요?

댓글란은 별도의 작업입니다. 댓글 저장과 분석 가이드를 참고하세요. 이 페이지는 기사 자체를 다룹니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
