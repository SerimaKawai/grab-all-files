매월의 절차

  1. 1페이지의 짧은 목록을 만들어 둡니다. 가격 페이지, 상품 페이지 두세 개, 카탈로그가 링크된 페이지입니다.
  2. 2'페이지를 HTML로 합치기'를 열고 어디서 수집할지 고릅니다(예: '붙여넣은 URL'). 시작 페이지는 매번 같게 유지합니다. 변경 보고서는 같은 사이트의 이전에 완료된 수집과 비교합니다.
  3. 3표도 파일로 받고 싶다면 AI 데이터 옵션에서 출력을 고르고 표를 CSV와 JSON으로 쓰는 설정을 켭니다. 변경 보고서는 별도입니다. 실행이 끝나면 '더 보기'를 열고 '이전 실행과의 변경 보고서 저장'을 고릅니다.
  4. 4수집을 저장합니다. 무료는 1회에 고른 한 페이지를 저장하며, AI 출력과 표 CSV도 그 한 페이지에 대해 작동합니다. Pro는 선택한 모든 페이지를 1회에 저장합니다.
  5. 5변경 보고서와 새 CSV를 엽니다. 새 CSV를 지난달 것 옆에 시트로 복사해 차이를 메모합니다.
  6. 6저장한 파일 이름에 월이 들어가도록 직접 바꿔 달별로 구별합니다. 확장 프로그램은 이름에 날짜를 넣지 않습니다. 이름이 같은 파일은 덮어쓰지 않고 자동으로 번호가 붙습니다.

하지 않는 일

  • –일정에 따라 저절로 실행하거나, 가격이 바뀌면 알려 주는 것.
  • –캔버스에만 그려졌거나, 로그인하지 않은 상태에서 로그인 뒤에 불러오는 가격을 읽는 것.
  • –경쟁사의 변경이 중요한지 판단하는 것.
  • –약관이 금지하는 사이트에서 수집하는 것. 사이트별 약관을 확인하고 빈도를 낮게 유지하세요.

잘못되기 쉬운 몇 가지

지역이나 플랜을 고른 뒤에야 가격이 표시되는 경우에는 먼저 브라우저에서 그것을 고르세요. 페이지는 브라우저에 표시된 그대로 저장됩니다. 표가 스크립트로 만들어진다면 표가 나타날 때까지 기다린 뒤 저장하세요.

시작 페이지가 달마다 바뀌면 변경 보고서가 비교할 만한 기준이 없습니다. 시작 페이지와 수집 방법을 같게 유지하세요.

관련 가이드

  • 웹 표를 CSV로 활용페이지의 표를 CSV나 JSON으로 바꾸기.
  • 개정 전후 자료 비교변경 보고서가 두 수집을 비교하는 방법.
  • 출처 URL·날짜와 함께 저장어느 저장 형태가 출처 URL과 날짜를 남기는지.

자주 묻는 질문

경쟁사 가격을 매주 자동으로 확인해 줄 수 있나요?

아니요. Grab All Files에는 스케줄러가 없습니다. 수집은 매번 직접 시작합니다. 여기서 소개한 절차는 직접 반복하는 것입니다.

이번 달과 지난달을 어떻게 비교하나요?

변경 보고서가 수집을 같은 사이트의 이전에 완료된 수집과 URL, 제목, 본문 텍스트로 비교합니다. 표는 매달의 CSV를 보관해 스프레드시트에서 비교하세요.

가격표를 CSV로 받을 수 있나요?

네. AI 데이터 옵션에 표를 CSV와 JSON으로도 쓰는 설정이 있으며, 무료에서도 한 페이지에 대해 작동합니다. 이상하게 만들어진 표는 깔끔하게 나오지 않을 수 있으므로 직접 쓰는 페이지에서 결과를 확인하세요.

경쟁사의 페이지를 저장해도 되나요?

사이트의 이용 약관과 사본을 쓰는 방식에 따라 다릅니다. 약관을 읽고, 필요한 것만 수집하고, 내용을 다시 게시하지 마세요.

저장한 페이지에 어디서 언제 수집했는지 표시되나요?

저장 형태에 따라 다릅니다. '원래 모양 그대로'와 목차·검색 형태에서는 각 페이지 제목 아래에 원래 URL과 수집 시각이 표시됩니다. 페이지별 HTML(ZIP)에서는 각 HTML 맨 위의 주석에, 세로로 이은 HTML에서는 HTML 주석에 들어 있습니다. '읽기 쉽게 정리'에서는 출처 URL 줄이 표시되지 않으며, 수집 정보와 실패 목록 옵션을 켰을 때만 문서 맨 위에 수집 시각이 나타납니다.
