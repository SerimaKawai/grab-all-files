자주 묻는 질문

무료 플랜에서도 “원래 모양 그대로”를 사용할 수 있나요?

네. 보기 옵션은 플랜에 따른 제한이 없습니다. 무료 플랜은 1회 실행에 한 페이지를 저장하므로 원하는 페이지 하나를 원래 디자인 그대로 HTML 파일 하나로 보관할 수 있습니다. 여러 페이지를 공용 목차가 있는 파일 하나로 합치려면 Pro($19.99, 1회 결제, 최대 3대 기기)가 필요합니다.

“다른 이름으로 저장”이나 한 페이지씩 저장하는 도구와는 무엇이 다른가요?

“다른 이름으로 저장”은 HTML 옆에 파일 폴더가 생기고, 한 페이지 저장 도구는 페이지마다 파일이 하나씩 만들어집니다. Grab All Files는 여러 페이지를 파일 하나에 담고 각 페이지를 독립된 프레임에 넣어 페이지 간 디자인이 충돌하지 않습니다. 공용 스타일시트, 이미지, 글꼴은 한 번만 저장되고, 저장된 페이지 사이의 링크는 파일 안에서 이동하며, 모든 페이지를 한 번에 검색할 수 있습니다.

메뉴, 탭, 슬라이더는 그대로 작동하나요?

안전을 위해 사이트의 스크립트는 제거되므로 지도, 검색 양식, 로그인, 필요할 때 불러오는 동영상 플레이어처럼 스크립트가 필요한 기능은 작동하지 않습니다. 자주 쓰는 요소는 사이트 스크립트 없이도 작동하도록 처리했습니다. 표준 접근성 마크업이나 Bootstrap으로 만든 탭과 아코디언은 열고 닫을 수 있고, 캐러셀 화살표(Swiper, Slick, Splide, Glide, Flickity)는 한 장씩 넘어갑니다. 양식은 전송되지 않습니다.

스크롤해야만 나타나는 이미지도 포함되나요?

네. 웹페이지는 각 페이지를 탭에서 열고 끝까지 스크롤한 뒤 저장하므로, 지연 로딩 이미지와 스크롤하면 콘텐츠가 더 추가되는 페이지도 포함됩니다. 스크롤은 페이지가 더 이상 길어지지 않거나 “스크롤 시간”에 설정한 시간(45초, 90초, 180초)이 끝나면 멈춥니다. 고정 헤더, 쿠키 안내, 스크롤 시 고정되는 제목도 저장한 파일에서 원래 위치에 나타납니다.

저장한 파일을 열고 공유해도 안전한가요?

원래 사이트의 스크립트는 제거됩니다. 탭, 패널, 슬라이드 화살표를 움직이는 Grab All Files의 작은 보조 스크립트만 남으며, 열 때 인터넷으로 나가는 요청도 차단되므로 다른 사이트의 추적기나 광고를 불러오지 않습니다. 링크에 들어 있는 로그인 정보도 제거됩니다. 페이지는 사용자의 브라우저에서 수집되어 기기에 저장되며, 내용이 저희 서버로 전송되지 않습니다. 공유하기 전에 저장한 페이지를 공유해도 되는지 확인하세요.

“읽기 쉽게 정리”는 언제 선택하나요?

디자인보다 텍스트가 중요할 때 선택하세요. 긴 자료를 읽거나, 인쇄하거나, 파일을 작게 만들거나, AI 도구용 Markdown과 데이터를 준비할 때입니다. 사이트의 헤더, 메뉴, 푸터 없이 모든 페이지를 하나의 깔끔한 스타일로 보여 줍니다. “원래 모양 그대로”는 페이지를 보이던 모습 그대로 보관하고 공유하기 위한 옵션입니다.

로그인이 필요한 페이지는 어떻게 되나요?

수집은 브라우저의 로그인 상태를 그대로 사용하며 인증 정보를 수집하지 않습니다. “로그인 필요”로 표시되면 “사이트를 열어 로그인”을 누르고 열린 탭에서 로그인한 뒤 “재개”를 누르세요. 계속 로그인이 필요한 페이지는 저장되지 않으며, 남은 페이지 수가 결과에 표시됩니다.
