제품 카탈로그·데이터시트

비교할 제품의 카탈로그, 사양 PDF와 데이터시트를 참고 자료 세트로 모읍니다.

IR·실적 보고서 PDF

한 기업의 실적 발표 자료, 설명 자료와 연차 보고서를 출처를 확인할 수 있는 읽기 자료로 모읍니다.

입찰·공모 서류

하나의 입찰·공모 건에 대한 공고, 사양서, 양식과 공개된 질문·답변을 검토용 자료 세트로 준비합니다.

파일 링크를 CSV로

선택한 파일의 URL, 파일명, 제목, 종류와 확인 가능한 메타데이터를 재사용 가능한 목록으로 내보냅니다.

SDS·기술 자료

정확한 제품에 대한 공급업체 자료를 선택하고 SDS, TDS와 관련 기술 PDF를 구분해 관리합니다.

arXiv PDF·연구 파일

arXiv 검색 결과를 스캔하고 PDF를 골라 제목, 폴더, ZIP, 파일 목록 CSV로 저장하세요. 실제 확장 화면과 사용 흐름을 소개합니다.

웹 표를 CSV로 활용

지원되는 웹 표를 CSV로 내보내고 열과 단위를 확인한 후 Excel에 가져오거나 외부 AI에 선택한 파일을 전달하는 방법입니다.

개정 전후 자료 비교

전후 자료를 따로 저장하고 이전 수집과의 변경 보고서로 대상 페이지를 확인합니다. 원문이나 외부 AI·비교 도구로 절차와 조건의 변화를 확인하세요.

PDF 제목 저장·종류별 정리

가져오거나 편집한 제목으로 PDF를 저장하고 파일 형식·출처별로 정리합니다. 원래 파일명과의 선택 및 저장 결과 확인 방법을 안내합니다.

공공기관 자료 세트

공공 제도 안내, 신청 요령과 연결된 PDF·Word를 필요한 단위로 모읍니다. HTML·ZIP·출처 목록을 정리해 다시 확인할 자료 세트를 준비하세요.

웹 자료를 Markdown으로

웹 본문을 하나의 Markdown, 페이지별 노트 또는 전체 패키지로 내보냅니다. 출처를 남기고 조사·글쓰기·노트나 외부 AI에 수동으로 재사용하세요.

업무 매뉴얼·지식 페이지 저장

열람·저장이 허용된 업무 매뉴얼과 지식 문서를 읽기 쉬운 자료집으로 정리합니다. 장별 HTML, 삽입 PDF, 메뉴형 기사를 저장하고 외부 AI 질문을 준비하세요.

정보 수집·읽기·AI 분석

웹정보를 읽기 쉬운 HTML로 모으거나 출처가 있는 파일로 내보내 외부 AI에서 요약·비교·조건 추출하는 방법과 질문 예시를 안내합니다.

페이지를 HTML로 합치기

Free는 관련 후보를 찾아 선택한 1페이지를 저장합니다. Pro는 선택한 여러 페이지 본문을 공통 목차가 있는 검색·인쇄 가능한 하나의 HTML로 결합합니다.

모든 PDF 다운로드

Chrome, Edge, Firefox에서 페이지 또는 해당 폴더에 연결된 PDF를 다운로드합니다. 결과를 필터링하고 무료로 실행당 최대 10개 파일을 저장하거나 PDF를 로컬에서 병합하세요.

이미지 일괄 다운로드

표시 이미지, 지연 로딩, 배경 이미지, blob 이미지를 감지해 선택 이미지를 저장하거나 URL을 CSV로 내보냅니다.

페이지 파일 다운로드

문서, 이미지, ZIP, CSV, 숨겨진 파일 응답을 찾고 필터링, 다운로드, ZIP, PDF 병합, CSV 내보내기를 지원합니다.

사내 포털 및 LMS

기존 브라우저 세션을 사용해 인트라넷, LMS, 회원 영역, 문서 대시보드의 허가된 파일을 수집합니다.

PDF 로컬 병합

웹페이지에서 감지한 PDF를 선택해 서버 업로드 없이 브라우저에서 하나로 병합합니다.

브라우저에서 Grab All Files를 사용해 보세요.

Free는 실행당 파일을 최대 10개 저장하고 관련 후보 중 정확히 1페이지를 HTML로 저장합니다. 그 페이지의 이미지에는 플랜상 개수 제한이 없으며, 직접 연결된 파일은 실행당 최대 10개까지 저장되며 결과 화면의 ‘다음 10건 저장’으로 나머지를 저장할 수 있습니다. Pro($19.99, 1회 결제)는 파일 제한을 없애고 선택한 여러 페이지 본문을 하나의 HTML로 결합합니다.
