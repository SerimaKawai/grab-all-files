하려는 작업에 맞는 가이드를 고르세요. 각 가이드에서 실제 단계, 확장 프로그램에 표시되는 이름, 무료 플랜의 범위(다운로드당 10개, 수집당 1페이지)를 안내합니다.

파일 일괄 다운로드 21

제품 카탈로그·데이터시트

비교하는 제품의 카탈로그, 사양서, 데이터시트를 모델명을 알 수 있는 이름으로 원본 링크와 함께 저장합니다. 무료로는 한 번에 10개까지 받을 수 있습니다.

IR·실적 보고서 PDF

한 기업의 실적 발표 자료, 설명 자료, 연차 보고서를 회계 기간별로 저장합니다. 제목에 기간을 붙이고 원본 URL도 기록할 수 있고, 한 번에 받는 파일은 무료 플랜에서 10개까지입니다.

입찰·공모 서류

한 건의 입찰·공모 공고, 사양서, 양식, 질의응답을 원래 형식 그대로 저장합니다. 역할을 알 수 있는 이름을 붙여 공식 목록과 맞춰 볼 수 있습니다. 무료 플랜은 한 번에 10개까지 저장합니다.

파일 링크를 CSV로

선택한 파일의 URL, 파일 이름, 제목, 유형, 크기, 날짜, 링크 원본 페이지를 Excel용 CSV로 내보냅니다. 무료 플랜은 한 번에 10행까지 내보냅니다.

SDS·기술 자료

제품별 SDS, TDS, 기술 PDF를 언어와 개정일을 알 수 있는 이름으로 원본 URL과 함께 저장합니다. 무료 플랜에서도 다운로드 한 번에 10개까지 가능합니다.

arXiv PDF·연구 파일

arXiv 검색 결과를 스캔하고 PDF를 골라 제목, 폴더, ZIP, 파일 목록 CSV로 저장하세요. 실제 확장 프로그램 화면과 사용 흐름을 소개합니다.

PDF 파일 이름 변경·정리

PDF를 실제 제목으로 파일 이름을 바꾼 뒤 저장하고 유형별·사이트별 폴더로 정리합니다. 제목은 직접 고칠 수 있고, 무료 플랜의 저장 한도는 다운로드당 10개입니다.

정부·공공기관 문서

정부·공공기관의 제도 안내 페이지는 HTML로, 첨부 PDF·Word는 파일로 저장하고 출처도 기록합니다. 무료 플랜은 한 번에 1페이지, 파일은 다운로드당 10개까지입니다.

모든 PDF 다운로드

Chrome, Edge, Firefox에서 페이지 또는 해당 폴더에 연결된 PDF를 다운로드합니다. 결과를 필터링하고 무료로 다운로드당 최대 10개 파일을 저장하거나 PDF를 로컬에서 병합하세요.

이미지 일괄 다운로드

표시 이미지, 지연 로딩, 배경 이미지, blob 이미지를 감지해 선택 이미지를 저장하거나 URL을 CSV로 내보냅니다.

페이지 파일 다운로드

웹페이지의 PDF, Office 문서, 이미지, ZIP, CSV를 찾아 목록을 필터링하고 한 번에 또는 ZIP으로 저장합니다. 무료 플랜은 다운로드당 10개까지 저장합니다.

사내 포털 및 LMS

인트라넷, LMS, 회원 영역에서 로그인된 브라우저 세션으로 권한 있는 파일을 저장합니다. 인증 정보는 수집하지 않고 파일은 기기로 바로 저장됩니다.

PDF 로컬 병합

웹페이지에서 찾은 PDF를 업로드 없이 브라우저 안에서 하나로 병합합니다. 드래그로 순서를 정하고 이름을 지정할 수 있으며, 무료 플랜은 병합당 10개까지입니다.

Bulk download Word, Excel, PowerPoint

Find every Word, Excel and PowerPoint file linked on a page, filter by Documents, Spreadsheets or Presentations, and save them. Free: 10 files per download.

Follow “Next” links and collect

A list split over page 1, 2, 3...? Grab All Files can follow “Next” for files (Pro) and for page collection (Free finds candidates, Pro saves them all at once).

Download many files as one ZIP

Select files on a page and press ZIP to get one archive. Free: 10 files. A confirmation appears above 200 MB, and 256 MB is the limit. It does not split archives.

Download linked video and audio files

Save video and audio that a page links to as plain files (mp4, mp3 and more). Streaming such as HLS and DASH, video sites and DRM are not saved. Free and Pro.

Insurance policy documents

Collect policy terms, brochures, key-information documents and revision notices from insurers' product pages, name them by product, and keep your own record of versions.

Law, case and patent PDFs

Select PDFs from the result pages of a public statute, case-law or patent database, name them by title and list sources. For large sets, use the provider's bulk download.

Course materials and syllabi

Save the lecture slides, handouts and syllabi of courses you are enrolled in, from a learning-management page or a teacher's site, into one folder per course.

Property and drawing PDFs

Save property outlines, floor plans, specification sheets and disclosure PDFs and images from pages you have the right to use, sorted by site and type, with a CSV list.

지원되는 웹 표를 CSV로 내보내고 열과 단위를 확인한 후 Excel에 가져오거나 외부 AI에 선택한 파일을 전달하는 방법입니다.

개정 전후 자료 비교

전후 자료를 따로 저장하고 이전 수집과의 변경 보고서로 대상 페이지를 확인합니다. 원문을 나란히 읽거나 외부 AI·비교 도구에 넘겨 절차와 조건이 어떻게 달라졌는지 살펴봅니다.

웹 자료를 Markdown으로

웹 본문을 하나의 Markdown, 페이지별 노트 또는 전체 패키지로 내보냅니다. 출처를 남기고 조사·글쓰기·노트나 외부 AI에 수동으로 재사용하세요.

업무 매뉴얼·지식 페이지 저장

열람·저장이 허용된 업무 매뉴얼과 지식 문서를 읽기 쉬운 자료집으로 정리합니다. 장별 HTML, 삽입 PDF, 메뉴형 기사를 저장하고 외부 AI 질문을 준비하세요.

정보 수집·읽기·AI 분석

웹정보를 읽기 쉬운 HTML로 모으거나 출처가 있는 파일로 내보내 외부 AI에서 요약·비교·조건 추출하는 방법과 질문 예시를 안내합니다.

댓글 일괄 저장·분석

YouTube·X(구 트위터)·Reddit·Bluesky·Yahoo! 뉴스(일본)의 댓글을 끝까지 불러와 접힌 답글까지 HTML 파일 하나에 저장하고, AI로 분석해 보세요. 무료 플랜 지원.

페이지를 HTML로 합치기

무료 플랜은 관련 후보를 찾아 선택한 1페이지를 저장합니다. Pro는 선택한 여러 페이지 본문을 공통 목차가 있는 검색·인쇄 가능한 하나의 HTML로 결합합니다.

컴퓨터의 HTML을 하나로

컴퓨터 폴더나 ZIP 속 여러 HTML 파일을 목차가 있는 HTML 하나로 합칩니다. 이미지는 포함되고 페이지 간 링크도 유지됩니다. 업로드하지 않습니다.

원래 디자인 그대로 저장

한 페이지든 여러 페이지를 합친 것이든 원래 레이아웃, 글꼴, 이미지 그대로 오프라인용 HTML 파일 하나에 저장합니다. 스크립트는 제거되고 아무것도 업로드되지 않습니다.
