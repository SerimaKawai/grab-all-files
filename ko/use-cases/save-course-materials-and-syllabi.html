수강 중인 강의의 자료를 강의마다 저장 위치를 나누어 저장하세요.

한 학기에는 슬라이드, 유인물, 읽기 자료, 강의계획서가 수십 개씩 생기고, 학습 관리 시스템, 교수 개인 사이트, 몇몇 학습 사이트에 흩어져 있습니다. Grab All Files는 열려 있는 페이지의 파일을 목록으로 보여 주고, 고른 것을 저장합니다. 본인이 받을 자격이 있는 자료를 본인 학습을 위해서만 사용하고, 자료를 제공하는 쪽이 허용하는 범위를 따르세요.

세 가지 장소, 세 가지 방법

학습 관리 시스템

같은 브라우저에서 본인 계정으로 로그인하고, 강의 페이지를 열어 스캔합니다. 로그인된 상태를 사용하며 비밀번호를 읽거나 전송하지 않습니다. 포털 전반에 대한 자세한 내용은 사내 포털 가이드에 있습니다.

교수 개인 사이트

대개 PDF와 슬라이드 링크가 나열된 단순한 페이지입니다. 강의 페이지에서 시작하세요. 깊이 설정은 그 페이지에서 링크를 따라가며, 시작한 페이지의 폴더 안에서만 따라갑니다.

학습·튜토리얼 사이트

유인물, 문제집, 풀이가 있는 페이지. 페이지에서 링크된 파일을 스캔하세요. 페이지가 길다면 무료에서는 스캔하기 전에 스크롤하세요.

순서

  1. 1필요하다면 브라우저에서 학습 관리 시스템에 로그인하고 강의 페이지를 엽니다.
  2. 2Grab All Files를 열고 '파일 일괄 다운로드'로 스캔합니다. 목록을 프레젠테이션, 문서, PDF로 좁힙니다.
  3. 3파일 이름을 PDF의 제목으로 하거나 원래 이름을 유지합니다. 폴더 정리는 유형별이나 도메인별뿐이므로, 강의마다 저장 폴더를 직접 만들어 저장할 때 선택하세요.
  4. 4저장합니다. 무료는 1회 저장에 최대 10개이므로 한 주 분량씩 저장하세요. Pro는 선택한 전체를 한 번에 저장합니다.
  5. 5저장 도중 세션이 끝나면 행에 로그아웃되었다고 표시됩니다. 다시 로그인하고 실패한 것을 다시 시도하세요. 저장된 파일은 그대로 남습니다.

페이지로 된 강의계획서

강의계획서는 파일이 아니라 웹 페이지인 경우가 많습니다. 보관하고 싶다면 '페이지를 HTML로 합치기'로 그 페이지를 HTML로 저장하세요. 메모 앱에서 읽고 싶다면 Markdown으로 저장합니다. 무료는 1회에 후보 목록에서 고른 한 페이지를 저장하고, Pro는 여러 페이지를 1회에 저장합니다.

자주 묻는 질문

학교 학습 시스템의 강의 슬라이드를 저장할 수 있나요?

네, 브라우저에서 강의 페이지를 열 수 있다면 가능합니다. 로그인한 계정을 사용합니다.

로그인이나 유료 장벽을 넘을 수 있나요?

아니요. 대신 로그인하지 않고, CAPTCHA를 깨지 않으며, 이미 볼 수 없는 페이지를 열지도 않습니다.

대학 웹사이트 전체를 훑을 수 있나요?

가능합니다. 깊이에는 무제한 설정이 있고 스캔은 최대 100,000페이지까지 읽습니다. 하지만 그것이 원하는 경우는 드뭅니다. 강의 페이지에서 시작해 작은 깊이를 쓰세요. 어차피 스캔은 시작 페이지의 폴더 안에 머뭅니다.

무료로 파일을 몇 개까지 저장할 수 있나요?

1회 저장에 선택한 파일 최대 10개입니다. 다음 파일을 선택해 다시 저장하세요. Pro는 저장당 제한이 없습니다.

동영상 강의도 저장할 수 있나요?

mp4처럼 일반 파일로 링크된 동영상만 가능합니다. 페이지의 뷰어에서 영상이 재생되는 스트리밍 강의는 저장하지 않습니다.

강의마다 폴더를 하나씩 만들어 주나요?

아니요. 저장 위치는 매번 직접 고르므로 강의마다 폴더를 직접 만드세요. 내장된 폴더 정리는 유형별이나 도메인별뿐이며, 강의 이름으로 폴더를 짓는 옵션은 없습니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
