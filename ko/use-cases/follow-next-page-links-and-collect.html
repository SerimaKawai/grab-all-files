이 페이지의 링크에서 후보 수집하기

페이지를 찾는 방법으로 '이 페이지의 링크를 따라가기'를 고릅니다. 다음 페이지 링크도 다른 링크와 함께 수집되며, 저장하기 전에 후보 목록을 확인할 수 있습니다.

모든 페이지의 파일 수집하기(Pro)

  1. 1목록의 첫 페이지를 열고 Grab All Files의 '파일 일괄 다운로드'를 엽니다.
  2. 2'끝까지 스크롤해서 불러오기'를 켜고 '모든 페이지 스캔'을 누릅니다.
  3. 3'스크롤 시간'으로 어디까지 갈지 고릅니다(6, 20, 100페이지. 고르지 않으면 철저히, 100페이지). 설정은 무한 스크롤 가이드에서 설명합니다.
  4. 4100페이지에 도달했는데 목록이 이어진다면 '다음 100페이지 읽기'를 누릅니다.
  5. 5합쳐진 목록을 유형별로 거른 뒤 저장합니다.

무료에서는 스캔하기 전에 긴 목록의 끝까지 직접 스크롤하고, 목록의 각 페이지를 차례로 직접 엽니다.

모든 페이지의 페이지 수집하기

  1. 1목록의 첫 페이지를 연 뒤 '페이지를 HTML로 합치기'를 엽니다.
  2. 2'이 페이지의 링크를 따라가기'를 고르고 후보를 찾게 합니다. '다음' 페이지는 무료와 Pro 모두 후보 목록에 들어갑니다.
  3. 3목록을 확인하고 필요 없는 것은 뺍니다.
  4. 4Pro: 페이지를 선택하고 모양과 저장 형태를 고른 뒤 1회에 저장합니다. 무료: 페이지 하나를 골라 저장하고, 다음 페이지는 같은 저장 파일에 추가합니다.

잘 되는 경우

  • ✓문서 자료실이나 블로그의 지난 글처럼 단순한 '다음'이나 '이전 글' 링크가 있는 아카이브.
  • ✓목록의 모든 페이지에 있는 파일을 한 세트로 받아야 할 때.
  • ✓로그인한 뒤에만 표시되는 페이지. 브라우저의 세션을 사용합니다.

확인하거나 다른 방법을 고를 경우

  • –'다음' 링크가 아니라 스크롤로 더 불러오는 목록: 무한 스크롤 가이드를 참고하세요.
  • –도중에 세션이 만료되는 목록: 로그인 가이드를 참고하세요.
  • –매우 큰 아카이브. 수천 페이지를 넘으면 PC용 웹사이트 복사 프로그램이 더 알맞습니다.

자주 묻는 질문

'다음'을 스스로 클릭해서 모든 페이지를 훑어 주나요?

네. 파일은 Pro가 '모든 페이지 스캔'으로 합니다. 페이지는 무료와 Pro 모두 '다음'을 따라가 후보 목록을 만들고, Pro는 그것을 1회에 모두 저장할 수 있습니다.

파일을 수집할 때 무료도 '다음'을 따라가나요?

아니요. 무료의 파일 스캔은 화면에 있는 것을 읽습니다. 긴 목록은 끝까지 직접 스크롤한 뒤, 목록의 각 페이지를 차례로 스캔하세요.

'모든 페이지 스캔'은 몇 페이지까지 따라가나요?

'스크롤 시간'에 따라 6, 20, 100페이지이며, 고르지 않았다면 100페이지입니다. 그 이상은 '다음 100페이지 읽기'를 누르세요. 설정은 무한 스크롤 가이드를 참고하세요.

무료로 몇 페이지까지 저장할 수 있나요?

30페이지짜리 목록이라도 후보는 모두 찾지만, 저장은 1회에 한 페이지입니다. 같은 저장 파일에 하나씩 추가하세요. Pro는 선택한 30페이지를 1회에 저장합니다.

다음 페이지가 링크가 아니라 스크롤로 불러와지면요?

다른 경우입니다. 무한 스크롤 페이지 가이드를 참고하세요.
