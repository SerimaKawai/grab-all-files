작업 흐름

  1. 1Chrome, Edge 또는 Firefox에서 페이지를 열고 툴바의 Grab All Files 아이콘을 누릅니다. 지금 열려 있는 페이지의 파일 목록이 만들어집니다.
  2. 2“스캔”을 누릅니다. 링크된 페이지까지 포함하려면 먼저 “깊이”를 올립니다(“이 페이지만”은 이 페이지만 확인). 링크는 시작 페이지의 폴더 안에서만 따라갑니다.
  3. 3파일 유형 목록, 파일 이름·제목 검색창, “상세 설정”(최소 크기, “저장 이름”)으로 목록을 좁히고 원하는 파일을 체크합니다.
  4. 4“선택한 파일 저장”을 누릅니다. ZIP, “PDF 병합”, “정리”, “파일 정보 CSV 내보내기”는 “기타 작업”에 있습니다. 무료 버전은 다운로드당 10개까지 저장합니다.
  5. 5목록이 길면 다음 파일을 선택하고 “선택한 파일 저장”을 다시 누릅니다. 실패한 행에는 이유가 표시되므로 접근 문제를 해결한 뒤 다시 시도하세요.

자주 묻는 질문

어떤 파일 형식을 지원하나요?

PDF, Office 문서, 이미지, ZIP, CSV 등 브라우저가 접근 가능한 다운로드 응답을 감지할 수 있습니다. 분할 / 멀티볼륨 아카이브 세트(.001, .r00, .z01 등)도 감지합니다.

일부 파일만 선택할 수 있나요?

예. 유형, 이름, 제목, 크기로 필터링하고 원하는 열로 정렬한 뒤 필요한 행만 체크하면 됩니다. 저장 버튼을 누르기 전에는 아무것도 저장되지 않습니다.

무료 버전에 제한이 있나요?

무료 버전은 다운로드당 선택한 파일을 최대 10개까지 저장하며, ZIP, “PDF 병합”, CSV 내보내기에도 같은 제한이 적용됩니다. 계속하려면 다음 파일을 선택하고 같은 버튼을 다시 누르세요. 잠기는 기능은 없습니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없습니다.

아무것도 찾지 못했거나 예상보다 적어요. 어떻게 하나요?

스크롤할 때 내용이 더 불러와지는 페이지는 “스캔 설정”에서 “스캔 전에 스크롤해 모두 불러오기(갤러리, 긴 목록)”를 켜고 다시 스캔하세요. 파일이 링크된 페이지에 있다면 “깊이”를 올립니다. 해당 사이트에서는 광고 차단기를 잠시 끄세요. 페이지의 JavaScript가 다운로드를 시작하는 경우에는 표시되는 “액티브 캡처”를 사용합니다.

로그인이 필요한 페이지는 어떻게 하나요?

먼저 같은 브라우저에서 사이트에 로그인한 뒤 스캔합니다. Grab All Files는 이미 있는 로그인 세션을 사용하며, 깊이 1 이상에서는 링크된 페이지도 같은 로그인 상태로 엽니다. 대신 로그인하거나 접근 제한을 우회하지는 않습니다. “로그인이 필요합니다”로 표시된 행은 다시 로그인한 뒤 재시도하세요.

오래된 HTTP 페이지도 작동하나요?

예. 브라우저에서 열 수 있는 HTTP/HTTPS 페이지를 스캔합니다.
