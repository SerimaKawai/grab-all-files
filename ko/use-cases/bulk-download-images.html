작업 흐름

  1. 1갤러리나 페이지를 열고 툴바의 Grab All Files 아이콘을 누릅니다.
  2. 2갤러리와 무한 스크롤 페이지는 Pro라면 끝까지 자동으로 스크롤해 불러옵니다. 시간이 더 필요하면 “스캔 설정”에서 “스크롤 시간”(일반 45초, 길게 90초, 철저히 180초)을 고릅니다. 무료 버전은 먼저 직접 끝까지 스크롤합니다. 그런 다음 “스캔”을 누릅니다.
  3. 3JPG, PNG, WebP, GIF, SVG 같은 이미지로 목록을 필터링합니다. “상세 설정”에서 최소 “크기”를 정하면 썸네일과 아이콘을 숨길 수 있습니다.
  4. 4이미지를 체크하고 “선택한 파일 저장”을 누릅니다(무료: 다운로드당 10개). ZIP, 유형별·도메인별 “정리”, “파일 정보 CSV 내보내기”는 “기타 작업”에 있습니다.

자주 묻는 질문

지연 로딩 이미지도 감지하나요?

예, 페이지에 들어와 있다면 감지합니다. 이미지 속성, srcset 값, CSS 배경, blob URL, 네트워크 응답을 확인합니다. 스크롤해야 나타나는 이미지는 Pro라면 자동으로 스크롤해 불러옵니다. 무료 버전에서는 스캔 전에 직접 끝까지 스크롤하세요.

특정 이미지 형식만 다운로드할 수 있나요?

예. 파일 유형 목록, 이름 검색창, “상세 설정”의 최소 “크기”를 사용하고, 크기순으로 정렬하면 원본 크기 파일을 찾기 쉽습니다.

썸네일이나 작은 아이콘까지 목록에 나오는 이유는요?

많은 페이지가 썸네일, 아이콘, 로고를 별도의 작은 파일로 씁니다. “상세 설정”에서 최소 “크기”를 정하면 숨길 수 있으며, 크기를 알 수 없는 파일은 목록에 남습니다. 크기와 URL을 비교해 원본을 고르세요.

다운로드 대신 이미지 URL만 내보낼 수 있나요?

예. 이미지를 체크하고 “기타 작업”의 “파일 정보 CSV 내보내기”를 사용하세요. 무료 버전은 작업당 10행까지 내보내며, 다음 행을 체크해 다시 내보내면 됩니다.

무료 버전에서 이미지 수 제한이 있나요?

무료 버전은 다운로드나 ZIP 한 번에 선택한 이미지를 최대 10개까지 저장합니다. 다음 이미지를 선택하고 같은 버튼을 다시 누르면 계속할 수 있으며 잠기는 기능은 없습니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없습니다.
