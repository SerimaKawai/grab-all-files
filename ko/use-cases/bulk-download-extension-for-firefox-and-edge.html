사이트 형태 사본이냐 ZIP이냐: 브라우저에 따라 다릅니다

“페이지를 HTML로 합치기”에는 네 가지 저장 형태가 있습니다. 세 가지는 모든 브라우저에서 쓸 수 있고, 이것은 Chrome과 Edge 전용이며 Firefox에서는 ZIP이 보통의 대안입니다.

Firefox로 충분한 경우

  • ✓평소의 다운로드 폴더에 파일을 저장하고, 매번 폴더를 고를 필요가 없습니다.
  • ✓폴더에 사이트 형태로 저장하는 사본 대신 페이지별 HTML의 ZIP이면 됩니다.
  • ✓원하는 파일이 페이지에 직접 링크되어 있어, 스크립트가 시작하는 다운로드를 가로채지 않아도 스캔이 찾아냅니다.

Chrome이나 Edge가 더 맞는 경우

  • –예를 들어 드라이브의 공유 폴더처럼 폴더를 직접 고르고 싶습니다.
  • –링크를 클릭하며 둘러볼 수 있도록 사이트 자체의 폴더 구조를 디스크에 기록하고 싶습니다.
  • –파일로 가는 일반 링크 없이 JavaScript를 실행하는 버튼이 다운로드를 시작합니다.

자주 묻는 질문

Grab All Files는 Firefox에서 작동하나요?

네, Firefox 128 이상에서 작동합니다. 네 가지가 다릅니다. 저장 폴더를 고를 수 없고, “폴더에 사이트 형태로 저장”을 쓸 수 없고, 액티브 캡처가 제한적이어서 JavaScript가 시작하는 다운로드를 가로채지 못하며, 페이지를 HTML로 합치기가 페이지를 읽는 방식이 다릅니다.

Firefox에서는 파일이 어디에 저장되나요?

다운로드 폴더 안의 GrabAllFiles 폴더입니다. 이 확장 프로그램에서는 Firefox가 저장할 폴더를 고르게 해 주지 않습니다.

어느 Edge 버전을 지원하나요?

Microsoft Edge 추가 기능에서 설치하는 Chromium 111 이상의 Edge입니다. Chrome도 같은 Chromium 버전에서 지원합니다.

라이선스 하나를 몇 대의 기기에서 쓸 수 있나요?

최대 3대입니다. US$19.99를 한 번만 결제하며 구독은 없습니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
