작업 흐름

  1. 1평소처럼 포털에 로그인하고, 접근이 허용된 파일이 있는 페이지를 엽니다.
  2. 2Grab All Files 아이콘을 누르고 “스캔”을 누릅니다. 시작 페이지 폴더 안의 링크된 페이지까지 포함하려면 “깊이”를 올립니다. 링크된 페이지도 현재 로그인 상태로 열립니다.
  3. 3필요한 파일을 필터링해 체크한 뒤 “선택한 파일 저장”을 누르거나 “기타 작업”에서 ZIP, “PDF 병합”, “파일 정보 CSV 내보내기”를 사용합니다. 무료 버전은 다운로드당 10개까지 저장합니다.
  4. 4다음 묶음은 다음 파일을 선택하고 “선택한 파일 저장”을 다시 누릅니다. “로그인이 필요합니다”로 표시된 행은 세션이 끝났다는 뜻이므로 다시 로그인한 뒤 재시도하세요.

자주 묻는 질문

비밀번호를 수집하나요?

아니요. 기존 브라우저 세션을 사용하며 인증 정보를 수집하지 않습니다.

접근 제어를 우회하나요?

아니요. 브라우저가 이미 접근 가능한 페이지와 파일만 대상입니다.

기밀 파일에 적합한가요?

파일은 포털에서 기기로 직접 다운로드되며 당사 서버를 거치지 않고, 스캔도 브라우저 안에서 이루어집니다. 다운로드 자동화를 사용하기 전에 조직의 규칙을 확인하세요.

무료로 몇 개까지 다운로드할 수 있나요?

무료 버전은 다운로드, ZIP, 병합 모두 작업당 선택한 파일을 최대 10개까지 처리합니다. 계속하려면 다음 파일을 선택하고 “선택한 파일 저장”을 다시 누르세요. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없습니다.

스캔 중에 세션이 만료되면요?

같은 브라우저에서 다시 로그인한 뒤 다시 스캔하거나 실패한 행을 재시도하세요. 저장된 파일이 로그인 페이지라면 그때 이미 세션이 끝난 것입니다. 로그아웃이 잦은 포털에서는 “스캔 설정”의 “세션 보호 모드”를 켜면 세션을 끊을 수 있는 후속 확인(크기, 날짜, 유형)을 건너뜁니다.

버튼이나 뷰어 뒤에 있는 파일도 가져올 수 있나요?

대부분 가능합니다. 뷰어, iframe, 백그라운드 요청의 파일도 감지합니다. 포털 자체의 JavaScript로 다운로드가 시작될 때는 “액티브 캡처”가 페이지에서 각 다운로드를 시작하게 해 파일을 함께 저장할 수 있습니다.
