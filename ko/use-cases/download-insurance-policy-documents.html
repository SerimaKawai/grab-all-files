한 상품에서 보통 모으는 문서

약관

전체 조건이 담긴 긴 PDF. 보통약관과 특별약관으로 나뉘어 각각 별도의 파일인 경우도 있습니다.

팸플릿

판매용 리플릿. 상품에 하나만 있거나, 플랜이나 특약마다 따로 있기도 합니다.

중요사항 설명서

중요한 사항을 설명하는 문서. 보험사에 따라 판매 채널이나 연령대별로 파일을 하나씩 공개하기도 합니다.

계약 개요

보험사가 공개하는 경우의 계약 요약 시트.

개정 안내

날짜가 붙은 변경 사항의 목록이나 페이지. PDF 또는 일반 웹 페이지로 게시됩니다.

신청서와 안내서

같은 상품 페이지에서 링크된 보험금 청구서, 주소 변경 서식, 절차 안내서.

확장 프로그램은 파일을 저장합니다. PDF가 약관의 어느 판인지는 알지 못합니다. 그 정보는 파일 이름이나 직접 만든 시트에 남겨 두세요.

순서

  1. 1보험사의 상품 페이지나 한 상품의 문서가 나열된 페이지를 엽니다. PDF 목록을 보려면 먼저 검색해야 한다면, 검색을 실행하고 결과 페이지를 엽니다.
  2. 2Grab All Files를 열고 “파일 일괄 다운로드”를 씁니다. 페이지를 스캔합니다. 파일이 모두 그 한 페이지에 있다면 “이 페이지만”을 그대로 두고, PDF가 거기서 링크된 페이지에 있다면 “깊이 1”을 고릅니다.
  3. 3목록에서 유형을 PDF로 좁히고 제목과 크기를 확인합니다. 다른 상품의 서식처럼 필요 없는 것은 뺍니다.
  4. 4파일 이름을 PDF의 제목으로 정하고(선택한 PDF의 제목을 가져오는 버튼이 있습니다) 폴더를 나누는 방법을 고릅니다. 선택한 파일을 저장합니다.
  5. 5파일 정보 CSV 버튼을 누릅니다. 스프레드시트로 열어 판과 개정일을 위한 열을 직접 추가합니다.

  • ✓해 줌: 체크한 파일을 PDF 제목을 파일 이름으로, 유형별 또는 도메인별 폴더로 저장합니다.
  • ✓내가 함: 상품 이름, 판, 개정일. 파일 이름이나 시트에 추가하세요.
  • ✓내가 함: 어느 판이 계약에 적용되는지, 상품이 고객에게 맞는지 판단하는 일.

  • ✓불가능: 내게 없는 로그인이 필요한 페이지, 그리고 두 PDF 안의 텍스트를 비교하는 일.

개정 비교하기

두 판을 비교하는 가장 간단한 방법은 두 PDF를 같은 상품 폴더에 판이나 날짜를 이름에 넣어 보관하고, 나란히 열어 보는 것입니다. 파일 정보 CSV의 “수정일” 열은 서버가 그 파일에 대해 알려 주는 날짜입니다. 보험사가 인쇄한 개정일이 아니므로 개정일로 쓰지 마세요.

보험사가 개정 안내를 일반 웹 페이지로 게시한다면, 방문할 때마다 “페이지를 HTML로 합치기”로 그 페이지를 저장할 수 있습니다. 그러면 변경 보고서가 같은 사이트의 최신 수집과 이전에 완료된 수집을 URL, 제목, 본문 텍스트로 비교합니다. 비교하는 것은 웹 페이지이며 PDF의 내용은 아닙니다.

자주 묻는 질문

여러 상품 페이지에서 약관과 팸플릿을 한꺼번에 다운로드할 수 있나요?

한 번에 한 페이지씩 스캔하거나, 시작 페이지에서 “깊이 1”~“깊이 5”로 링크를 따라갑니다. 목록에는 찾은 모든 PDF가 표시되며 저장할 것은 직접 고릅니다. 무료는 1회 저장이 선택한 10개로 제한되고, Pro는 저장당 제한이 없습니다.

PDF가 약관의 어느 판인지 알려 주나요?

아니요. 파일 정보 CSV에는 파일 이름, 제목, 크기, 서버가 그 파일에 대해 알려 준 날짜, 찾은 페이지가 있습니다. 판과 개정일은 문서를 읽고 직접 적어 두는 것입니다.

보험사가 약관을 개정한 것을 알아채 주나요?

스스로는 하지 않습니다. 안내 페이지나 상품 페이지를 다시 열어 바뀐 부분을 저장하세요. 일반 웹 페이지는 변경 보고서가 같은 사이트의 최신 수집과 이전 수집을 비교합니다.

파일 이름을 상품별로 붙여 주나요?

PDF의 제목을 파일 이름으로 쓰고, 폴더를 유형별이나 도메인별로 나눌 수 있습니다. 제목이나 사이트 이름에 없는 상품 이름은 나중에 이름을 바꾸거나 시트에 직접 추가합니다.

보험 계약과 관련된 정보가 서버로 전송되나요?

아니요. 파일은 보험사 사이트에서 내 컴퓨터로 가고, 작업은 브라우저에서 이루어집니다. 개발자에게 전달되는 것은 라이선스 확인과, 켜 둔 경우의 선택적 사용 통계뿐입니다.
