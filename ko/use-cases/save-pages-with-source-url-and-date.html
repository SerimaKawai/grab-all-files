URL과 시각이 남는 곳

모양과 저장 형태남는 곳파일을 열었을 때 보이는지
'원래 모양 그대로' + 목차·검색 기능이 있는 HTML각 페이지 제목 아래: 링크로 된 원래 URL과 수집 시각네, 화면에 보입니다
'원래 모양 그대로' + 페이지별 HTML(ZIP)각 HTML 파일 맨 위의 주석: url과 저장 날짜아니요. 페이지 소스에서 볼 수 있습니다
'원래 모양 그대로' + 세로로 이은 HTML(인쇄용)제목, URL, 저장 날짜가 담긴 HTML 주석아니요. 페이지 소스에서 볼 수 있습니다
'읽기 쉽게 정리'각 페이지의 원래 URL을 보여 주는 줄은 없습니다. 문서 맨 위의 수집 시각은 기본값이 꺼져 있는 '수집 정보와 실패 목록 넣기'를 켰을 때만 나타납니다그 옵션을 켰을 때만, 그것도 시각만 보입니다

두 가지 모양과 AI용 출력

필요에 따라 고르는 방법

읽거나 인쇄하면서 출처가 보이길 원할 때

'원래 모양 그대로'와 '목차·검색 기능이 있는 HTML'. URL과 시각이 각 제목 아래에 있어서 인쇄물에도 나옵니다.

페이지마다 HTML 파일 하나씩 보관할 때

'원래 모양 그대로'와 '페이지별 HTML(ZIP)'. URL과 날짜는 각 파일 맨 위 주석에 있고, 페이지 목록은 index.html에 있습니다.

나중에 텍스트를 검색하거나 AI 서비스에 넘길 때

AI용 Markdown. 모든 페이지에 source_url과 captured_at이 텍스트로 있고, JSONL과 매니페스트의 모든 항목에도 있습니다.

저장한 파일을 직접 확인하는 방법

  1. 1먼저 쓰려는 모양과 저장 형태로 한두 페이지를 저장합니다.
  2. 2파일을 브라우저에서 엽니다. 목차·검색 형태라면 페이지 제목 아래에서 URL과 시각을 찾습니다.
  3. 3ZIP과 세로로 이은 형태는 브라우저에서 페이지 소스를 보고 맨 위의 주석을 읽거나, 텍스트 편집기로 파일을 엽니다.
  4. 4Markdown은 .md 파일을 열어 각 페이지의 source_url과 captured_at을 찾습니다.
  5. 5URL이나 시각이 없다면 모양이나 저장 형태를 바꾸거나 수집 정보 옵션을 켜고 다시 저장합니다.

알려 주는 것과 알려 주지 않는 것

저장한 페이지에는 읽어 온 주소와 수집한 시각이 기록됩니다. 덕분에 원본을 다시 찾을 수 있고, 오래된 수집본과 새 수집본을 구별할 수 있습니다. 같은 사이트의 수집본을 시간 순서대로 비교한다면 '이전 실행과의 변경 보고서 저장' 버튼이 사이트의 마지막으로 완료된 수집과 새 수집을 URL, 제목, 본문으로 비교한 Markdown 변경 보고서를 만들어 줍니다.

내 컴퓨터의 파일은 다른 파일처럼 편집할 수 있으므로, URL과 시각은 페이지에 붙여 둔 메모이지 봉인이 아닙니다. 이 가이드는 법원, 감사인, 플랫폼이 그런 파일을 어떻게 취급할지는 다루지 않습니다.

자주 묻는 질문

저장한 페이지에 원래 URL이 표시되나요?

'원래 모양 그대로'와 '목차·검색 기능이 있는 HTML'이라면 네, 각 페이지 제목 아래에 수집 시각과 함께 표시됩니다. '읽기 쉽게 정리'에는 페이지별 URL 줄이 없습니다.

페이지별 HTML ZIP에서 URL은 어디에 있나요?

'원래 모양 그대로'를 쓸 때는 각 HTML 파일 맨 위의 주석에 url과 저장 날짜로 들어 있습니다. 페이지에 표시되지는 않습니다.

'읽기 쉽게 정리'에서도 수집 시각을 얻을 수 있나요?

네, '수집 정보와 실패 목록 넣기'를 켜세요. 기본값은 꺼져 있으며, 문서 맨 위에 수집 시각이 추가될 뿐 페이지별 URL 줄은 추가되지 않습니다.

URL과 시각을 기계가 읽을 수 있는 형태로 남기는 출력은 무엇인가요?

AI용 Markdown 출력입니다. 각 페이지에 source_url과 captured_at이 있고, chunks.jsonl과 manifest.json에도 둘 다 있습니다.

인쇄하면 출처도 나오나요?

'원래 모양 그대로'와 '목차·검색 기능이 있는 HTML'이라면 네, URL과 시각이 각 제목 아래에 인쇄됩니다. 세로로 이은 형태에서는 HTML 주석에만 있으므로 인쇄물에는 나오지 않습니다.
