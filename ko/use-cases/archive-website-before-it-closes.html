무엇을 어떤 순서로 저장할까

표의 위에서부터 진행하세요. 시간이 다 되면 거기서 멈춥니다. 앞쪽 항목일수록 대체하기 어려운 경우가 많습니다.

우선순위저장할 것Grab All Files에서의 방법
1이 사이트에만 있는 페이지: 공지, 가격, 절차, 연혁, 연락처“페이지를 HTML로 합치기”, 모양은 “원래 모양 그대로”, 저장 형태는 “폴더에 사이트 형태로 저장”(Chrome, Edge) 또는 “페이지별 HTML(ZIP)”. 각 페이지는 스타일, 폰트, 이미지를 그대로 유지하며, 여러 페이지가 함께 쓰는 파일은 한 번만 저장합니다.
2페이지가 링크한 PDF와 Word, Excel, PowerPoint 파일링크된 파일을 페이지와 함께 저장하는 옵션을 켭니다(무료 1회 10개, Pro 100개). 또는 “파일 일괄 다운로드”에서 깊이 1~5로 유형별로 걸러 ZIP으로 저장합니다.
3그 밖의 모든 것: 지난 뉴스, 태그·아카이브 페이지시간이 남으면 마지막에 합니다. 사이트맵이 있다면 사이트가 나열하는 페이지가 몇 개인지 알 수 있습니다.

저장한 사본이 유지하는 세 가지

그래도 저장할 수 있는 것

  • ✓브라우저에 표시된 그대로의 페이지. JavaScript로 만든 페이지와 로그인 뒤의 페이지도 포함합니다.
  • ✓페이지에서 링크된 PDF, Word, Excel, PowerPoint 파일.
  • ✓mp4나 mp3처럼 페이지가 직접 링크한 동영상과 오디오 파일.
  • ✓실패한 파일: 다시 시도하거나, 실패한 URL 목록을 사유와 함께 내보낼 수 있습니다.

저장할 수 없는 것

  • –HLS나 DASH 스트림, blob: 주소를 쓰는 플레이어 같은 스트리밍 동영상.
  • –서버에 질의하는 검색창과 양식. 저장한 페이지는 네트워크에 연결하지 않습니다.
  • –내 브라우저에서 열 수 없는 페이지, 또는 내게 없는 로그인이 필요한 페이지.
  • –DRM이나 암호화된 뷰어 안의 파일, 캔버스에만 그려진 텍스트.

마지막 한 주의 체크리스트

  • ✓시작 페이지를 적어 둡니다. 홈 페이지, 자료실, 뉴스 아카이브, 연락처 페이지입니다.
  • ✓사이트 일부가 회원 전용이라면 먼저 로그인합니다. 긴 작업 도중 세션이 만료되면 작업이 일시 정지되므로, 다시 로그인한 뒤 “재개”를 누릅니다. 이미 저장한 페이지는 남아 있습니다.
  • ✓링크된 문서의 수는 일찍 세어 둡니다. 링크된 파일은 무료는 1회 10개, Pro는 100개씩 저장되고 나머지는 결과 화면의 버튼으로 이어 가므로, 수백 개 파일이 있는 자료실이라면 여러 번 나누어 해야 합니다.
  • ✓네트워크를 끈 상태에서 저장한 사본을 열어 봅니다. 몇 페이지를 클릭해 보며 저장한 페이지끼리의 링크가 저장된 파일을 여는지 확인합니다.
  • ✓날짜를 남겨 둡니다. “원래 모양 그대로”와 “목차·검색 기능이 있는 HTML”을 쓰면 각 페이지 제목 아래에 출처 URL과 수집 시각이 표시됩니다.

사이트가 수천 페이지일 때

Grab All Files는 브라우저 안에서 페이지를 하나씩 차례로 읽습니다. 로그인 뒤의 페이지에 닿을 수 있는 것도 이 방식 덕분이고, 아주 큰 사이트에서 시간이 오래 걸리는 것도 같은 이유입니다. 수천 페이지에 남은 시간이 얼마 없다면, 서버에 직접 페이지를 요청하는 PC용 웹사이트 복사 프로그램이 시간당 더 넓은 범위를 처리합니다. Grab All Files는 그 프로그램이 볼 수 없는 페이지와, 링크된 문서를 유형별로 뽑아낼 때 쓰세요.

관련 가이드

  • 웹사이트 통째로 저장기한이 없을 때 사이트를 통째로 복사하는 일반적인 순서.
  • 출처 URL·날짜와 함께 저장출처 주소와 시각이 저장 형태별로 어디에 남는지.
  • 복사 프로그램·페이지 저장·다운로드 관리자 비교어느 규모의 사이트에 어떤 종류의 도구가 알맞은지.

자주 묻는 질문

닫히는 사이트에서는 무엇부터 저장해야 하나요?

공지, 가격, 절차처럼 그곳에만 있는 페이지와, 그 페이지가 링크한 PDF·Office 파일입니다. 모양과 오래된 아카이브 페이지는 그다음입니다.

저장한 사이트를 링크를 클릭하며 오프라인으로 둘러볼 수 있나요?

네. Chrome이나 Edge에서 “폴더에 사이트 형태로 저장”을 쓰거나 “페이지별 HTML(ZIP)”로 저장하면 됩니다. 저장한 페이지끼리의 링크는 저장된 파일을 엽니다. 저장하지 않은 페이지로 가는 링크는 계속 실제 사이트를 가리킵니다.

PDF와 Word 파일도 저장되나요?

네. 페이지에서 링크된 파일은 페이지와 함께(무료 1회 10개, Pro 100개) 저장하거나 “파일 일괄 다운로드”로 모을 수 있습니다. 그 텍스트는 HTML에 합쳐지지 않으며, 페이지에는 링크가 남습니다.

사이트의 동영상도 저장할 수 있나요?

mp4처럼 페이지가 직접 링크한 동영상 파일만 가능합니다. 스트리밍 동영상은 저장하지 않으며, DRM이나 워터마크를 우회하지도 않습니다.

사이트가 수천 페이지입니다. 무엇을 써야 하나요?

서버에 직접 페이지를 요청하며 큰 공개 사이트에서 더 빠른 PC용 웹사이트 복사 프로그램을 쓰세요. 로그인이 필요한 페이지와 문서를 뽑아낼 때는 Grab All Files를 쓰세요.
