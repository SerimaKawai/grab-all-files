여러 HTML 파일을 하나의 HTML로 합치기.

저장해 둔 웹사이트, 내보낸 매뉴얼, .html 페이지가 가득한 ZIP이 있나요? 컴퓨터의 폴더나 ZIP을 고르면 Grab All Files가 페이지를 목차가 있는 HTML 파일 하나로 합칩니다. 페이지는 사이트 자체의 링크 순서를 따르고, 컴퓨터 안의 이미지는 포함되며, 페이지 사이의 링크는 파일 안에서 이동합니다. 모든 처리는 브라우저 안에서 이루어지며 업로드하지 않습니다.

적합한 용도

  • ✓예전에 저장하거나 미러링한 웹사이트(index.html과 수십 개의 페이지)를 파일 하나로 보관하고, 읽고, 검색하고 싶을 때.
  • ✓HTML 페이지 폴더로 내보낸 도움말, 제품 매뉴얼, 기술 문서.
  • ✓여러 페이지의 HTML 문서를 첨부 파일 하나로 공유하거나, 한 번에 PDF로 인쇄하고 싶을 때.
  • ✓컴퓨터에 있는 문서 묶음을 출처가 표시된 Markdown 또는 데이터 패키지로 AI 도구에 한꺼번에 넘기고 싶을 때.

작업 흐름

  1. 1Grab All Files를 열고 “페이지를 HTML로 합치기”를 선택한 다음, 소스를 “컴퓨터 폴더에서”로 바꿉니다.
  2. 2폴더나 ZIP 파일을 선택하거나 화면으로 끌어다 놓습니다. .html, .htm, .xhtml 파일이 index.html에서 사이트가 연결한 순서대로 나열되고, 링크되지 않은 페이지는 이름순으로 뒤에 붙습니다.
  3. 3목록을 확인합니다. 페이지를 남기거나 빼고, “파일 이름 순서”로 바꾸고, “대상 폴더”로 범위를 좁히거나 “제외(한 줄에 하나)”로 경로를 제외합니다. 용도로 “사이트 보관”, “파일 하나로 공유”, “인쇄·PDF 만들기”, “AI에게 읽히기” 중 하나를 고릅니다.
  4. 4HTML을 만듭니다. 보고서에서 읽지 못한 파일, 제외한 페이지로 향하는 링크, 포함하지 못한 이미지를 확인합니다.

자주 묻는 질문

무료로 써볼 수 있나요?

페이지 하나라면 가능합니다. 폴더 모드에서 Free 플랜은 한 번에 선택한 HTML 파일 하나를, 로컬 이미지가 포함된 독립형 HTML로 변환합니다. 여러 HTML 파일을 공통 목차가 있는 파일 하나로 합치려면 Pro($19.99, 1회 결제)가 필요합니다.

파일이 어딘가에 업로드되나요?

아니요. 폴더나 ZIP은 브라우저 안에서 읽고, 합친 HTML은 내 기기에서 만들어집니다. 사이트 접근 권한도 필요 없으며, 페이지가 참조하는 온라인 이미지는 다운로드하지 않고 링크로 남겨 둡니다.

오래된 일본어 페이지가 깨져 보이지 않나요?

문자 인코딩 선언이 없거나, UTF-8로 선언되었지만 실제로는 Shift_JIS, EUC-JP, ISO-2022-JP로 작성된 페이지는 자동으로 판별해 올바르게 읽습니다. 모든 페이지의 <title>이 같다면 목차에는 각 페이지의 제목을 대신 사용합니다.

이미지, PDF, 페이지 간 링크는 어떻게 되나요?

컴퓨터 안의 PNG, JPEG, GIF, WebP, AVIF 이미지는 포함됩니다. 합친 페이지 사이의 링크는 파일 안에서 이동하는 링크가 됩니다. PDF, Office, ZIP 같은 링크된 파일은 “HTML 옆에 복사”(기본값), “HTML 안에 포함”(기본값은 파일당 20 MiB, 전체 100 MiB까지), “링크로 그대로 두기” 중에서 고를 수 있습니다.

어떤 파일을 읽을 수 있나요?

폴더나 ZIP 안의 .html, .htm, .xhtml 파일입니다. 프레임셋(frameset) 페이지는 기본적으로 제외하고 프레임 안의 페이지는 포함합니다. MHT 파일과 CHM 도움말 파일은 직접 읽지 않으므로, CHM은 먼저 HTML로 추출해 주세요.

웹사이트의 페이지를 합치는 기능과는 무엇이 다른가요?

“브라우저 페이지” 모드는 공개 중인 웹사이트에서 관련 페이지를 모읍니다. 폴더 모드는 이미 컴퓨터에 있는 파일만 사용하므로, 보관해 둔 사이트, 오프라인 매뉴얼, 더 이상 온라인에 없는 문서에 알맞습니다.

결과에 페이지나 이미지가 빠진 이유는요?

HTML을 만든 뒤 보고서를 확인하세요. 읽지 못한 파일, 제외한 페이지로 가는 링크, 포함하지 못한 이미지가 나열됩니다. 선택한 하위 폴더 밖이나 제외한 경로의 페이지는 포함되지 않고, 온라인 이미지는 링크로 남으며, 프레임 구성 페이지(frameset)는 기본적으로 제외되지만 프레임 안의 페이지는 포함됩니다.
