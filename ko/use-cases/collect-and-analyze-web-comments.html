작업 흐름

  1. 1저장할 게시물·동영상·스레드·기사의 댓글란을 브라우저에서 엽니다.
  2. 2Grab All Files에서 “페이지를 HTML로 합치기”를 선택하고, 수집 범위를 “현재 페이지만”으로 정한 뒤 저장을 시작합니다.
  3. 3페이지가 수집용 탭에서 열리고 끝까지 자동으로 스크롤됩니다. 답글을 펼치는 버튼과 답글·댓글을 더 불러오는 버튼도 자동으로 누릅니다. 화면에는 지금까지 불러온 개수가 표시됩니다.
  4. 41,000개를 읽을 때마다 계속할지 묻습니다. “계속 읽기”를 누르면 이어서 읽고, “이 게시물 저장”을 누르면 지금까지 읽은 분량을 저장합니다. 10분 동안 답이 없으면 그때까지 읽은 댓글을 저장합니다.
  5. 5다 읽으면 댓글과 답글이 HTML 파일 하나로 저장됩니다. AI로 분석하려면 이어서 “본문 복사”, “하나의 Markdown으로 저장”, “텍스트 파일(.txt)로 저장” 중 하나를 사용하세요.

자주 묻는 질문

어떤 사이트의 댓글을 저장할 수 있나요?

실제 페이지에서 동작을 확인한 것은 X(구 트위터)의 게시물과 답글, YouTube 동영상의 댓글, Reddit 스레드, Bluesky의 스레드와 프로필, Yahoo! 뉴스(일본) 기사의 댓글입니다. 그 밖의 사이트도 스크롤하면 다음 내용이 이어서 나오는 목록이라면 끝까지 스크롤해 저장되는 경우가 있습니다.

접힌 답글도 저장되나요?

네. YouTube, Reddit, Yahoo! 뉴스에서는 접힌 답글을 펼치는 버튼과 답글·댓글을 더 불러오는 버튼을 자동으로 눌러 엽니다. Bluesky처럼 답글이 다른 페이지로 이어지는 경우, Pro에서는 “현재 페이지만”을 선택해 두어도 그 페이지까지 따라가서 읽습니다.

몇 개까지 저장할 수 있나요?

개수 제한은 없습니다. 1,000개를 읽을 때마다 계속 읽을지, 지금까지 읽은 분량을 저장할지 확인합니다. 10분 동안 답이 없으면 그때까지 읽은 댓글을 저장합니다. 스크롤해도 새 댓글이 더 나오지 않으면 끝까지 읽은 것으로 보고 마칩니다.

무료 플랜에서도 쓸 수 있나요?

네. 댓글을 끝까지 불러오는 기능과 답글을 펼치는 기능은 무료 플랜과 Pro가 같습니다. 무료 플랜으로 YouTube, Reddit, Bluesky의 댓글란을 끝까지 저장할 수 있다는 것도 확인했습니다. 차이는 한 번에 저장하는 페이지 수입니다. 무료 플랜은 한 페이지씩 저장하고, Pro는 여러 페이지를 HTML 파일 하나로 합칩니다. Yahoo! 뉴스처럼 댓글 목록이 여러 페이지로 나뉜 사이트에서는 무료 플랜으로 첫 페이지만 저장됩니다.

광고도 들어가나요?

X에서는 타임라인과 답글 사이에 섞인 프로모션(광고) 게시물을 가려내 저장하지 않습니다. 열어 둔 게시물 자체는 저장됩니다.

동영상도 다운로드되나요?

이 페이지에서 소개하는 것은 댓글과 답글을 페이지로 저장하는 기능입니다. 동영상 파일 자체는 다운로드하지 않습니다.

로그인해야 보이는 댓글은요?

저장되는 것은 브라우저에 보이는 댓글입니다. 회원 전용 댓글처럼 로그인해야 보이는 댓글은 들어가지 않습니다. YouTube에서는 저장된 개수가 동영상에 표시된 댓글 수보다 조금 적을 수 있습니다. 표시된 숫자에는 로그인하지 않은 사람에게는 보이지 않는 답글도 포함되어 있기 때문입니다.

저장한 댓글이 어딘가로 전송되나요?

전송되지 않습니다. 댓글은 사용자의 브라우저에서 불러와 컴퓨터에 저장합니다. 복사한 본문이나 저장한 파일을 AI 서비스에 넘길지, 어느 서비스에 넘길지는 직접 정하면 됩니다. 다른 사람의 글을 공유하거나 공개할 때는 각 사이트의 약관과 글쓴이의 권리를 확인하세요.
