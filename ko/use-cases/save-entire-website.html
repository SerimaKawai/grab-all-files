  • –내 브라우저에서 열 수 없는 페이지입니다.

저장하기 전에 고르는 것

저장 형태는 네 가지

네 가지 모두 '원래 모양 그대로'에서 쓸 수 있습니다. 무료 플랜은 어느 형태로든 1회에 한 페이지를 저장할 수 있고, Pro는 여러 페이지를 1회에 저장합니다.

순서(Pro 기준)

  1. 1로그인이 필요한 사이트라면 같은 브라우저에서 로그인해 둡니다. 시작할 페이지(대개 홈 페이지나 목차 페이지)를 엽니다.
  2. 2Grab All Files를 열고 '페이지를 HTML로 합치기'로 바꿉니다. 수집 범위에서 '링크된 페이지도 찾기'를 고릅니다. 더 세밀하게 정하려면 사이트맵이나 붙여넣은 URL 목록도 쓸 수 있습니다.
  3. 3후보 목록을 확인하고, 필요 없는 페이지는 빼고, 나머지를 읽고 싶은 순서로 정렬합니다.
  4. 4'원래 모양 그대로'와 저장 형태 '폴더에 사이트 형태로 저장'(Firefox라면 ZIP)을 고르고, 저장할 폴더를 정해 시작합니다.
  5. 5페이지가 PDF나 Office 문서로 링크되어 있으면 페이지 옆에 함께 저장됩니다. Pro는 1회에 최대 100개이며, 나머지는 결과 화면의 버튼으로 이어서 저장합니다.

저장한 페이지의 동작

각 페이지는 해당 페이지의 스타일시트, 웹 폰트, 이미지를 포함한 채 저장됩니다. 여러 페이지가 함께 쓰는 파일은 한 번만 저장합니다. 사이트의 스크립트는 제거되고, 저장한 페이지는 열어도 네트워크에 연결하지 않습니다. 탭, 아코디언, 캐러셀 화살표는 동작하지만 전송 양식, 서버에 질의하는 검색창, 삽입된 동영상 플레이어는 동작하지 않습니다.

저장하기 전에 각 페이지를 탭에서 열고 스크롤해서 지연 로딩 이미지가 나타나게 합니다. 이 작업에 쓰는 시간은 '스크롤 시간' 설정(45초, 90초, 180초)을 따릅니다. 광고는 기본적으로 제외하며, 모든 페이지에 반복되는 머리글, 메뉴, 바닥글은 첫 페이지에만 남길 수도 있습니다.

사이트가 수천 페이지일 때

Grab All Files는 브라우저 안에서 페이지를 하나씩 차례로 읽습니다. 로그인 후의 페이지나 JavaScript 페이지를 저장할 수 있는 것도 이 때문이고, 수천 페이지짜리 사이트에서 시간이 오래 걸리는 것도 같은 이유입니다. 수천 페이지가 필요하거나 지난번 이후 바뀐 파일만 다시 받고 싶다면 PC용 웹사이트 복사 프로그램을 쓰세요. 이런 프로그램은 서버에서 직접 페이지를 가져오므로 큰 공개 사이트에서는 빠르지만, 로그인이 필요한 페이지나 브라우저 안에서 만들어지는 페이지는 볼 수 없습니다.

자주 묻는 질문

저장한 사본은 링크를 클릭해 오프라인에서 둘러볼 수 있나요?

네. '폴더에 사이트 형태로 저장'(Chrome, Edge) 또는 '페이지별 HTML(ZIP)'로 저장하면 저장한 페이지끼리의 링크가 저장된 파일을 엽니다. 저장하지 않은 페이지로 가는 링크는 계속 원래 사이트를 가리킵니다.

로그인이 필요한 페이지에서도 쓸 수 있나요?

네, 같은 브라우저에서 열 수 있는 페이지라면 가능합니다. 현재의 로그인 상태를 그대로 사용하며, 비밀번호를 저장하거나 전송하지 않습니다. 긴 작업 도중 세션이 만료되면 일시 정지되므로, 다시 로그인한 뒤 '재개'를 누르세요.

무료로 몇 페이지까지 저장할 수 있나요?

1회에 한 페이지입니다. 같은 저장본에 한 페이지씩 계속 추가할 수 있습니다. Pro는 고른 페이지를 1회에 모두 저장합니다.

사이트를 똑같이 복제할 수 있나요?

브라우저에 표시된 내용을 사이트의 스타일과 이미지째 저장합니다. 검색, 양식, 로그인 같은 서버 측 기능은 사본에서 동작하지 않으며, 스트리밍 동영상은 저장하지 않습니다.

페이지가 어딘가로 전송되나요?

아니요. 페이지를 읽고 저장하는 일은 모두 내 컴퓨터에서 이루어집니다. 개발자의 서버에 전달되는 것은 라이선스 확인과, 켜 둔 경우의 사용 통계뿐입니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
