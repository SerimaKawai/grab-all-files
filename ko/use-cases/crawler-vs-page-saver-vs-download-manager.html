이 방식들은 경쟁 관계가 아닙니다. 흔한 분담은 이렇습니다. 큰 공개 사이트에는 PC용 웹사이트 복사 프로그램을, 같은 사이트의 로그인 영역이나 몇 페이지에 흩어진 PDF에는 Grab All Files를 씁니다. 다른 도구에 넘기고 싶다면 Grab All Files의 파일 목록을 모든 파일의 URL이 담긴 CSV로 내보낼 수도 있습니다.

자주 묻는 질문

Grab All Files는 웹사이트 복사 프로그램인가요?

일반적인 의미에서는 아닙니다. 브라우저 안에서 페이지를 한 번에 하나씩 저장하며, 사이트의 폴더 구조를 컴퓨터에 기록할 수도 있습니다. 한정된 페이지 묶음에 알맞습니다. 수천 페이지라면 PC용 웹사이트 복사 프로그램을 쓰세요.

로그인해야 하는 사이트에서는 어느 방식이 되나요?

이미 가진 로그인을 쓸 수 있는, 브라우저 안에서 실행되는 도구입니다. Grab All Files와 한 페이지 저장 확장 프로그램이 이 방식입니다. PC용 복사 프로그램은 대개 추가 설정이 필요합니다.

저장한 사본을 새로 고치고 바뀐 것만 다운로드할 수 있나요?

Grab All Files로는 안 됩니다. 같은 사이트의 마지막 수집과 비교하는 Markdown 변경 보고서는 있지만, 페이지를 다시 저장합니다. 갱신을 위해 만들어진 방식은 PC용 웹사이트 복사 프로그램입니다.

다운로드 관리자와는 어떻게 다른가요?

다운로드 관리자는 파일 링크 목록을 받아 잘 가져옵니다. Grab All Files는 먼저 파일을 찾고(페이지가 스크립트로 불러오는 것도 포함), 확인할 수 있게 목록으로 보여 주며, 페이지를 HTML로 저장할 수도 있습니다.

브라우저에서 Grab All Files를 사용해 보세요.

무료 플랜은 파일 일괄 다운로드에서 다운로드당 최대 10개, 페이지를 HTML로 합칠 때는 한 번에 선택한 1페이지를 저장합니다. 그 페이지에 직접 링크된 파일은 “다음 파일 10개 저장”으로 10개씩 저장합니다. Pro($19.99, 1회 결제, 최대 3대)는 다운로드당 제한이 없고 여러 페이지를 하나의 HTML로 합칩니다.
