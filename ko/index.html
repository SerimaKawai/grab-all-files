자주 묻는 질문

지원하는 파일 형식은 무엇인가요?

Grab All Files는 PDF, Word, Excel, PowerPoint, 이미지, ZIP, CSV 등 708종류(확장자)의 파일을 지원합니다. 분할 / 멀티볼륨 아카이브 시퀀스(.000/.001…, WinRAR .r00/.s00, WinZip .z01)도 감지하여 압축 아카이브로 분류합니다. 확장자로 필터링하고 필요한 항목을 선택하여 한 번의 클릭으로 모두 다운로드할 수 있습니다.

무료로 사용할 수 있나요?

네. 모든 기능이 무료입니다. 한 번의 다운로드로 최대 20개 파일을 저장할 수 있으며, 다운로드를 반복하면 나머지도 무료로 저장할 수 있습니다. 웹페이지 수집은 20페이지마다 확인을 위해 일시 중지합니다. Pro($19.99 일회성 구매)는 다운로드 제한을 해제하고 페이지 수집을 자동으로 계속합니다.

여러 웹페이지를 하나의 HTML 파일로 합칠 수 있나요?

네. 확장 프로그램을 열고 “페이지를 HTML로 합치기”를 선택하세요. 관련 페이지를 찾은 후 목록을 검토할 수 있으며, 선택한 페이지를 목차가 있는 하나의 검색·인쇄 가능한 HTML 파일로 저장합니다. Free는 20페이지마다 확인을 위해 일시 중지하고, Pro는 자동으로 계속합니다.

Pro 가격은?

$19.99 USD 일회성 결제. 평생 라이선스, 구독 없음. 최대 3대 기기.

브라우저 데이터를 어디로 보내나요?

아니요. 파일은 소스 사이트에서 직접 기기로 다운로드됩니다. 라이선스 확인과 소수의 익명 플랜 상호작용 이벤트(무작위 기기 ID, 플랜 상태, 기능 레이블)만 서버에 도달하며, 페이지 콘텐츠·URL·파일 이름은 전송되지 않습니다.

지원 브라우저는?

Google Chrome 및 Microsoft Edge (Chromium 111 이상), 그리고 Mozilla Firefox (128 이상).

환불이 가능한가요?

즉시 제공되는 디지털 제품으로 원칙적으로 환불은 불가합니다. 무료 플랜으로 Pro 구매 전에 모든 기능을 충분히 검토하실 수 있습니다. 기술적 결함으로 확장 프로그램이 작동하지 않는 경우 30일 이내에 문의하시면 전액 환불해 드립니다.

대용량·장시간 다운로드를 일시정지·재개하며 처리할 수 있나요?

네. Grab All Files에는 병렬 수 조정, 일시정지/재개, 자동 재시도, 실패한 파일만 원클릭 재시도가 가능한 내장 다운로드 관리자가 있어, 연결이 끊겨도 대량 배치가 계속됩니다. 매우 큰 단일 파일이나 장시간 무인 작업의 경우 URL 목록을 내보내 전용 다운로드 관리자에 넘길 수도 있습니다.

JDownloader나 aria2 같은 다운로드 관리자와 함께 쓸 수 있나요?

네, 서로 보완합니다. Grab All Files는 iframe, 뷰어, JavaScript, CMS 경로 뒤에 있는 복잡하거나 로그인이 필요한 페이지에서 파일을 찾아내는 데 강합니다. 결과를 CSV나 URL 목록으로 내보내 다운로드 관리자에 넘기면 대량 일괄 다운로드를 맡길 수 있습니다. 발견은 Grab All Files, 무거운 다운로드는 전용 관리자입니다.

JavaScript 앱, 로그인 전용 페이지, 봇 차단 사이트에서도 작동하나요?

네. 페이지가 구성된 후 JavaScript로 렌더링되는 SPA(React, Next.js, Nuxt, Vue)를 읽고, 이미 열 수 있는 페이지에서는 기존 브라우저 세션을 사용하며, CSRF로 보호된 다운로드 폼을 따라가고, Cloudflare/WAF 봇월을 감지해 복구를 안내합니다. 확장자뿐 아니라 시그니처로 파일 형식을 확인하며, 접근 제어나 보안 보호를 우회하지 않습니다.
