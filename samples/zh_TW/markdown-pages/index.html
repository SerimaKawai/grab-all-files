將四個頁面儲存為逐頁 Markdown（Pro）

收集同一份手冊的四個頁面，再從結果中的「交給 AI」面板轉成逐頁 Markdown。ZIP 內每個頁面各有一個 .md（pages/）、CSV 格式的表格（tables/）、記錄來源與數量的 manifest.json、README.md 等檔案。同一次執行儲存的易讀 HTML 也一併收錄。

來源頁面是放在本網站上的虛構素材。輸出檔案就是擴充功能儲存的原始結果，未經編輯。

此 Pro 範例未使用授權，而是以同一份 5.8.20 原始碼建置的開發版，啟用其中的 Pro 功能製作而成。開發版只更動方案檢查等部分，儲存程式碼與商店版相同。
