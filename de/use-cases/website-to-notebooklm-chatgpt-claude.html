Wo die Erweiterung aufhört und Sie anfangen

Die Erweiterung liest die Seiten in Ihrem Browser, wandelt sie auf Ihrem Computer um und speichert die Dateien. Mehr tut sie nicht. Sie meldet sich nicht bei einem KI-Dienst an, lädt nichts hoch und stellt keine Frage für Sie.

Sie öffnen den KI-Dienst Ihrer Wahl, fügen die Dateien als Quellen oder Anhänge hinzu und stellen dort Ihre Frage. Welche Dateitypen und Größen der Dienst akzeptiert und wie er hochgeladene Dateien behandelt, legt der Dienst fest. Lesen Sie seine aktuellen Grenzen und Datenschutzeinstellungen, bevor Sie Seiten einer Website nur für Mitglieder hochladen.

Der Weg in fünf Schritten

  1. 1Öffnen Sie die Startseite der Website oder die Übersichtsseite des Bereichs, der Sie interessiert. Brauchen die Seiten eine Anmeldung, melden Sie sich zuerst im selben Browser an.
  2. 2Öffnen Sie Grab All Files, wechseln Sie zu „Seiten als HTML bündeln“ und wählen Sie, woher gesammelt wird: die Links der Seite, eine Sitemap, der gleiche Pfad oder eine eingefügte URL-Liste. Prüfen Sie die Kandidatenliste und entfernen Sie Seiten, die nicht gelesen werden sollen.
  3. 3Öffnen Sie in den Ausgabeeinstellungen „KI-Analysedaten (Markdown mit Quellen)“ und wählen Sie das Ausgabeformat. „Hauptinhalt (Standard)“ behält den Artikeltext und lässt Menüs und Werbung weg.
  4. 4Starten Sie die Erfassung. Drücken Sie danach „KI-Analyse-ZIP speichern“ oder „Als eine Markdown-Datei speichern“. „KI-Anfragetext kopieren“ kopiert eine fertige Anfrage, die Sie in den Chat einfügen können.
  5. 5Öffnen Sie NotebookLM, ChatGPT, Claude oder einen anderen Dienst selbst, fügen Sie die Dateien hinzu und fügen Sie die Anfrage ein. Prüfen Sie eine Antwort anhand von source_url und captured_at der Seite, aus der sie stammt.

Was die Einstellung 25 MB bedeutet

Der Standardwert 25 MB ist eine Zielgröße, um den Markdown-Text in Dateien aufzuteilen. Er ist keine Obergrenze für die gesamte ZIP und kein Versprechen, dass ein Dienst eine Datei dieser Größe annimmt. Das vollständige Paket ist eine ZIP aus corpus.md, chunks.jsonl, manifest.json, dem Anfragetext und dem lesbaren HTML und damit größer als das Markdown allein.

Nimmt der Dienst, den Sie nutzen, kleinere Dateien an, senken Sie die Zielgröße unter „Nach Dateigröße“. Begrenzt er, wie viele Dateien Sie hinzufügen können, erhöhen Sie die Zielgröße oder wählen Sie eine Markdown-Datei. Die richtige Zahl ergibt sich aus den eigenen Grenzen des Dienstes, die sich ändern können.

FAQ

Sendet Grab All Files meine Seiten an NotebookLM, ChatGPT oder Claude?

Nein. Es speichert Dateien auf Ihrem Computer. Sie laden sie selbst beim KI-Dienst hoch, und danach gelten für die Dateien die Regeln dieses Dienstes.

Sollte ich eine Markdown-Datei oder eine Datei pro Seite nutzen?

Nutzen Sie eine Datei für eine kleine Website, die Sie als Ganzes befragen möchten. Nutzen Sie Dateien pro Seite oder eine kleinere Zielgröße, wenn der Text die Dateigrenze des Dienstes übersteigt oder Sie Seiten getrennt hinzufügen und ersetzen möchten.

Was bedeuten die 25 MB als Standardwert?

Es ist die Zielgröße für die Aufteilung des Markdown-Textes. Es ist keine Größengrenze für die ZIP und keine Garantie, dass ein Dienst die Datei annimmt.

Woran erkenne ich, aus welcher Seite eine KI-Antwort stammt?

Jede Seite im Markdown hat source_url und captured_at, und auch chunks.jsonl und manifest.json enthalten sie. Suchen Sie die Seite heraus und vergleichen Sie die Antwort mit dem Original.

Kann es Seiten lesen, die eine Anmeldung brauchen?

Ja, wenn Sie im selben Browser bei der Website angemeldet sind. Es nutzt diese Sitzung und sammelt Ihr Passwort nicht. Die Ausgabe enthält, was der Browser angezeigt hat. Überlegen Sie daher, wer die Dateien sehen wird, bevor Sie sie hochladen.
