Grab All Files speichert Seiten so, wie Ihr Browser sie anzeigt. Deshalb funktioniert es auch in Mitgliederbereichen und auf Websites, die mit JavaScript aufgebaut sind. Es passt zu Websites mit einigen Dutzend bis einigen Hundert Seiten. Für Tausende Seiten oder eine Kopie, die laufend aktuell bleibt, ist ein Website-Kopierer für den Desktop das bessere Werkzeug – das steht weiter unten auf dieser Seite.

Wo es gut funktioniert

  • ✓Die Seiten werden von JavaScript aufgebaut, sodass ein einfacher Download des HTML fast leer zurückkommt.

  • –Seiten, die Sie in Ihrem eigenen Browser nicht öffnen können.

Was Sie vor dem Speichern wählen

Vier Arten, die Kopie zu speichern

Alle vier stehen mit „Ursprüngliches Aussehen behalten“ zur Verfügung. In der kostenlosen Version speichern Sie pro Durchlauf eine Seite, in jeder dieser Formen; Pro speichert viele Seiten in einem Durchlauf.

Schritte, mit Pro

  1. 1Melden Sie sich im selben Browser bei der Website an, falls das nötig ist, und öffnen Sie die Seite, von der Sie starten möchten – meist die Startseite oder das Inhaltsverzeichnis.
  2. 2Öffnen Sie Grab All Files und wechseln Sie zu „Seiten als HTML bündeln“. Wählen Sie unter „wie weit gesammelt wird“ die Suche nach verlinkten Seiten, oder nutzen Sie eine Sitemap oder eine eingefügte URL-Liste für mehr Kontrolle.
  3. 3Prüfen Sie die Kandidatenliste. Entfernen Sie Seiten, die Sie nicht brauchen, und bringen Sie den Rest in die gewünschte Reihenfolge.
  4. 4Wählen Sie „Ursprüngliches Aussehen behalten“ und die Form „Website-Kopie in einem Ordner“ (oder eine ZIP, wenn Sie Firefox nutzen), wählen Sie dann den Zielordner und starten Sie.
  5. 5Verlinken die Seiten auf PDFs oder Office-Dateien, werden diese neben den Seiten gespeichert: mit Pro bis zu 100 pro Durchlauf, für den Rest gibt es auf dem Ergebnisbildschirm eine Schaltfläche.

Wie sich die gespeicherten Seiten verhalten

Jede Seite behält ihre eigenen Stylesheets, Webfonts und Bilder. Dateien, die viele Seiten gemeinsam nutzen, werden nur einmal gespeichert. Die Skripte der Website werden entfernt, und die gespeicherten Seiten bauen beim Öffnen keine Netzwerkverbindung auf. Reiter, Akkordeons und Pfeile in Karussells funktionieren daher weiter, Formulare, Suchfelder, die den Server abfragen, und eingebettete Videoplayer dagegen nicht.

Vor dem Speichern wird jede Seite in einem Tab geöffnet und gescrollt, damit nachgeladene Bilder erscheinen. Wie lange das dauert, richtet sich nach der Einstellung „Scroll-Zeit“ (45, 90 oder 180 Sekunden). Werbung bleibt standardmäßig draußen, und Kopfzeile, Menü und Fußzeile, die auf jeder Seite wiederkehren, lassen sich nur auf der ersten Seite behalten.

Wenn die Website Tausende Seiten hat

Grab All Files liest jede Seite in Ihrem Browser, eine nach der anderen. Genau das macht es möglich, angemeldete und JavaScript-Seiten zu speichern, und es ist auch der Grund, warum eine Website mit mehreren Tausend Seiten lange dauert. Brauchen Sie Tausende Seiten oder möchten Sie nur die seit dem letzten Mal geänderten Dateien erneut herunterladen, nutzen Sie einen Website-Kopierer für den Desktop. Solche Programme fordern Seiten direkt beim Server an, was bei großen öffentlichen Websites schneller ist, aber keine Seiten sehen kann, die Ihre Anmeldung brauchen oder erst im Browser aufgebaut werden.

FAQ

Kann ich die gespeicherte Kopie offline über ihre Links durchblättern?

Ja, mit „Website-Kopie in einem Ordner“ (Chrome und Edge) oder „Einzelne HTML-Seiten (ZIP)“. Links zwischen gespeicherten Seiten öffnen die gespeicherten Dateien. Links zu Seiten, die Sie nicht gespeichert haben, zeigen weiterhin auf die Live-Website.

Funktioniert es auf Seiten, die eine Anmeldung brauchen?

Ja, wenn Sie sie im selben Browser öffnen können. Es nutzt Ihre bestehende Anmeldung und speichert oder sendet Ihr Passwort nicht. Läuft die Sitzung während eines langen Durchlaufs ab, pausiert es; melden Sie sich erneut an und drücken Sie „Fortsetzen“.

Wie viele Seiten kann ich kostenlos speichern?

Eine Seite pro Durchlauf. Sie können der gespeicherten Kopie weiter einzeln Seiten hinzufügen. Pro speichert alle ausgewählten Seiten in einem Durchlauf.

Wird die Website originalgetreu kopiert?

Es speichert, was der Browser anzeigt, mit den Stilen und Bildern der Website. Serverseitige Funktionen wie Suche, Formulare und Anmeldungen funktionieren in der Kopie nicht, und gestreamtes Video wird nicht gespeichert.

Werden die Seiten irgendwohin gesendet?

Nein. Seiten werden auf Ihrem Computer gelesen und gespeichert. Nur die Lizenzprüfung und, falls Sie sie einschalten, Nutzungsstatistiken erreichen den Server des Entwicklers.
