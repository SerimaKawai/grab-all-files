How to check a saved file yourself

  1. 1Save one or two pages first with the look and form you plan to use.
  2. 2Open the file in the browser. In the contents-and-search form, look under the page title for the URL and the time.
  3. 3For the ZIP and the vertically joined form, view the page source in the browser and read the comment at the top, or open the file in a text editor.
  4. 4For Markdown, open the .md file and look for source_url and captured_at at each page.
  5. 5If the URL or the time is not there, change the look or form, or turn on the collection details option, and save again.

What it does and does not tell you

A saved page records the address it was read from and the time it was captured. That lets you find the original again and tell an old capture from a new one. If you compare captures of the same site over time, the “Save change report vs. previous run” button writes a Markdown change report that compares the site’s last completed collection with the new one, by URL, title and text.

A file on your computer can be edited like any other file, so the URL and the time are a note kept with the page, not a seal. This guide does not say how a court, an auditor or a platform would treat such a file.

FAQ

Does a saved page show its original URL?

With “Keep the original look” and “HTML with contents and search”, yes: under each page title, with the capture time. With “Easy to read”, there is no URL line per page.

Where is the URL kept in the ZIP of separate HTML pages?

In a comment at the top of each HTML file, as url and saved date, when you use “Keep the original look”. It is not printed on the page.

Can I get the capture time with “Easy to read”?

Yes, turn on “Include the collection details and the list of failures”. It is off by default, and it adds the capture time at the top of the document, not a URL line for each page.

Which output keeps the URL and the time in a machine-readable form?

The AI Markdown output. Each page has source_url and captured_at, and chunks.jsonl and manifest.json have both.

Will a printout show the source?

With “Keep the original look” and “HTML with contents and search”, yes: the URL and the time are printed under each title. With the vertically joined form they are only in an HTML comment, so a printout does not show them.
