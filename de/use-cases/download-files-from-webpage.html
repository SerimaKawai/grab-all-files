Laden Sie alle Dateien einer Webseite in einem organisierten Lauf herunter.

Wenn eine Seite PDFs, Office-Dokumente, Bilder, ZIPs, CSVs und versteckte fetch-Antworten mischt, ist manuelles Speichern mühsam. Grab All Files scannt die Seite, listet erkennbare Dateien mit Metadaten und lässt Sie genau auswählen, was Sie behalten.

Ablauf

  1. 1Öffnen Sie die Seite in Chrome, Edge oder Firefox und klicken Sie in der Symbolleiste auf das Grab-All-Files-Symbol. Die Dateiliste bezieht sich auf die geöffnete Seite.
  2. 2Klicken Sie auf „Scannen“. Sollen verlinkte Seiten einbezogen werden, erhöhen Sie vorher die „Tiefe“ („Nur diese Seite“ prüft nur diese Seite); Links werden nur innerhalb des Ordners der Ausgangsseite verfolgt.
  3. 3Grenzen Sie die Liste über die Dateitypen, das Suchfeld für Namen und Titel und „Details“ (Mindestgröße, „Speichern als“) ein. Haken Sie die gewünschten Dateien an.
  4. 4Klicken Sie auf „Herunterladen“. ZIP, „PDFs zusammenführen“, „Ablage“ und „Dateiinfo als CSV exportieren“ finden Sie unter „Weitere Aktionen“. Die kostenlose Version speichert bis zu 10 Dateien pro Download.
  5. 5Bei längeren Listen wählen Sie die nächsten Dateien aus und klicken erneut auf „Herunterladen“. Fehlgeschlagene Zeilen nennen den Grund; beheben Sie den Zugriff und wiederholen Sie sie.

FAQ

Welche Typen werden unterstützt?

PDF, Office, Bilder, ZIP, CSV und andere herunterladbare Antworten, die der Browser erreichen kann. Es erkennt außerdem geteilte / mehrteilige Archivsätze wie .001, .r00 und .z01.

Kann ich nur bestimmte Dateien auswählen?

Ja. Filtern Sie nach Typ, Name, Titel oder Größe, sortieren Sie nach einer beliebigen Spalte und haken Sie nur die benötigten Zeilen an. Gespeichert wird erst, wenn Sie eine Speicherschaltfläche anklicken.

Gibt es in der kostenlosen Version ein Limit?

Die kostenlose Version speichert bis zu 10 ausgewählte Dateien pro Download; dasselbe Limit gilt für ZIP, „PDFs zusammenführen“ und den CSV-Export. Zum Weitermachen wählen Sie die nächsten Dateien aus und klicken erneut auf die Schaltfläche – gesperrt wird nichts. Pro (19,99 $, einmalig, bis zu 3 Geräte) hebt das Limit pro Download auf.

Es wurde nichts oder weniger gefunden als erwartet. Was kann ich tun?

Bei Seiten, die beim Scrollen nachladen, öffnen Sie „Scan-Optionen“, aktivieren „Vor dem Scan alles scrollen & laden“ und scannen erneut. Liegen die Dateien auf verlinkten Seiten, erhöhen Sie die „Tiefe“. Pausieren Sie Werbeblocker für die Website. Werden Downloads vom JavaScript der Seite gestartet, nutzen Sie „Aktive Erfassung“, sobald sie angeboten wird.

Die Seite verlangt eine Anmeldung. Was tun?

Melden Sie sich zuerst im selben Browser bei der Website an und scannen Sie dann. Grab All Files nutzt Ihre bestehende Sitzung; ab Tiefe 1 öffnet es verlinkte Seiten mit derselben Anmeldung. Es meldet sich nie für Sie an und umgeht keine Zugriffsbeschränkungen. Zeilen mit „Anmeldung erforderlich“ wiederholen Sie nach einer erneuten Anmeldung.

Funktioniert es auf HTTP-Seiten?

Ja. Es scannt HTTP und HTTPS, wenn der Browser die Seite öffnen kann.
