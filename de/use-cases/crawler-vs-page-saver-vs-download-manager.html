Wo Grab All Files die richtige Wahl ist

  • ✓Sie müssen sich anmelden, um die Seiten zu sehen, und können sie bereits in Ihrem Browser öffnen.
  • ✓Die Seiten werden von JavaScript aufgebaut, und ein einfacher Download kommt leer zurück.
  • ✓Sie möchten die PDFs und Office-Dateien zuerst aufgelistet haben, um sie zu prüfen und nur einige zu behalten.
  • ✓Die Aufgabe ist eine begrenzte Zahl von Seiten oder eine lange Liste von Dateien auf wenigen Seiten.

Wo es die falsche Wahl ist

  • –Eine ganze Website mit Tausenden Seiten, in einem Zug kopiert.
  • –Eine Kopie, die Sie jede Woche aktualisieren und dabei nur die geänderten Dateien holen.
  • –Video, das gestreamt statt als Datei verlinkt wird.
  • –Seiten, die Sie in Ihrem eigenen Browser nicht öffnen können.

Mehr als eines nutzen

Die Methoden sind keine Rivalen. Eine übliche Aufteilung: Nutzen Sie einen Website-Kopierer für den Desktop für eine große öffentliche Website und Grab All Files für den angemeldeten Bereich derselben Website oder für die PDFs, die auf wenige Seiten verstreut sind. Die Dateiliste von Grab All Files lässt sich auch als CSV exportieren, mit der URL jeder Datei, wenn Sie sie an ein anderes Werkzeug weitergeben möchten.

FAQ

Ist Grab All Files ein Website-Kopierer?

Nicht im üblichen Sinn. Es speichert Seiten jeweils einzeln in Ihrem Browser und kann die Ordnerstruktur einer Website auf Ihren Computer schreiben. Es passt zu einer begrenzten Zahl von Seiten. Für Tausende Seiten nutzen Sie einen Website-Kopierer für den Desktop.

Welche Methode funktioniert bei einer Website, bei der ich mich anmelden muss?

Ein Werkzeug, das in Ihrem Browser läuft, weil es die Anmeldung nutzt, die Sie bereits haben. Grab All Files und Einzelseiten-Speicher als Erweiterung arbeiten so. Kopierer für den Desktop brauchen dafür oft zusätzliche Einrichtung.

Kann ich eine gespeicherte Kopie aktualisieren und nur das Geänderte herunterladen?

Nicht mit Grab All Files. Es hat einen Markdown-Änderungsbericht, der mit Ihrer letzten Erfassung derselben Website vergleicht, speichert die Seiten aber erneut. Ein Website-Kopierer für den Desktop ist die Methode, die fürs Aktualisieren gebaut ist.

Wie unterscheidet es sich von einem Download-Manager?

Ein Download-Manager nimmt eine Liste von Dateilinks und holt sie gut ab. Grab All Files findet zuerst die Dateien, auch solche, die eine Seite per Skript lädt, zeigt sie zur Prüfung in einer Liste und kann zusätzlich die Seiten als HTML speichern.
