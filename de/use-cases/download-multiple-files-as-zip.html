Wo die ZIP-Schaltfläche sitzt

Die Zahlen

Schritte

  1. 1Öffnen Sie die Seite und scannen Sie sie mit dem „Datei-Downloader“.
  2. 2Filtern Sie die Liste und haken Sie die gewünschten Dateien an. Achten Sie auf die Größen: Rechnen Sie nach, wenn Sie nahe an 200 MB liegen.
  3. 3Drücken Sie „ZIP“. Bestätigen Sie, falls nach der Größe gefragt wird.
  4. 4Öffnen Sie die ZIP-Datei in Ihrem Download-Ordner. Kostenlose Version: Für mehr Dateien wählen Sie die nächsten aus und drücken erneut ZIP.

Eine ZIP passt gut, wenn

  • ✓Sie eine Gruppe als eine Datei senden oder archivieren möchten.
  • ✓es einige Dutzend Dateien sind, deutlich unter 200 MB.
  • ✓Sie eine ordentliche einzelne Datei statt vieler loser Downloads wollen.

Speichern Sie lieber in einen Ordner, wenn

  • –die Gesamtgröße nahe an oder über 256 MB liegt: Videos, große Zeichnungen, gescannte Bücher.
  • –Sie die Dateien nach Typ oder Website in getrennten Ordnern sortieren möchten.
  • –Sie einzelne Dateien sofort öffnen oder umbenennen möchten.

ZIP ist eine von mehreren Ausgaben

Dieselbe Auswahl lässt sich auch als einzelne Dateien speichern, zusammenführen (PDF) oder als Dateiliste (CSV) exportieren. Alles wird in Ihrem Browser verarbeitet.

Nicht zu verwechseln mit „Einzelne HTML-Seiten (ZIP)“

„Einzelne HTML-Seiten (ZIP)“ gehört zu „Seiten als HTML bündeln“, dem anderen Werkzeug. Dabei werden gespeicherte Webseiten als eine HTML-Datei pro Seite samt index.html in einer ZIP abgelegt. Die Schaltfläche „ZIP“ im Datei-Downloader packt Dateien wie PDFs und Office-Dokumente unverändert. Es sind zwei getrennte Funktionen, und die Grenzen auf dieser Seite sind die Zahlen der ZIP-Schaltfläche.

FAQ

Wie lade ich viele Dateien einer Seite als eine ZIP herunter?

Scannen Sie die Seite mit dem Datei-Downloader, haken Sie die Dateien an und drücken Sie „ZIP“. Sie erhalten ein Archiv.

Wie viele Dateien passen kostenlos in eine ZIP?

10. Aus 30 Berichten werden drei ZIP-Dateien mit je 10: Wählen Sie die nächsten 10 aus und drücken Sie erneut „ZIP“.

Wie groß darf eine ZIP höchstens sein?

256 MB insgesamt. Ab 200 MB werden Sie um eine Bestätigung gebeten. Die Dateien werden nicht auf mehrere ZIP-Dateien aufgeteilt.

Wie heißt die ZIP-Datei?

Sie trägt den Hostnamen der Website und das Datum, zum Beispiel docs.example.com_2026-11-17.zip. Ein vorangestelltes www. entfällt.

Meine Auswahl ist für eine ZIP zu groß. Was nun?

Wählen Sie pro ZIP weniger Dateien aus oder speichern Sie in einen Ordner, statt eine ZIP zu erstellen.
