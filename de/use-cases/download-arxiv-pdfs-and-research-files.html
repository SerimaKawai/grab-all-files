Die echte Erweiterung auf arXiv

Geeignet für

  • ✓Eine Leseliste aus einer eingegrenzten Suche oder Kategorie erstellen.
  • ✓Gewählte PDFs mit verständlichen Namen speichern.
  • ✓Unterstützte öffentliche Dateien und eine CSV mit URLs verwalten.

Ablauf

  1. 1Grenzen Sie die Suche auf arXiv nach Begriff, Kategorie und Zeitraum ein. Öffnen Sie die Ergebnisse oder Artikelliste.
  2. 2Öffnen Sie Grab All Files und scannen Sie die angezeigte Seite. Beginnen Sie dort und prüfen Sie Titel sowie Quell-URLs.
  3. 3Filtern Sie nach PDF und wählen Sie die Artikel. Prüfen Sie andere öffentliche Dateilinks getrennt auf benötigte unterstützte Formate.
  4. 4Prüfen oder bearbeiten Sie Titel und wählen Sie Dateinamen und Ordneroption. Speichern Sie Dateien oder ZIP und exportieren Sie die Dateiliste als CSV.
  5. 5Öffnen Sie die PDFs und prüfen Sie das Ergebnis. Notieren Sie Quell-URL und Artikelversion. Für große Bestände nutzen Sie die offiziellen arXiv-Dienste.

Den passenden arXiv-Zugang nutzen

Für Ihre Lesesammlung prüfen Sie eine gezielte Liste. Für große Bestände nutzen Sie den offiziellen Massenzugang; die API liefert Metadaten. Lesen Sie vor automatisierter Sammlung die Zugriffshinweise.

FAQ

Durchsucht die Erweiterung ganz arXiv nach meinem Thema?

Nein. Suchen und filtern Sie auf arXiv. Die Erweiterung scannt die gewählte Seite; sie ist keine wissenschaftliche Suchmaschine und kein vollständiger arXiv-Downloader.

Werden Links ohne .pdf erkannt?

arXiv-PDF-URLs wie /pdf/Artikel-ID können als PDF erkannt werden. Prüfen Sie Dateityp und URL vor dem Speichern.

Kann ich auch TeX, Daten und Code speichern?

Nur gefundene öffentliche Links in unterstützten Formaten sind auswählbar. Nicht jeder Artikel bietet diese Dateien; externe Repositorien können einen eigenen Besuch erfordern.

Kann ich Artikel kostenlos speichern?

Free speichert bis zu 10 Dateien je Vorgang; Sie können ihn wiederholen. Pro hebt das Dateilimit auf. Die kostenlose Seitensammlung speichert eine gewählte Seite als HTML; Pro bündelt mehrere ausgewählte Seiten.

Wozu dienen Titel, ZIP und CSV?

Prüfen oder bearbeiten Sie die Titel. Automatische Namen verwenden ohne brauchbaren Titel den Originalnamen. Typ- und Domainordner sind alternative Optionen. ZIP bündelt die Auswahl; CSV dokumentiert Dateiinformationen und URLs.

Ist dies ein offizielles arXiv-Werkzeug?

Nein. Das unabhängige Werkzeug ist nicht mit arXiv verbunden. Beachten Sie Zugriffshinweise und Nutzungsbedingungen der Artikel. Nutzen Sie die offizielle API für Metadaten und den offiziellen Massenzugang für große PDF- oder Volltextsammlungen.
