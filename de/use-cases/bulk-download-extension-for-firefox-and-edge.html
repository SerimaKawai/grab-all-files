Erweiterung für den Massen-Download in Chrome, Edge und Firefox: wo Sie sie erhalten und was in Firefox anders ist.

Grab All Files läuft in Chrome, in Edge (Chromium 111 oder neuer) und in Firefox 128 oder neuer. Beide Werkzeuge, der Datei-Downloader und „Seiten als HTML bündeln“, stehen in allen dreien zur Verfügung. In Firefox funktionieren vier Dinge anders oder fehlen, sie sind unten aufgeführt, damit Sie vor der Installation entscheiden können.

Was Firefox nicht kann

Diese vier Unterschiede wurden im Code der Erweiterung geprüft. Diese Seite behauptet nicht, dass es sonst keine Unterschiede gibt.

Website-Kopie oder ZIP: Es hängt vom Browser ab

„Seiten als HTML bündeln“ hat vier Formen der gespeicherten Datei. Drei sind in jedem Browser verfügbar; diese hier nur in Chrome und Edge, und die ZIP ist in Firefox der übliche Ersatz.

Firefox genügt, wenn

  • ✓Sie Dateien in den üblichen Download-Ordner speichern und nicht jedes Mal einen Ordner wählen müssen.
  • ✓Sie statt einer Website-Kopie in einem Ordner eine ZIP mit einzelnen HTML-Seiten nehmen können.
  • ✓Die gewünschten Dateien direkt auf der Seite verlinkt sind, der Scan sie also findet, ohne einen von einem Skript gestarteten Download abzufangen.

Chrome oder Edge passt besser, wenn

  • –Sie den Ordner wählen möchten, zum Beispiel einen freigegebenen Ordner auf einem Laufwerk.
  • –Sie die Ordnerstruktur der Website auf die Platte schreiben möchten, um per Klick auf Links darin zu blättern.
  • –Der Download von einer Schaltfläche gestartet wird, die JavaScript ausführt, ohne normalen Link zur Datei.

FAQ

Funktioniert Grab All Files in Firefox?

Ja, in Firefox 128 oder neuer. Vier Dinge sind anders: Sie können den Speicherordner nicht wählen, „Website-Kopie in einem Ordner“ ist nicht verfügbar, die Aktive Erfassung ist eingeschränkt und kann keine von JavaScript gestarteten Downloads abfangen, und „Seiten als HTML bündeln“ liest Seiten anders.

Wo speichert es Dateien in Firefox?

In einem Ordner GrabAllFiles in Ihrem Download-Ordner. Firefox lässt Sie in dieser Erweiterung den Zielordner nicht wählen.

Welche Edge-Versionen werden unterstützt?

Edge auf Chromium 111 oder neuer, installiert über Microsoft Edge Add-ons. Chrome wird auf derselben Chromium-Version unterstützt.

Auf wie vielen Geräten lässt sich eine Lizenz nutzen?

Auf bis zu 3 Geräten. Es ist ein Einmalkauf für US$19.99, ohne Abonnement.

Testen Sie Grab All Files in Ihrem Browser.

Die kostenlose Version speichert im Datei-Downloader bis zu 10 Dateien pro Download und beim Bündeln von Seiten eine gewählte Seite pro Durchgang; deren verlinkte Dateien werden mit „Nächste 10 Dateien speichern“ in Zehnergruppen gespeichert. Pro (19,99 $, einmalig, bis zu 3 Geräte) hebt das Download-Limit auf und bündelt mehrere Seiten in einem HTML.
