✓Scrolling pages

Save a page that keeps loading as you scroll: what is automatic, and what is not.

A timeline, a comment section, a product list or an image gallery adds items as you scroll, so a plain save gets only the first screenful. Grab All Files scrolls for you in some cases and not in others, with different limits. Find your case in the table first. None of it promises to reach the very end of every page, so check the result.

Check these yourself

  • –An ordinary list page stops after 10 scrolls by default, so a long product list may be cut off.
  • –Text drawn only on a canvas, or inside a closed Shadow DOM, is not read.
  • –A frame from another domain is read only after you allow it.
  • –Pages you cannot open in your own browser, such as ones that need a sign-in you do not have.

Saving a long timeline or comment section

  1. 1Open the page in the browser tab where you are signed in, if it needs a sign-in.
  2. 2Open Grab All Files and switch to “Combine pages into HTML”. Choose the current page only.
  3. 3Choose the look and the form, and start the save. The page scrolls on its own.
  4. 4At every 1,000 items it asks whether to continue. Answer, or leave it: after 10 minutes without an answer it saves what has been read so far.
  5. 5Open the saved file and compare its last item with the end of the live page, and the item count with the count the page shows, if it shows one.

For a list of files on a long page

On Free, scroll the page to the end yourself, then press the scan. The scan reads what is loaded.

Why “to the very end” is not promised

Each page decides for itself when to load more. The limits above are what let a run finish; they are not a guarantee that every item was reached.

So the last step matters. Compare the end of your saved file with the end of the live page. If it was cut off, run it again, or on the file side scroll further and rescan.

FAQ

Can it save an infinite-scroll page to the very end?

For feeds such as timelines and comment sections it scrolls until the feed ends. For other pages it stops after 10 scrolls by default. Always compare the end of the saved file with the live page.

Is there a limit on how many comments or posts it reads?

Not for feeds. It asks whether to continue after every 1,000 items. If nobody answers for 10 minutes, it saves what it has read.

Do I have to scroll myself?

When saving pages, no. When scanning for files on the Free plan, yes: it reads what is on screen. Pro scans scroll the page for you.

How many pages does the Pro scan follow?

6, 20 or 100 pages, according to the “Scroll time” setting (45, 90, 180 seconds). If you choose nothing, it is 100. A button reads the next 100.

Which sites are confirmed for comments and timelines?

X posts and replies, YouTube comments, Reddit, Bluesky and Yahoo! News comments. Other sites may work, but are not on this list.
