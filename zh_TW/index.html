找出隱藏檔案

支援 708 種檔案類型（副檔名）。偵測iframe內的PDF、延遲載入圖片、fetch/XHR回應、blob URL、CMS下載路徑、表單隱藏值，以及一般連結擷取工具會忽略的39種data-*屬性。更能深入 Shadow DOM / Web Components、SPA 水合資料（Next.js、JSON-LD）、Cache Storage / OPFS / IndexedDB 以及帶簽章的雲端儲存 URL（Cloudflare R2、Firebase、Supabase、Vercel Blob）。

⚙️

篩選功能

依副檔名、檔案大小、檔名、頁面標題或修改日期篩選結果。支援排序和手動重新排序，並可將URL複製為純文字。

🕸️

同站爬取

選擇深度（0–5或無限）造訪起始頁所在資料夾下的連結（從網站根目錄開始可涵蓋整站），找出子頁面中的PDF、檢視器URL與CMS文件路徑，每次執行最多100,000頁。還會讀取 sitemap.xml / robots.txt，並跟隨 JavaScript 選單（javascript:/onclick）、框架集、影像地圖與 GET 搜尋/分頁表單中的連結，到達沒有普通 HTML 連結的頁面。

常見問題

支援哪些檔案類型？

Grab All Files 支援 708 種檔案類型（副檔名），包括 PDF、Word、Excel、PowerPoint、圖片、ZIP 和 CSV。也能偵測分卷 / 多卷壓縮檔序列（.000/.001…、WinRAR .r00/.s00、WinZip .z01）並歸入壓縮檔類別。可依副檔名篩選，選擇所需檔案，一鍵全部下載。

可以免費使用嗎？

可以。免費版每次下載最多批次儲存 10 個檔案，並尋找相關頁面，讓您始終只選 1 頁儲存為 HTML。所選頁面內的圖片不受方案數量限制；該頁直接連結的檔案每次儲存 10 個，可在結果畫面用「儲存接下來的10個」繼續儲存。Pro 為 $19.99 一次購買，可解除檔案上限，並將多個頁面的正文合併成一個 HTML。

達到 10 個檔案的上限後會怎樣？

不會鎖定任何功能。免費版每次下載最多儲存 10 個檔案。下載完成後，在清單中選取接下來的檔案，再次點擊「儲存所選檔案」即可；重複操作即可逐批儲存其餘檔案。Pro 沒有每次下載的數量上限。

可以將多個網頁合併成一個 HTML 檔案嗎？

可以，Pro 支援此功能。免費版也會尋找並列出相關頁面，但只儲存您選擇的 1 頁。Pro 可選擇多個候選頁面，將其可讀正文合併成附統一目錄、可搜尋、可列印的一個 HTML。

Pro 費用是多少？

$19.99 USD 一次購買。永久授權，無訂閱。最多可在 3 台裝置上啟用；1 台裝置指一台電腦上的一個瀏覽器設定檔，在擴充功能的授權畫面中移除裝置即可釋出名額。

購買後如何啟用 Pro？

付款後，授權金鑰會立即顯示在購買完成頁面上，並同時以電子郵件寄送給您。開啟擴充功能，點擊右上角的「免費」（或開啟「⋯」選單並選擇「Pro·授權金鑰」），貼上金鑰後點擊「啟用」。右上角的標籤變為「Pro」即表示完成。

會傳送我的瀏覽資料嗎？

不會。檔案直接從來源網站下載到您的裝置。只有授權驗證和選用的假名化使用統計會到達我們的伺服器。使用統計預設關閉，僅在您明確同意後傳送；每筆事件只包含隨機安裝 ID、擴充功能版本、您的方案以及粗略的計數或標籤（例如找到的檔案數），絕不包含頁面內容、URL 或檔案名稱。詳情請參閱安全和權限。

支援哪些瀏覽器？

Google Chrome 和 Microsoft Edge（Chromium 111 或更新版本），以及 Mozilla Firefox（128 或更新版本）。

可以退款嗎？

作為立即交付的數位產品，原則上不接受退款。購買 Pro 前，可用免費版確認相容性並試用單頁 HTML 與每次 10 個檔案的下載流程。若技術故障導致無法使用，請在購買日起 30 天內聯絡我們以獲得全額退款。

需要登入的受保護網站也能使用嗎？

可以。擴充功能會使用您現有的瀏覽器工作階段，掃描您已獲授權存取的頁面，例如內網、LMS 入口網站和會員專區。它不會收集憑證，也不會繞過存取控制。

如何一次下載網頁上的所有檔案？

在 Google Chrome、Microsoft Edge 或 Mozilla Firefox 安裝 Grab All Files，開啟頁面（或貼上其 URL），擴充功能就會列出偵測到的檔案，包括隱藏在 iframe、檢視器、延遲載入、fetch/XHR 回應、blob URL 與 CMS 下載路徑背後的檔案。選取所需檔案，一鍵全部下載。

如何下載網站上的所有 PDF？

Grab All Files 能偵測頁面上的 PDF，包括嵌入 iframe 的 PDF 與 PDF 檢視器 URL，並可爬取同站連結，每次執行最多 100,000 頁。將結果篩選為 PDF，全選後批次下載，或在瀏覽器中於本機合併為一個 PDF。

批次下載檔案最好用的 Chrome 擴充功能是哪個？

Grab All Files 是適用於 Google Chrome、Microsoft Edge 與 Mozilla Firefox 的檔案批次下載工具。它能找到一般連結擷取工具遺漏的 PDF、Office 文件、圖片、ZIP 與 CSV，一鍵儲存所選檔案，還能合併 PDF、封存為 ZIP，並將檔案 URL 匯出為 CSV。免費版每次下載最多儲存 10 個檔案；$19.99 一次購買的 Pro 授權可解除此上限。

如何儲存網頁上的所有圖片？

Grab All Files 能偵測各類圖片，包括延遲載入圖片、CSS 背景圖片與 blob URL。將結果篩選為圖片類型，選取後一次全部下載，或將圖片 URL 清單匯出為 CSV。

可以不上傳到伺服器就合併 PDF 嗎？

可以。Grab All Files 在您的瀏覽器內於本機合併所選 PDF。不會上傳任何內容，檔案始終不會離開您的裝置。

能否處理大型檔案或長時間下載，並支援暫停與續傳？

可以。Grab All Files 內建下載管理器，支援並行數調整、暫停/續傳、自動重試以及一鍵重試失敗檔案，即使斷線也能讓大批量任務繼續。對於數GB的單一檔案或長時間無人看管的任務，您也可以匯出URL清單，交給專用下載管理器。

可以與 JDownloader 或 aria2 等下載管理器搭配使用嗎？

可以，兩者互補。Grab All Files 擅長在複雜或需登入的頁面上發現檔案（隱藏於 iframe、檢視器、JavaScript 與 CMS 路徑之後）。將結果匯出為 CSV 或URL清單，交給下載管理器進行大批量下載即可。

它能在 JavaScript 應用、僅登入頁面與有機器人防護的網站上運作嗎？

可以。它會在頁面建構後讀取 JavaScript 渲染的單頁應用（React、Next.js、Nuxt、Vue），在您已可開啟的頁面上使用您現有的瀏覽器工作階段，跟隨受 CSRF 保護的下載表單，並偵測 Cloudflare/WAF 機器人牆以引導復原。它透過檔案簽章而非僅憑副檔名確認檔案類型，且絕不繞過存取控制或安全防護。
