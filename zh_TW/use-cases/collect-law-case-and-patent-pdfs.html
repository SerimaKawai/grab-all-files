From a result page to a tidy folder

Narrow the list before you save, then choose how the files come out.

Steps

  1. 1Run your search in the database in your browser and set the display so that the result page shows as many rows as it allows.
  2. 2With the result page open, start “Bulk File Download” and scan. If the PDF is not on the result page but on each detail page, choose “Depth 1”.
  3. 3Narrow the list to PDF. Free reads only what is on the screen, so scroll a long result list to the end before scanning. Pro can scroll and follow the list's “Next” pages for you, by default up to 100 pages per scan.
  4. 4Choose the file name “PDF title”, and a folder sort that suits the work: by type, by site, or none.
  5. 5Save the selected files. On Free, one save takes up to 10 files; select the next ones and press save again.
  6. 6Export the file-information CSV. It has the URL, file name, title and the page each file came from, which you can keep as your source list.

A good fit

  • ✓A few dozen to a few hundred PDFs from result pages for one research question.
  • ✓You want the title in the file name instead of a code such as a gazette page number.
  • ✓You need a list of where each file came from.
  • ✓The database lets you look at the pages without a login, or you have an account and use it in the same browser.

Use the provider's own route instead

  • –Tens of thousands of documents, or a full year of decisions. Look for a bulk download or an API from the provider.
  • –Text that you need as structured data rather than as PDFs. The provider's data files are better.
  • –Anything you must keep updated: the extension does not watch for changes.
  • –Questions about whether a text is in force or how it applies. That is for a qualified person and the original source.

Terms of use and what the file is

Public databases set their own rules about automatic access, copying and re-use. Read them before you collect in volume, and keep the request rate modest by saving in batches. Grab All Files does not get around logins, limits or CAPTCHAs.

A PDF you save is a copy of what the site served on that day. Write the date you saved it next to the title in your list, and go back to the source when exact wording matters.

常見問題

Can I download all search results as PDFs?

You can save every PDF the scan finds on the pages it reads. On Free, a single save takes up to 10 selected files; Pro has no limit per save. Pro can also scroll a long result list and follow its “Next” pages. For very large sets, the provider's bulk download or API is the better tool.

Will the PDFs be named by title?

You can set the file name to the PDF's title. The title comes from the PDF itself, so check a few. If a PDF has no title, the file name is used.

Does it tell me whether a law or a case is current?

No. It saves files. Whether a text is in force, correct or relevant to your matter is not something it decides, and nothing on this page is legal advice.

Which databases does it support?

It is not built for one site. It finds files that a page links to or loads, so it works on any page you can open in your browser where the PDFs are present. Each site has its own rules for automated access.

Can I get a list of what I saved?

Yes. Export the file-information CSV: URL, file name, title, type, size, the date the server reports for the file, and the page it was found on. It has no column for the date you saved it, so add one.
