常見問題

Grab All Files 是網站複製工具嗎？

不是一般意義上的那種。它在瀏覽器內一次儲存一頁，也可以將網站的資料夾結構寫入您的電腦。它適合數量有限的頁面。若要處理數千頁，請使用桌面版網站複製工具。

需要登入的網站，哪種方法可行？

在瀏覽器內執行的工具，因為它會沿用您現有的登入狀態。Grab All Files 和單頁儲存擴充功能都是這樣運作。桌面版複製工具通常需要額外設定。

可以更新已儲存的副本，只下載有變更的部分嗎？

Grab All Files 無法做到。它有 Markdown 變更報告，會與您上次收集的同一網站比較，但仍會重新儲存頁面。桌面版網站複製工具才是為更新而設計的方法。

它和下載管理程式有什麼不同？

下載管理程式接收一份檔案連結清單，並能妥善地抓取。Grab All Files 則先找出檔案（包括頁面以指令碼載入的檔案），以清單顯示供您檢查，還能將頁面儲存為 HTML。
