檔案批次下載的流程

適合用途

  • ✓包含大量文件、媒體或壓縮檔連結的頁面。
  • ✓檔案透過JavaScript、檢視器或背景請求出現的頁面。
  • ✓需要以CSV記錄檔案URL、大小與來源頁面的稽核。
  • ✓不值得特地架設爬蟲的一次性收集作業。

工作流程

  1. 1在Chrome、Edge或Firefox開啟頁面，點擊工具列上的Grab All Files圖示。清單會針對目前開啟的頁面產生。
  2. 2點擊「掃描」。若要包含連結到的頁面，請先提高「深度」（「僅此頁面」只檢查本頁）；連結只會在起始頁面所在的資料夾內追蹤。
  3. 3用檔案類型清單、檔名／標題搜尋框和「詳細設定」（最小大小、「儲存名稱」）縮小清單，勾選需要的檔案。
  4. 4點擊「儲存所選檔案」。ZIP、「合併PDF」、「整理」和「匯出檔案資訊CSV」位於「其他操作」中。免費版每次下載最多儲存10個檔案。
  5. 5檔案較多時，選取接下來的檔案，再次點擊「儲存所選檔案」。失敗的列會顯示原因，解決存取問題後可重試。

常見問題

支援哪些檔案類型？

可偵測瀏覽器能存取的PDF、Office文件、圖片、ZIP、CSV和其他可下載回應。也能偵測分卷 / 多卷壓縮檔（如 .001、.r00、.z01）。

可以只選擇部分檔案嗎？

可以。依類型、名稱、標題或大小篩選，依任一欄排序，只勾選需要的列。點擊儲存按鈕之前不會儲存任何內容。

免費版有限制嗎？

免費版每次下載最多儲存10個選取的檔案，ZIP、「合併PDF」和CSV匯出也適用相同上限。若要繼續，請選取接下來的檔案並再次點擊同一按鈕，不會被鎖定。Pro（$19.99，一次購買，最多3台裝置）沒有每次下載的數量限制。

什麼都沒找到，或比預期少怎麼辦？

對於捲動時才載入更多內容的頁面，請在「掃描設定」中開啟「捲動到底並載入」後重新掃描。若檔案在連結到的頁面上，請提高「深度」。請在該網站暫停廣告封鎖器。若下載由頁面本身的JavaScript觸發，請在出現時使用「主動擷取」。

頁面需要登入怎麼辦？

請先在同一瀏覽器登入網站，再進行掃描。Grab All Files 使用您既有的登入工作階段；深度為1以上時，也會以相同登入狀態開啟連結到的頁面。它不會代您登入，也不會繞過存取限制。標示「需要登入」的列，請重新登入後再重試。

舊HTTP頁面也可以嗎？

可以。瀏覽器能開啟的HTTP和HTTPS頁面都可掃描。
