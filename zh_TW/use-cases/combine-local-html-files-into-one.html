把多個HTML檔案合併成一個HTML檔案。

手邊有存下來的網站、匯出的手冊，或裝滿 .html 頁面的 ZIP？在電腦上選擇資料夾或 ZIP，Grab All Files 就會把這些頁面合併成一個附目錄的 HTML 檔案。頁面依網站本身的連結順序排列，本機圖片會內嵌，頁面之間的連結變為檔案內跳轉。所有處理都在瀏覽器中完成，不會上傳任何內容。

工作流程

  1. 1開啟 Grab All Files，選擇「將網頁合併為 HTML」，並把來源切換為「從電腦資料夾」。
  2. 2選擇資料夾或 ZIP 檔案，也可以直接拖曳到頁面上。.html、.htm 和 .xhtml 檔案會依網站從 index.html 出發的連結順序排列，沒有被連結的頁面依名稱排在後面。
  3. 3檢查清單：保留或移除頁面，切換為「依檔名順序」，限定為「僅此資料夾」，或用「排除（每行一個）」排除路徑。再選擇用途：「保存網站」、「以單一檔案分享」、「列印或製作 PDF」或「交給 AI 閱讀」。
  4. 4產生 HTML。在報告中查看無法讀取的檔案、指向被排除頁面的連結，以及無法內嵌的圖片。

常見問題

可以免費試用嗎？

可以試用一頁：在資料夾模式下，Free 版每次把所選的一個 HTML 檔案轉換為內嵌本機圖片的獨立 HTML。要把多個 HTML 檔案合併成附共同目錄的一個檔案，需要 Pro（$19.99，一次性付費）。

我的檔案會被上傳到哪裡嗎？

不會。資料夾或 ZIP 在瀏覽器中讀取，合併後的 HTML 在您的裝置上產生。不需要任何網站權限，頁面引用的網路圖片也不會下載，而是保留為連結。

日本的舊網頁會變成亂碼嗎？

沒有宣告字元集的頁面，或宣告為 UTF-8 但實際是 Shift_JIS、EUC-JP、ISO-2022-JP 的頁面，會被自動辨識並正確讀取。如果所有頁面的 <title> 都相同，目錄會改用各頁面的標題。

圖片、PDF 和頁面間的連結會怎樣？

本機的 PNG、JPEG、GIF、WebP 和 AVIF 圖片會被內嵌。合併後各頁面之間的連結變為檔案內跳轉。PDF、Office、ZIP 等被連結的檔案，可以選擇「複製到 HTML 旁邊」（預設）、「嵌入到 HTML 中」（預設每個檔案上限 20 MiB，總計 100 MiB）或「保留為連結」。

可以讀取哪些檔案？

資料夾或 ZIP 中的 .html、.htm 和 .xhtml 檔案。「框架外框」（frameset）頁面預設會被排除，但框架內的頁面會被納入。MHT 檔案和 CHM 說明檔不能直接讀取，請先把 CHM 解壓縮為 HTML。

這和合併網站頁面的功能有什麼不同？

「瀏覽器頁面」模式從線上網站收集相關頁面。資料夾模式只處理電腦上已有的檔案，因此適合已封存的網站、離線手冊，以及不再於線上提供的文件。

為什麼結果中缺少某個頁面或圖片？

產生HTML後請查看報告：其中列出無法讀取的檔案、指向已排除頁面的連結以及無法嵌入的圖片。所選子資料夾以外或已排除路徑中的頁面不會包含，線上圖片保留為連結；框架版面頁面（frameset）預設略過，但框架內的頁面會保留。
