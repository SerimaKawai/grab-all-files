用途

請選擇與您的任務最接近的指南。每篇指南都介紹實際步驟、擴充功能中顯示的名稱，以及免費版的範圍：每次下載10個檔案，每次收集1個頁面。

產品型錄與資料表

依型號儲存要比較的產品型錄、規格書和資料表，標題中註明型號與文件類型，並保留來源連結。免費版每次下載最多10個檔案，全程在瀏覽器中完成。

IR與財務報告PDF

依會計年度和季度儲存一家發行人的業績公告、簡報和年報，在標題中註明期間並保留來源連結，方便日後核對。免費版每次下載最多10個檔案。

招標與申請文件

將一個招標或申請案件的公告、規格書、表單和問答依原格式儲存，依用途命名，並用檔案資訊CSV與官方清單核對。免費版每次下載最多10個檔案。

檔案連結匯出為CSV

將所選檔案的URL、檔名、標題、類型、大小、日期和來源頁面匯出為Excel可用的CSV清單。免費版每次最多匯出10列，全程在瀏覽器本機完成。

SDS與技術資料

依產品儲存SDS、TDS及技術PDF，名稱中註明語言和修訂日期，並保留來源URL。免費版每次下載最多10個檔案，全程在瀏覽器中完成。

arXiv PDF與研究檔案

掃描arXiv搜尋結果，篩選並選取所需論文PDF，依標題命名後儲存為檔案或ZIP，並用檔案清單CSV記錄來源URL。附實際擴充畫面與流程圖。

網頁表格轉CSV

將網頁中支援的HTML表格匯出為CSV或JSON，核對欄名、單位和註記後匯入Excel，或手動交給外部AI進行比較與分析。全程在瀏覽器中完成。

儲存並比較修訂前後資料

分別儲存修訂前後的資料，用與上次收集比較的變更報告找出變化的頁面，再對照原文或借助外部比較工具、AI核對步驟、條件及例外的變化。

PDF重新命名與整理

下載前用PDF的真實標題批次重新命名，再依類型或網站分到不同資料夾。標題可雙擊編輯，也可保留原始檔名。免費版每次下載最多儲存10個檔案。

政府公開文件與說明

把政府或公部門的制度說明頁面儲存為HTML，附件PDF、Word儲存為檔案，並記錄來源。免費版每次儲存1個頁面，檔案每次下載最多10個。

用Markdown重用Web資料

把收集的網頁正文匯出為單一Markdown、逐頁筆記或完整套件，並保留來源URL和擷取時間，用於研究、寫作，或手動重用到筆記工具與外部AI。

儲存業務手冊與知識文章

將允許查看與儲存的業務手冊及知識文章整理為易讀資料集。依章節HTML、內嵌PDF與階層選單文章選擇儲存方式，並準備向外部AI提問。

收集資訊·閱讀·AI分析

將網頁資訊收集為易讀的HTML，或匯出附來源的資料，再手動交給外部AI進行摘要、比較與條件擷取。附操作步驟、提問範例以及核對答案的方法。

將網頁合併為 HTML

Free 尋找相關候選並儲存所選的1個頁面。Pro 將多個所選頁面正文合併成一個附有統一目錄、可搜尋且可列印的 HTML 檔案。

電腦裡的 HTML 合為一個

把電腦上資料夾或ZIP裡的多個HTML檔案合併成一個附目錄的離線HTML。圖片內嵌，頁面間連結在檔案內跳轉，全程在瀏覽器中完成，不上傳任何檔案。

保留原樣的網頁儲存

將單一網頁或多個合併的網頁，連同原有版面、字型與圖片儲存成一個可離線開啟的 HTML 檔案。指令碼會被移除，也不會上傳任何內容。

下載所有PDF

在Chrome、Edge或Firefox中下載頁面或其所在資料夾中連結的PDF。可篩選結果，免費版每次最多儲存10個檔案，或在本機合併PDF。

批次下載圖片

偵測可見圖片、延遲載入圖片、CSS背景圖和blob圖片，將選取的圖片批次儲存、打包ZIP或匯出URL的CSV。免費版每次下載最多10個。

下載網頁檔案

找出網頁上的PDF、Office文件、圖片、ZIP和CSV，篩選清單後批次儲存或打包為ZIP。免費版每次下載最多儲存10個檔案，全程在瀏覽器本機處理。

內部入口和LMS

使用瀏覽器中既有的登入工作階段，從內網、LMS和會員區儲存您有權存取的檔案。不收集憑證，檔案直接儲存到您的裝置，不經過我們的伺服器。

本機合併PDF

將網頁上找到的PDF在瀏覽器內合併為一個檔案，無需上傳。可拖曳調整順序並指定檔名，也能保留原始PDF。免費版每次合併最多10個。

在瀏覽器中試用 Grab All Files。

免費版在檔案批次下載中每次下載最多儲存10個檔案，將網頁合併為HTML時每次儲存1個選定頁面；該頁面直接連結的檔案可用「儲存接下來的10個」每次儲存10個。Pro（$19.99，一次購買，最多3台裝置）沒有每次下載的上限，並可將多個頁面合併為一個HTML。
