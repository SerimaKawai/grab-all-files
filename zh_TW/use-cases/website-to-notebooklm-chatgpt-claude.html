擴充功能做到哪裡，從哪裡換您接手

擴充功能只在您的瀏覽器中讀取頁面，在您的電腦上轉換並儲存檔案。它不會登入 AI 服務，不會上傳任何內容，也不會替您提問。

您自己開啟喜歡的 AI 服務，將檔案加入為來源或附件，並在那裡提問。該服務接受哪些檔案類型和大小，以及如何處理上傳的檔案，都由該服務決定。上傳會員專屬網站的頁面之前，請先閱讀該服務目前的限制和隱私設定。

五個步驟的流程

  1. 1開啟網站的首頁，或您關心的區段的索引頁。如果頁面需要登入，請先在同一個瀏覽器中登入。
  2. 2開啟 Grab All Files，切換到「將網頁合併為 HTML」，並選擇收集來源：頁面的連結、網站地圖、相同的路徑，或貼上的網址清單。檢查候選清單，移除不想讀取的頁面。
  3. 3在輸出設定中，開啟「AI分析資料（附出處的Markdown）」並選擇輸出格式。「主要本文（預設）」會保留文章內容，並排除選單和廣告。
  4. 4執行收集。完成後，按「儲存AI分析ZIP」或「儲存為單一Markdown」。「複製給AI的提示詞」會複製一段現成的提示詞，可直接貼到聊天中。
  5. 5自己開啟 NotebookLM、ChatGPT、Claude 或其他服務，加入檔案並貼上提示詞。閱讀回答時，請對照它所引用頁面的 source_url 和 captured_at 加以核對。

AI 輸出設定

輸出格式、要擷取的文字和分割方式都在這裡選擇。

免費版也可以使用 AI 設定；免費版每次執行處理 1 個頁面，Pro 一次執行即可收集多個頁面。Markdown 中的每個頁面都附有 source_url 和 captured_at。chunks.jsonl 和 manifest.json 也有，因此任何一段文字都能追溯到它所屬的頁面和儲存的時間。

25 MB 設定代表什麼

預設的 25 MB 是將 Markdown 文字分割成多個檔案時的目標大小。它不是整個 ZIP 的上限，也不保證服務一定會接受這個大小的檔案。完整套件是由 corpus.md、chunks.jsonl、manifest.json、提示詞和易讀的 HTML 組成的 ZIP，因此比單純的 Markdown 大。

如果您使用的服務只接受較小的檔案，請在「依檔案大小」中調低目標。如果它限制可加入的檔案數量，請調高目標，或選擇單一 Markdown。合適的數字取決於該服務本身的限制，而這些限制可能會變動。

一個檔案就夠的情況

  • ✓網站只有數十頁，Markdown 遠低於該服務的大小限制。
  • ✓您想針對整個網站提問，並且只想管理一個來源。
  • ✓您之後不需要個別排除某些頁面。

依頁面或依大小分割的情況

  • ✓文字量超過該服務單一檔案所能接受的大小。
  • ✓您只想加入某些區段，或在網站更新後只替換其中一個頁面。
  • ✓您想要每個頁面一個檔案，讓回答能指向單一來源檔案。

常見問題

Grab All Files 會把我的頁面傳送給 NotebookLM、ChatGPT 或 Claude 嗎？

不會。它只會把檔案儲存在您的電腦上。上傳到 AI 服務是由您自己進行，之後這些檔案適用該服務自己的規則。

應該用單一 Markdown 檔案，還是每個頁面一個檔案？

想把整個小型網站當成一個整體來提問時，用一個檔案。當文字量超過該服務的檔案限制，或您想分別加入和替換頁面時，請用逐頁檔案，或調低大小目標。

預設的 25 MB 是什麼意思？

它是分割 Markdown 文字時的目標大小。它不是 ZIP 的大小上限，也不保證服務會接受該檔案。

我要怎麼知道 AI 的回答來自哪個頁面？

Markdown 中的每個頁面都有 source_url 和 captured_at，chunks.jsonl 和 manifest.json 也有。請找出該頁面，並將回答與原文比對。

需要登入的頁面也能讀取嗎？

可以，只要您在同一個瀏覽器中已登入該網站。它使用該登入工作階段，不會收集您的密碼。輸出的內容就是瀏覽器顯示的內容，因此上傳之前，請先想清楚誰會看到這些檔案。
