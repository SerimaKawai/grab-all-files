找出文章的三種方式

網站地圖

如果網站有公開網站地圖，其中列出的網址會成為候選。候選的數量可作為網站列出多少頁面的粗略參考。

相同的路徑

從部落格的清單頁開始，收集相同路徑下的頁面，例如部落格資料夾底下的所有頁面。網站的其他部分不會納入。

清單頁上的「下一頁」連結

標示為 next、「下一頁」、「較舊」等類似字樣的連結都會被辨識。會一頁一頁沿著清單找出候選，最多可找到 100,000 個候選。

候選、外觀與形式

候選清單會標明每個頁面是如何找到的。清單下方可選擇外觀和四種形式之一。

選擇儲存檔案的形式

形式您會得到適合
附目錄及搜尋的 HTML所有文章放在一個 HTML 檔案中，附有目錄和搜尋框在螢幕上閱讀，並在數百篇文章中找出某個詞句。這是各種形式中檔案最小的。
直向串接 HTML（適合列印）文章由上到下串接，列印時每篇之間會換頁列印或製作 PDF：使用瀏覽器的列印對話方塊另存為 PDF。Grab All Files 本身不會產生 PDF。

儲存整個部落格的步驟

  1. 1開啟部落格的清單頁，也就是顯示最新文章的那一頁，而不是單篇文章。如果網站需要登入，請先登入。
  2. 2開啟 Grab All Files，切換到「將網頁合併為 HTML」。在收集來源中，選擇網站地圖、「相同的路徑」或「追蹤本頁的連結」。
  3. 3等候候選清單出現。使用篩選和排除欄位，剔除不是文章的頁面：標籤頁、分類頁、作者頁、關於頁。
  4. 4使用 Pro 時，選取文章並排成想要的順序。不保證由新到舊，請自行確認順序。
  5. 5選擇外觀和形式後儲存。開啟儲存的檔案，檢查第一篇和最後一篇文章、文章數量，並搜尋一個您確定位於中間的詞句。

什麼時候這不是合適的工具

Grab All Files 在瀏覽器中逐篇讀取每篇文章，因此處理數千篇文章需要很長的時間，也會產生非常大的檔案。對於這種規模的新聞存檔，直接向伺服器要求頁面的桌面版網站複製軟體是更好的選擇，不過它看不到需要您登入才能看到的頁面。

若清單是隨著捲動才載入更多項目，而不是使用「下一頁」連結，那就是另一種情況。開始之前，請先閱讀無限捲動的指南。

常見問題

要怎麼一次儲存部落格的所有文章？

開啟部落格的清單頁，選擇網站地圖、「相同的路徑」或「追蹤本頁的連結」，從候選清單中剔除不是文章的頁面，再用 Pro 一次執行儲存。免費版每次執行儲存 1 篇文章，其餘的一次一篇陸續加入。

它會追蹤「下一頁」和「較舊的文章」連結嗎？

會。next、「下一頁」和「較舊」等連結都會被辨識並追蹤，以找出候選。使用 Pro 時，也能一次執行就儲存所有後續頁面。

可以把所有文章做成 PDF 嗎？

請儲存為「直向串接HTML（適合列印）」，在瀏覽器中開啟，再用列印對話方塊另存為 PDF。列印時每篇文章都會從新的一頁開始。

要怎麼在所有儲存的文章中搜尋？

請儲存為「附目錄及搜尋的HTML」。這一個 HTML 檔案附有目錄和搜尋框，可在瀏覽器中離線使用。

會包含留言嗎？

留言區是另一項作業。請參閱儲存與分析留言的指南；本頁只談文章本身。
