✓保持原樣

網頁長什麼樣,就儲存成什麼樣,存成一個 HTML 檔案。

選擇「保持原樣」後,Grab All Files 會將每個網頁連同它自己的樣式表、字型與圖片一併儲存:您在瀏覽器中看到的版面、配色與字體排印,都會放進一個獨立完整的 HTML 檔案。無論是把網站上的多個網頁,或電腦資料夾中的多個網頁合併在一起,每個網頁都在各自獨立的框架中保留自己的設計,並提供目錄與跨全部網頁的搜尋。指令碼會被移除,因此檔案可離線開啟,沒有追蹤,也沒有彈出視窗。

實際擴充畫面 — 保留原樣的網頁儲存

適合用途

  • ✓在網站改版、遷移或關閉之前,留下網站目前的樣貌。
  • ✓連同擷取時的網址與日期一起封存網頁,作為證據、法遵或稽核紀錄。
  • ✓將一組網頁(包括需要登入才能看到的)以一個隨處都能開啟的檔案寄給客戶或同事。
  • ✓將儲存下來的網站資料夾或匯出的說明網站,變成一個仍保持原貌的檔案。

工作流程

  1. 1開啟 Grab All Files,選擇「將網頁合併為 HTML」。可以從瀏覽器目前開啟的網頁開始,讓擴充功能自動尋找相關網頁,也可以將來源切換為「從電腦資料夾」,選擇包含 HTML 檔案的資料夾或 ZIP。
  2. 2確認要納入的網頁。在「外觀」中選擇「保持原樣」。合併同一網站的多個網頁時,請開啟「每頁重複的頁首、選單和頁尾只保留在第一頁」。「不保存廣告」預設為開啟,可讓檔案更小;如需保留廣告版位,請將其關閉。
  3. 3對於網頁,當系統要求存取提供樣式表與圖片的網站時,請予以允許。所有網站只會詢問一次。每個網頁都會在分頁中開啟並捲動到底部,讓捲動時才載入的圖片與內容也能納入。
  4. 4儲存。開啟 HTML 後,可透過目錄與搜尋在各網頁之間切換。每個網頁都會顯示來源網址與擷取時間。如果也想在檔案中列出未能保留的圖片或部分,請開啟「包含擷取資訊與失敗清單」。

誰需要保留網頁的原有設計

改版或遷移之前

網站團隊與代理商在重建網站、遷移到新系統或下線之前,逐頁留存網站目前的樣貌。

證據與法遵紀錄

法務、法遵與廣告審查團隊留存頁面、優惠或公告當時的呈現方式,每個網頁都附有來源網址與擷取時間。

即將關閉的網站與服務

研究人員、社群與愛好者留存即將終止營運的服務的網頁,存成不依賴網站持續上線的檔案。

分享需要登入的網頁

將入口網站、內部網路或客戶專區的網頁,以一個可在任何瀏覽器離線開啟的檔案,寄給沒有存取權限的人。

設計與競品參考

設計師與行銷人員依真實的字型、配色與間距,收集登陸頁與競品網站。

已儲存的網站與匯出的說明文件

網站備份資料夾,或匯出為 HTML 的說明與手冊頁面,可變成一個仍保持原貌的檔案。

儲存的檔案中包含什麼

版面、字型與配色

內嵌每個網頁的樣式表、所用的網頁字型(每種字型一種格式,優先 WOFF2)以及圖片,包括背景圖。

網頁呈現的樣子

在頁面穩定後、開啟任何選單之前擷取,因此關閉的選單會維持關閉。捲動時漸顯的內容會以可見狀態儲存。

稍後載入的內容

延遲載入的圖片、邊捲動邊變長的網頁、擴充功能有權讀取的網站的內嵌框架、Web 元件的樣式,以及由 SVG 精靈檔案繪製的圖示。

禁止外部引用的圖片

在其他地方請求時會被拒絕的圖片,會依原網頁載入它們的方式重新取得,每張只取得一次。

來源與擷取時間

在每個網頁標題下方顯示來源網址與擷取時間。指向其他已儲存網頁與檔案的連結,會在檔案內或儲存資料夾中開啟。

更小的檔案

多個網頁使用的同一個樣式表、圖片或字型只儲存一份。廣告聯播網的廣告版位預設不保存,也可以選擇保留。

常見問題

免費版可以使用「保持原樣」嗎?

可以。外觀選項不受方案限制。免費版每次執行儲存一個網頁,因此您可以將任一單一網頁依原有設計儲存成一個 HTML 檔案。若要將多個網頁合併成具有共用目錄的單一檔案,則需要 Pro($19.99,一次性付費,最多 3 台裝置)。

這和「另存新檔」或單頁儲存工具有什麼不同?

「另存新檔」會在 HTML 旁產生一個檔案資料夾,單頁儲存工具則是每個網頁產生一個檔案。Grab All Files 將多個網頁放進同一個檔案,並讓每個網頁保留在各自的框架中,因此不同網頁的設計不會互相衝突。共用的樣式表、圖片與字型只儲存一份,已儲存網頁之間的連結會在檔案內跳轉,還能一次搜尋全部網頁。

選單、分頁標籤和滑動圖片還能用嗎?

基於安全考量,網站的指令碼會被移除,因此依賴指令碼的功能,例如地圖、搜尋表單、登入或隨選載入的影片播放器,將無法運作。常見的元件已做處理,不需網站指令碼也能運作:以標準無障礙標記或 Bootstrap 建構的分頁標籤與收合面板可以展開和收合,輪播箭頭(Swiper、Slick、Splide、Glide、Flickity)可逐張切換。表單不會被送出。

捲動後才出現的圖片也會儲存嗎?

會。對於網頁,每個網頁在擷取前都會在分頁中開啟並捲動到底部,因此延遲載入的圖片,以及邊捲動邊增加內容的網頁都會被納入。當頁面不再變長,或「捲動時間」設定的時間(45、90 或 180 秒)用完時,捲動即停止。固定頁首、Cookie 提示與黏性標題在您捲動已儲存的檔案時,會出現在原本的位置。

儲存的檔案可以放心開啟與分享嗎?

檔案不含指令碼,且開啟時會封鎖對網際網路的請求,因此不會載入來自其他網站的追蹤器或廣告。連結中帶有的登入資訊會被移除。網頁在您自己的瀏覽器中收集並儲存到您的裝置,內容不會傳送到我們的伺服器。分享之前,請確認您有權分享所儲存的網頁。

什麼時候應該改選「整理為易讀格式」?

當您比較重視文字而非設計時,請選擇「整理為易讀格式」:例如閱讀長篇資料、列印、縮小檔案,或為 AI 工具準備 Markdown 與資料。它會以統一、簡潔的樣式顯示所有網頁,不含網站的頁首、選單與頁尾。「保持原樣」則用於依網頁原本的樣子保存與分享。
