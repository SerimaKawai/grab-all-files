依用途選擇表格的使用方式

在Excel中處理

匯入CSV後確認資料類型，再篩選、排序。需要時將識別編號保留為文字。

使用外部AI比較

選擇相關表格與來源資料，請求比較或摘要，並將回答和原表核對。

適合用途

  • ✓保留單位與註記，比較公開費用或條件表。
  • ✓在Excel中篩選公開清單並檢查項目。

工作流程

  1. 1開啟允許儲存的來源，在擴充功能中選擇「將網頁合併為 HTML」。選擇含表格的頁面。
  2. 2收集前啟用「AI分析資料（附出處的Markdown）」，選擇「逐頁Markdown」或「完整套件」並啟用「同時將表格匯出為CSV/JSON」。
  3. 3收集頁面後點擊「儲存AI分析ZIP」。將CSV、JSON表格檔案的欄名、儲存格、單位與註記和原表核對。
  4. 4將CSV匯入Excel，或手動將支援檔案交給外部AI。檢查日期、識別編號與分析結果。

針對表格提出問題

比較條件

請僅使用提供的值比較各列。保留單位與註記，引用來源，缺少值請明確標出，不要推測。

檢查清單

請找出重複項目與空白欄位，解釋判斷規則，並保留可核對的原始值。

常見問題

這是檔案清單CSV嗎？

不是。檔案清單CSV記錄檔案URL與資訊，此流程透過收集器的AI輸出擷取HTML表格資料。

任何表格都能變成CSV嗎？

選擇按頁面或完整套件並啟用表格匯出後，在支援範圍內擷取有意義的HTML表格。排版表格會被排除，不保證圖片或PDF畫面中的表格能轉為資料。

能直接輸出XLSX嗎？

此流程產生CSV、JSON。由您在Excel中開啟或匯入CSV，並非直接匯出XLSX。

可以從免費版開始嗎？

免費版收集所選1頁，Pro可選擇多個頁面正文。檔案在裝置上準備，由您交給Excel或外部AI。

需要登入的頁面怎麼辦？

收集直接使用您瀏覽器的登入狀態，不收集憑證。頁面顯示「需要登入」時，請點擊「開啟網站進行登入」，在開啟的分頁中登入後點擊「繼續」。仍需登入的頁面不會被儲存，結果中會顯示剩餘頁面數。

表格要捲動或點選「顯示更多」後才出現，怎麼辦？

請開啟「頁面缺少文字時：內容和 JavaScript 設定」，開啟「點選『顯示更多』以包含後續內容」，然後重新收集。以圖片形式繪製的表格或PDF中的表格不會匯出為CSV。
