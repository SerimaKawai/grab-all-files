儲存前要選擇的項目

備份可以用四種方式儲存

選擇「保持原樣」時，四種形式都可以使用。免費版在任何一種形式下，每次執行儲存 1 個頁面；Pro 每次執行可儲存多個頁面。

步驟（使用 Pro）

  1. 1如果網站需要登入，請先在同一個瀏覽器中登入，再開啟您要作為起點的頁面，通常是首頁或目錄頁。
  2. 2開啟 Grab All Files，切換到「將網頁合併為 HTML」。在收集範圍中，選擇尋找連結的頁面；若想更精確控制，可使用網站地圖或貼上網址清單。
  3. 3檢查候選清單。移除不需要的頁面，並將其餘頁面排成想要的順序。
  4. 4選擇「保持原樣」，形式選擇「依網站結構儲存到資料夾」（Firefox 請改用 ZIP），再選擇儲存資料夾並開始。
  5. 5如果頁面連結到 PDF 或 Office 檔案，這些檔案會儲存在頁面旁邊：Pro 每次執行最多 100 個，其餘的可在結果畫面按按鈕繼續儲存。

儲存下來的頁面會是什麼樣子

每個頁面都保留自己的樣式表、網頁字型和圖片。多個頁面共用的檔案只儲存一份。網站的指令碼會被移除，儲存的頁面在開啟時也不會連上網路，因此分頁標籤、收合面板和輪播箭頭仍可操作，但表單、需要向伺服器查詢的搜尋框，以及內嵌的影片播放器則無法使用。

儲存之前，每個頁面都會在分頁中開啟並捲動，讓延遲載入的圖片顯示出來。所花的時間依「捲動時間」設定而定（45、90 或 180 秒）。廣告預設不儲存，每個頁面重複出現的頁首、選單和頁尾也可以只保留在第一頁。

網站有數千頁時

Grab All Files 會在您的瀏覽器中逐頁讀取每個頁面。因此它能儲存登入後的頁面和 JavaScript 頁面。不過，數千頁的網站會需要很長的時間。如果您需要處理數千頁，或想只重新下載上次之後有變動的檔案，請使用桌面版的網站複製軟體。這類軟體直接向伺服器要求頁面，處理大型公開網站比較快，但看不到需要您登入或在瀏覽器中才會產生的頁面。

常見問題

儲存的副本可以點擊連結離線瀏覽嗎？

可以，使用「依網站結構儲存到資料夾」（Chrome 和 Edge）或「分頁HTML（ZIP）」。已儲存頁面之間的連結會開啟已儲存的檔案。指向未儲存頁面的連結，仍會連到線上的網站。

需要登入的頁面也能用嗎？

可以，只要您能在同一個瀏覽器中開啟。它使用您現有的登入狀態，不會儲存或傳送您的密碼。如果長時間執行期間登入工作階段過期，它會暫停；請重新登入後按「繼續」。

免費版可以儲存幾頁？

每次執行 1 頁。您可以一次一頁，持續加入同一份備份。Pro 一次執行即可儲存您選取的所有頁面。

會和原網站完全一樣嗎？

它儲存的是瀏覽器顯示的內容，連同網站的樣式和圖片。搜尋、表單和登入等伺服器端功能在副本中無法使用，串流影片也不會被儲存。

頁面會被傳送到別的地方嗎？

不會。頁面是在您的電腦上讀取並儲存。只有授權驗證，以及您開啟後的使用統計，才會傳到開發者的伺服器。
