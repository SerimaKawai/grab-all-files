常見問題

Grab All Files 能在 Firefox 上使用嗎？

可以，需要 Firefox 128 以上。有四項差異：無法選擇儲存資料夾、無法使用「依網站結構儲存到資料夾」、主動擷取受限且無法接住由 JavaScript 觸發的下載，以及「將網頁合併為 HTML」讀取頁面的方式不同。

在 Firefox 中檔案會儲存在哪裡？

儲存在「下載」資料夾內的 GrabAllFiles 資料夾。此擴充功能在 Firefox 中無法讓您選擇目的地資料夾。

支援哪些 Edge 版本？

Chromium 111 以上的 Edge，需從 Microsoft Edge 附加元件安裝。Chrome 也是支援相同的 Chromium 版本。

1 份授權可以在幾台裝置上使用？

最多 3 台裝置。這是 $19.99 的一次性購買，無需訂閱。
