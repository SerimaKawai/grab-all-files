工作流程

  1. 1開啟起始頁面，點擊Grab All Files圖示並選擇「將網頁合併為 HTML」。
  2. 2在「收集範圍」中保持「僅目前開啟的頁面」，或選擇「同時尋找連結到的頁面」以列出相關候選頁面。
  3. 3檢視候選頁面。免費版始終只選取1個頁面並每次儲存；Pro可以選取多個頁面，並移除或調整順序。
  4. 4選擇圖片和連結檔案選項後儲存。Pro會產生一個附統一目錄、可跨頁面搜尋的HTML。

常見問題

可以選擇要收錄哪些頁面嗎？

可以。免費版每次只選取1個候選，改選其他頁面時，選取項目會自動切換。Pro 可選取多個頁面、移除不需要的頁面並調整其餘頁面的順序。

結果可以離線閱讀嗎？

可以。您可以嵌入圖片以供離線閱讀，也可以保留線上參照以縮小 HTML 檔案。連結的文件也可與 HTML 檔案一併儲存。

頁面內容會上傳到你們的伺服器嗎？

不會。所有處理均在您的裝置上完成。免費版只儲存所選的1個候選頁面，Pro 則將多個所選頁面的正文合併。安全、驗證、權限、來源網站和裝置保護限制仍然適用。

這與 SingleFile 等單頁儲存工具有何不同？

單頁儲存工具保留目前開啟的頁面。Grab All Files 還會尋找相關候選。免費版儲存所選的1頁，Pro 將多個所選頁面中便於閱讀的正文合併成一個附有統一目錄的 HTML。

需要登入的頁面怎麼辦？

收集直接使用您瀏覽器的登入狀態，不收集憑證。頁面顯示「需要登入」時，請點擊「開啟網站進行登入」，在開啟的分頁中登入後點擊「繼續」。仍需登入的頁面不會被儲存，結果中會顯示剩餘頁面數。

為什麼儲存的頁面缺少部分文字？

有些網站要捲動或點擊後才顯示正文。請開啟「頁面缺少文字時：內容和 JavaScript 設定」，開啟「點選『顯示更多』以包含後續內容」，然後重新收集。如果儲存的是頁面的其他部分，可在那裡用「在螢幕上選擇」指定正文範圍。
