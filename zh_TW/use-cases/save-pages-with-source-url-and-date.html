如何自行確認儲存的檔案

  1. 1先用您打算使用的外觀與形式，儲存一兩個頁面。
  2. 2在瀏覽器中開啟檔案。若是附目錄及搜尋的形式，請在頁面標題下方查看網址和時間。
  3. 3若是 ZIP 與直向串接的形式，請在瀏覽器中檢視網頁原始碼，閱讀開頭的註解，或用文字編輯器開啟檔案。
  4. 4若是 Markdown，請開啟 .md 檔案，在每個頁面查看 source_url 與 captured_at。
  5. 5如果找不到網址或時間，請更換外觀或形式，或開啟擷取資訊選項，再儲存一次。

它能告訴您什麼，不能告訴您什麼

儲存的網頁會記錄它被讀取的位址和擷取的時間。這樣您就能再次找到原始網頁，並分辨舊的擷取與新的擷取。若您想比較同一網站在不同時間的擷取結果，「儲存與上次收集的變更報告」按鈕會寫出一份 Markdown 變更報告，依網址、標題和文字，比較該網站上次完成的收集與這次的收集。

電腦上的檔案和其他檔案一樣可以被編輯，因此網址與時間只是附在頁面上的備註，不是封印。本指南並未說明法院、稽核人員或平台會如何看待這樣的檔案。

常見問題

儲存的網頁會顯示原始網址嗎？

使用「保持原樣」與「附目錄及搜尋的HTML」時會：顯示在每個頁面標題下方，並附有擷取時間。使用「整理為易讀格式」時，沒有逐頁的網址行。

分頁 HTML 的 ZIP 中，網址記錄在哪裡？

使用「保持原樣」時，記錄在每個 HTML 檔案開頭的註解中，包含網址（url）與儲存日期，不會印在頁面上。

使用「整理為易讀格式」時能取得擷取時間嗎？

可以，請開啟「包含擷取資訊與失敗清單」。此選項預設為關閉，開啟後會在文件開頭加上擷取時間，但不會為每個頁面加上網址行。

哪種輸出會以機器可讀的形式保留網址與時間？

AI 用 Markdown 輸出。每個頁面都有 source_url 與 captured_at，chunks.jsonl 和 manifest.json 也都有這兩項。

列印出來會顯示來源嗎？

使用「保持原樣」與「附目錄及搜尋的HTML」時會：網址和時間印在每個標題下方。直向串接的形式只放在 HTML 註解中，所以列印出來看不到。
