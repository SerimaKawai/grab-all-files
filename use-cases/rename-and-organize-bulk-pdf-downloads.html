Actual extension screen — Name & organise PDF downloads

Names and folders serve different purposes

Recognise a document

Use a meaningful retrieved or edited title, or deliberately keep the original filename. Check the extension as well.

Find a file set

Group a mixed set by file type or source site. Choose no grouping when a single folder is easier.

Best for

  • ✓Keep PDFs from a manual or public-document list easier to recognise.
  • ✓Separate a mixed set of PDFs, spreadsheets and other files by format.

Workflow

  1. 1Open a page you are permitted to use and scan for downloadable files. Filter the results to the PDFs you need.
  2. 2Review each selected title and original filename. Edit a title when appropriate; keep the original name if it identifies the document better.
  3. 3Choose “Save as”: “Auto (title when usable)”, “Title” or “Original file name”. For “Organize”, choose “By type”, “By domain” or “No folders”.
  4. 4Download the selected files or create a ZIP. Check filenames, extensions, grouping, duplicates and any failed downloads in the saved result.

FAQ

Does it always find the PDF’s real title?

No. Available metadata or page headings may be missing or generic. Review the retrieved title; automatic mode can use the original filename when no useful title is found.

Does type grouping understand document subjects?

It groups files by file type or source domain, not by an inferred business subject. A PDF-only set is still the same file format.

Can I choose any destination folder in every browser?

Destination depends on browser support and download settings. Chromium can offer a folder picker; Firefox uses its Downloads/GrabAllFiles route. Check the resulting destination.

Can I keep using Free for a large set?

The naming and grouping settings are also available in Free. Free file actions use a 10-file per-run cap; select the next batch and repeat. Pro removes that file-count cap. Scan and review the results before saving.
