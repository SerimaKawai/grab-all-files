Download all PDFs

Find PDFs across a page or same-site crawl, including iframe viewers and CMS download routes. Bulk-download selected PDFs or merge them locally.

Bulk-download images

Detect visible, lazy-loaded, background, and blob images, then save selected image files in bulk or export their URLs.

Download files from a page

Find documents, images, ZIPs, CSVs, and hidden file responses on a page. Filter, select, bulk-download, ZIP, merge PDFs, or export CSV.

Internal portals & LMS

Use your existing browser session to collect authorized files from intranets, LMS portals, member areas, and document-heavy dashboards.

Merge PDFs locally

Select PDFs detected on a web page and merge them into one file locally, without uploading files to a server.
