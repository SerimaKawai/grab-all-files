What is kept, and what may not be

Kept

  • ✓Layout, colours and text sizes
  • ✓Images (when stored in the file)
  • ✓Fonts that could be fetched

May not be kept

  • The site’s own scripts (removed when saving)
  • Videos, maps and screens that need sign-in
  • Form submission, site search and anything that talks to the server

Workflow

  1. 1Open Grab All Files and choose “Combine pages into HTML”. Start from the page open in your browser, let the extension find related pages, or switch the source to “From a computer folder” for a folder or ZIP of HTML files.
  2. 2Check the pages to include. Under “Look”, choose “Keep the original look”. When you combine several pages from one site, turn on “Leave out the header, menu and footer that repeat on every page (keep the first)”. “Leave out ads” is on from the start for a lighter file; turn it off to keep the ad spaces.
  3. 3For web pages, allow access to the sites that serve the stylesheets and images when asked. It is asked once for all of them. Each page is opened in a tab and scrolled to the end so that images and content that load on scroll are included.
  4. 4Save. Choose how the result is put together before saving. For one page: “The page as it is (standard)” or “With contents and search”. For several pages (Pro): “With contents and search (standard)”, “As they are, one long page (printing and PDF)” or “Each page as it is (ZIP)”. With contents and search, each page keeps its original design inside a frame, with the source address and capture time above it, and the contents and search box move you between pages. “The page as it is” and “one long page” have no contents or search panel, so use your browser’s find (Ctrl+F / ⌘F); a single saved page keeps its source address and time in a comment at the top of the HTML. “Each page as it is (ZIP)” includes a contents page (index.html) linking to each page. To also list images or parts that could not be kept, choose “With contents and search” and turn on “Include the collection details and the list of failures”.

Who keeps pages with their original design

Before a redesign or migration

Web teams and agencies keep the current site as it looks today, page by page, before it is rebuilt, moved to a new system or taken offline.

Evidence and compliance records

Legal, compliance and advertising-review teams keep how a page, an offer or a notice was shown, with the source address and capture time on every page.

Sites and services that are closing

Researchers, communities and fans keep pages from a service that is shutting down, in a file that does not depend on the site still being online.

Sharing pages behind a login

Send pages from a portal, an intranet or a client area to someone without access, as one file they can open offline in any browser.

Design and competitor references

Designers and marketers collect landing pages and competitor sites as they appear, with the real fonts, colors and spacing.

Saved sites and exported help

A website backup folder, or help and manual pages exported as HTML, become one file that still looks like the original.

What is kept in the saved file

Layout, fonts and colors

Each page’s stylesheets are embedded, along with the web fonts it uses (one format per font, WOFF2 first) and its images, including backgrounds.

The page as it was shown

The page is captured after it settles, before any menu is opened, so closed menus stay closed. Content that fades in on scroll is saved visible.

Content loaded later

Lazy-loaded images, pages that grow as you scroll, frames from sites the extension may read, styles of web components, and icons drawn from SVG sprite files.

Images that block outside use

Images refused when requested from elsewhere are fetched again the way the original page loaded them, once each.

Source and capture time

Under each page title: the address it came from and when it was captured. Links to other saved pages and files open inside the file or the save folder.

A lighter file

The same stylesheet, image or font used on many pages is stored once. Ad spaces from ad networks are left out by default, and you can keep them if you prefer.

FAQ

Can I use “Keep the original look” on the Free plan?

Yes. The look option is not limited by plan. Free saves one page per run, so you can keep any single page with its original design as one HTML file. Combining several pages into one file with a shared table of contents requires Pro ($19.99, one-time, up to 3 devices).

How is this different from saving with “Save page as” or a single-page saver?

“Save page as” writes a folder of files next to the HTML, and single-page savers produce one file per page. Grab All Files puts many pages in one file and keeps each page in its own frame, so the designs of different pages do not clash. Shared stylesheets, images and fonts are stored once, links between the saved pages jump inside the file, and you can search all pages at once.

Will menus, tabs and sliders still work?

The site’s scripts are removed for safety, so features that need them, such as maps, search forms, logins or video players that load on demand, do not run. Common parts are made to work without the site’s scripts: tabs and accordions built with standard accessibility markup or Bootstrap open and close, and carousel arrows (Swiper, Slick, Splide, Glide, Flickity) move one slide at a time. Forms are never submitted.

Does it include images that only appear when you scroll?

Yes. For web pages, each page is opened in a tab and scrolled to the end before it is captured, so lazy-loaded images and pages that add more content as you scroll are included. Scrolling stops when the page stops growing or when the time set in “Scroll time” runs out (45, 90 or 180 seconds). Fixed headers, cookie notices and sticky headings appear in their original positions as you scroll the saved file.

Is the saved file safe to open and share?

Scripts from the original site are removed. The only script left is a small Grab All Files helper that makes tabs, panels and carousel arrows work, and the file blocks requests to the internet when opened, so it does not load trackers or ads from other sites. Login details found in links are removed. The pages are collected in your own browser and saved on your device; their content is not sent to our servers. Before sharing, check that you are allowed to share the pages you saved.

When should I choose “Easy to read” instead?

Choose “Easy to read” when you want the text more than the design: for reading long material, printing, smaller files, or preparing Markdown and data for an AI tool. It shows every page in one clean style without the site’s header, menus and footer. “Keep the original look” is for keeping and sharing pages as they appeared.

What if a page needs me to sign in?

Collection uses your own browser session and does not collect credentials. If a page is marked “Sign-in needed”, press “Open the site to sign in”, sign in in that tab, then press “Resume”. Pages that still need a sign-in are not saved, and the result says how many were left out.
