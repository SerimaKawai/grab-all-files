FAQ

Does it detect lazy-loaded images?

Yes. It checks DOM attributes, srcset values, background images, blob URLs, and network-discovered file responses.

Can I download only some image types?

Yes. Use extension filters for file extension, size, name, or source page.

Can I export image URLs instead of downloading?

Yes. Export the detected file list as CSV.
