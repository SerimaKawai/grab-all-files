How the file downloader works

Best for

Workflow

  1. 1Open the gallery or page and click the Grab All Files icon in the toolbar.
  2. 2For galleries and infinite-scroll pages, Pro scrolls to the end by itself; if it needs longer, choose a “Scroll time” (Normal 45 s, Long 90 s, Thorough 180 s) in “Scan options”. On the free plan, scroll to the end yourself first. Then press “Scan”.
  3. 3Filter the list to images such as JPG, PNG, WebP, GIF or SVG. In “Details”, set a minimum “Size” to hide thumbnails and icons.
  4. 4Tick the images and press “Save selected files” (Free: up to 10 per download), or use “More actions” for ZIP, “Organize” by type or domain, or “Export File Info CSV”.

FAQ

Does it detect lazy-loaded images?

Yes, once they are in the page. It reads image attributes, srcset values, CSS backgrounds, blob URLs and network responses. Images that appear only after scrolling: Pro scrolls the page to load them by itself; on the free plan, scroll to the end yourself before scanning.

Can I download only some image types?

Yes. Use the file-type list, the search box for names and the minimum “Size” in “Details”, then sort by size to find the full-size files.

Why are thumbnails or tiny icons listed?

Pages often use separate small files for thumbnails, icons and logos. Set a minimum “Size” in “Details” to hide them; files whose size is unknown stay in the list. Compare size and URL to pick the full-size version.

Can I export image URLs instead of downloading?

Yes. Tick the images and use “Export File Info CSV” under “More actions”. Free exports up to 10 rows per operation; tick the next rows and export again.

Is there a limit on images in the free version?

Free saves up to 10 selected images per download or ZIP. Select the next images and press the button again to continue; nothing is locked. Pro ($19.99 one-time, up to 3 devices) removes the per-download limit.
