FAQ

Is this an online PDF merge service?

No. The merge runs in the browser. Files are not uploaded to Grab All Files servers.

Can I control merge order?

Yes. Sort or manually reorder the selected PDF list before merging.

Can I download the original PDFs too?

Yes. You can save originals, build a ZIP, and merge selected PDFs.
