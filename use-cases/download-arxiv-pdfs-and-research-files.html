Workflow

  1. 1Use arXiv search to narrow the topic, category and date range. Open the results or paper list you want to work with.
  2. 2Open Grab All Files and scan the displayed page. Start with that page, then review the detected file titles and source URLs.
  3. 3Filter by PDF and select the papers you need. Review other public file links separately and choose only supported files relevant to your work.
  4. 4Check or edit titles, choose title-based saving and a folder option. Save the selection as files or ZIP; export the file-list CSV for a record of the URLs.
  5. 5Open the saved PDFs and review the results. Keep the source URL and paper version in your notes. For a large corpus, use arXiv’s official bulk services.

Use the right arXiv access route

For a personal reading set, review a focused list and save the papers you need. For large collections, use arXiv’s official bulk access; its API provides metadata. Read the access guidance before automated collection.

FAQ

Does the extension search all of arXiv for my topic?

No. Search and refine the results on arXiv itself. The extension scans the page you choose; it is not a scholarly search engine or a complete arXiv downloader.

What about PDF links without a .pdf extension?

arXiv PDF URLs such as /pdf/paper-id can be recognized as PDFs. Review the detected file type and URL before saving.

Can I save TeX, datasets and code too?

Only public links that are found and match a supported file format can be selected. TeX sources, datasets and code are not present or downloadable for every paper; following an external repository may require a separate visit.

Can I save these papers for free?

Free saves up to 10 selected files per run, and you can repeat the operation. Pro removes that file-count cap. Free page collection saves one chosen page as HTML; Pro can combine multiple selected pages.

How do title names, ZIP and CSV help?

Review or edit a title before saving. Automatic naming can fall back to the original name when no useful title is available. Type and domain folders are alternative options. ZIP packages selected files; CSV records their file information and URLs.

Is this an official arXiv tool?

No. Grab All Files is an independent tool, not affiliated with arXiv. Follow arXiv’s access guidance and each paper’s reuse terms. Use the official API for metadata, and official bulk access for large-scale PDF or full-text collection.
