页面收集模式

将相关网页整合为一个易于阅读的 HTML 文件。

从浏览器中当前打开的页面开始。Grab All Files 会查找相关页面，让您检查将要收录的内容，并将所选页面合并为一个带目录、可搜索、可打印的 HTML 文件。

查找并检查页面

可使用自动发现快速开始，也可通过详细设置指定菜单、路径、站点地图和粘贴的 URL 列表。收集前可检查页面标题，并删除不需要的页面或调整顺序。

保存为一个便于携带的文档

可嵌入图片以便离线阅读，也可保留在线引用以减小文件大小。链接的 PDF、Office 文件及其他文档也可与 HTML 一并保存。

按需导出 AI 就绪数据

可生成来源可追溯的 Markdown、JSONL、manifest 和表格数据，用于分析。页面收集和 HTML 生成均在您的设备本地运行；页面内容不会上传到我们的服务器。

何时使用

Grab All Files 与其他工具如何配合

Grab All Files 专注两项任务：在复杂或需登录的页面中查找文件，以及将所选多个页面整理为一个易读的HTML。下载管理器和整站复制工具负责流程中的其他部分。

🔎

在复杂或需登录页面上发现文件

隐藏在 iframe、查看器、JavaScript、登录和 CMS 路径之后的 PDF、图片和文档。Grab All Files 会检测它们，支持筛选和选择，然后在本地一键批量下载、合并 PDF、生成 ZIP 并导出 CSV。这正是 Grab All Files 的专长。

🚚

批量下载已知 URL 或超大文件

对于超大文件，或需要队列管理与续传的长时间无人值守批量任务，专用下载管理器（JDownloader、aria2）更合适。Grab All Files 负责发现文件并导出 URL 列表，繁重下载交给它。

🗺️

需要完整、原样地离线复制整个网站吗？

如果您需要一个保留原始页面、链接和结构且可正常浏览的副本，请使用 HTTrack 等网站复制工具。Grab All Files 则是将所选页面中便于阅读的内容合并为一个带目录的 HTML 文件，并不会创建像素级还原的网站镜像。

常见问题

支持哪些文件类型？

Grab All Files 支持 708 种文件类型（扩展名），包括 PDF、Word、Excel、PowerPoint、图片、ZIP 和 CSV。还能检测分卷 / 多卷压缩包序列（.000/.001…、WinRAR .r00/.s00、WinZip .z01）并归入压缩文件类别。可按扩展名筛选，选择所需文件，一键全部下载。

可以免费使用吗？

可以。所有功能均免费；单次下载最多保存20个文件，其余文件可重复下载。网页收集会把所有选定页面保留在同一次收集中，每 10 页确认是否继续，完成后保存一个最终 HTML。Pro（$19.99 一次性购买）可解除下载数量限制并跳过这些确认。

可以将多个网页合并为一个 HTML 文件吗？

可以。打开扩展程序并选择“将网页合并为 HTML”。它会查找相关页面，供您检查列表，并将所选页面保存为一个带目录、可搜索、可打印的 HTML 文件。Free 在同一次收集中每 10 页确认一次；Pro 跳过这些确认并继续到您选择的安全上限。

会发送我的浏览数据吗？

不会。文件直接从源网站下载到您的设备。只有许可证验证和默认关闭且仅在明确同意后发送的可选假名化使用统计会到达我们的服务器，绝不包含页面内容、URL或文件名。

Google Chrome 和 Microsoft Edge（Chromium 111 或更高版本），以及 Mozilla Firefox（128 或更高版本）。

能否处理大文件或长时间下载，并支持暂停和续传？

可以。Grab All Files 内置下载管理器，支持并行数调节、暂停/续传、自动重试以及一键重试失败文件，即使断网也能让大批量任务继续。对于数GB的单个文件或长时间无人值守的任务，你还可以导出URL列表，交给专用下载管理器。

可以，二者互为补充。Grab All Files 擅长在复杂或需登录的页面上发现文件（隐藏于 iframe、查看器、JavaScript 和 CMS 路径之后）。将结果导出为 CSV 或URL列表，交给下载管理器进行大批量下载即可：发现交给 Grab All Files，繁重下载交给下载管理器。

它能在 JavaScript 应用、仅登录页面和有机器人防护的网站上工作吗？

可以。它会在页面构建后读取 JavaScript 渲染的单页应用（React、Next.js、Nuxt、Vue），在你已可打开的页面上使用你现有的浏览器会话，跟随受 CSRF 保护的下载表单，并检测 Cloudflare/WAF 机器人墙以引导恢复。它通过文件签名而非仅凭扩展名确认文件类型，且绝不绕过访问控制或安全防护。
