找出文章的三种方式

站点地图

如果网站发布了站点地图，其中列出的网址就会成为候选。候选数量可以大致说明网站列出了多少页面。

相同的路径

从博客的列表页开始，收集同一路径下的页面，例如博客文件夹下的所有内容。网站的其余部分不会收集。

列表页上的“下一个”链接

标记为 next、“下一页”、“更早的文章”等的链接都会被识别。程序会逐页跟随列表来找出候选。最多可找到100,000个候选。

候选、外观和形式

候选页面会连同各自的发现方式一起列出。在其下方选择外观和四种形式之一。

选择保存文件的形式

形式得到的内容适合的用途
带目录和搜索的HTML所有文章放在一个HTML文件里，带目录和搜索框在屏幕上阅读，并在数百篇文章中查找某个词句。四种形式中体积最小。
纵向拼接HTML（适合打印）文章从上到下拼接，打印时每篇之间分页打印或生成PDF：使用浏览器的打印对话框并另存为PDF。Grab All Files 本身不会生成PDF。
Markdown一个Markdown文件，或每篇文章一个，每页都带有source_url和captured_at笔记、个人存档，或把文本交给您自己选择的AI服务。请参阅下面的Markdown指南。

对于文章，“整理为易读格式”通常是合适的外观：速度更快，文件也更小。“保持原样”会保留每篇文章的版式、字体和图片，代价是运行时间更长、文件更大。

保存整个博客的步骤

  1. 1打开博客的列表页，即显示最新文章的那一页，而不是某篇文章。如果网站需要登录，请先登录。
  2. 2打开 Grab All Files，切换到“将网页合并为 HTML”。在收集来源中，选择站点地图、“相同的路径”或“跟随本页的链接”。
  3. 3等待候选列表出现。使用筛选和排除框去掉不是文章的页面：标签页、分类页、作者页、关于页。
  4. 4使用 Pro 时，选择文章并排成想要的顺序。不能保证最新的在最前面，请检查顺序。
  5. 5选择外观和形式，然后保存。打开保存的文件，检查第一篇和最后一篇文章、数量，并搜索一个您确定在中间部分的词句。

不适合用本工具的情况

Grab All Files 在浏览器中读取每篇文章，因此处理数千篇文章需要很长时间，并会生成非常大的文件。对于这种规模的新闻存档，直接向服务器请求页面的桌面版网站复制工具是更好的选择，不过它看不到需要您登录的页面。

如果列表是在滚动时加载更多内容，而不是使用“下一个”链接，那是另一种情况。开始之前，请阅读关于无限滚动的指南。

常见问题

如何一次保存博客的所有文章？

打开博客的列表页，选择站点地图、“相同的路径”或“跟随本页的链接”，从候选列表中去掉不是文章的页面，然后使用 Pro 一次操作保存。使用免费版时每次保存1篇文章，其余的一次添加一篇。

会跟随“下一个”和“更早的文章”链接吗？

会。next、“下一个”、“更早的文章”等链接都会被识别并跟随，以找出候选。使用 Pro 时，还可以一次操作保存所有后续页面。

能把所有文章做成PDF吗？

保存为“纵向拼接HTML（适合打印）”，在浏览器中打开，用打印对话框另存为PDF。打印时每篇文章都从新的一页开始。

如何在所有已保存的文章中搜索？

保存为“带目录和搜索的HTML”。这一个HTML文件带有目录和搜索框，可以在浏览器中离线使用。

会包含评论吗？

评论区是另一项任务。请参阅关于保存和分析评论的指南；本页讲的是文章本身。
