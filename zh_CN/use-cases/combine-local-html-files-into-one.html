适合用途

  • ✓多年前保存或镜像下来的网站（index.html 加几十个页面），想合成一个文件来保存、阅读或搜索。
  • ✓以 HTML 页面文件夹形式导出的帮助文件、产品手册或技术文档。
  • ✓把多页 HTML 文档作为一个附件分享，或一次性打印成 PDF。
  • ✓把整套本地文档作为带出处的 Markdown 或数据包，一次交给 AI 工具。

工作流程

  1. 1打开 Grab All Files，选择“将网页合并为 HTML”，并把来源切换为“从电脑文件夹”。
  2. 2选择文件夹或 ZIP 文件，也可以直接拖到页面上。.html、.htm 和 .xhtml 文件会按网站从 index.html 出发的链接顺序排列，没有被链接的页面按名称排在后面。
  3. 3检查列表：保留或移除页面，切换为“按文件名顺序”，限定为“仅此文件夹”，或用“排除（每行一个）”排除路径。再选择用途：“保存网站”、“作为一个文件分享”、“打印或生成 PDF”或“交给 AI 阅读”。
  4. 4生成 HTML。在报告中查看无法读取的文件、指向被排除页面的链接，以及无法内嵌的图片。

常见问题

可以免费试用吗？

可以试用一页：在文件夹模式下，Free 版每次把所选的一个 HTML 文件转换为内嵌本地图片的独立 HTML。要把多个 HTML 文件合并成带统一目录的一个文件，需要 Pro（$19.99，一次性付费）。

我的文件会被上传到哪里吗？

不会。文件夹或 ZIP 在浏览器中读取，合并后的 HTML 在您的设备上生成。不需要任何网站权限，页面引用的网络图片也不会下载，而是保留为链接。

日本的旧网页会变成乱码吗？

没有声明字符集的页面，或声明为 UTF-8 但实际是 Shift_JIS、EUC-JP、ISO-2022-JP 的页面，会被自动识别并正确读取。如果所有页面的 <title> 都相同，目录会改用各页面的标题。

图片、PDF 和页面间的链接会怎样？

本地的 PNG、JPEG、GIF、WebP 和 AVIF 图片会被内嵌。合并后各页面之间的链接变为文件内跳转。PDF、Office、ZIP 等被链接的文件，可以选择“复制到 HTML 旁边”（默认）、“嵌入到 HTML 中”（默认每个文件最大 20 MiB，总计 100 MiB）或“保留为链接”。

可以读取哪些文件？

文件夹或 ZIP 中的 .html、.htm 和 .xhtml 文件。“框架外壳”（frameset）页面默认被排除，但框架内的页面会被包含。MHT 文件和 CHM 帮助文件不能直接读取，请先把 CHM 解压为 HTML。

这和合并网站页面的功能有什么不同？

“浏览器页面”模式从在线网站收集相关页面。文件夹模式只处理电脑上已有的文件，因此适合已存档的网站、离线手册，以及不再在线的文档。
