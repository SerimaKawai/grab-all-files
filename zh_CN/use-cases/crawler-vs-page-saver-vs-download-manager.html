  • –以流媒体方式播放、而不是作为文件链接的视频。
  • –您自己的浏览器打不开的页面。

常见问题

Grab All Files 是网站复制工具吗？

不是通常意义上的。它在您的浏览器内一次保存一个页面，并且可以把网站的文件夹结构写到您的电脑上。它适合有限的一组页面。对于数千页，请使用桌面版网站复制工具。

哪种方式适用于需要登录的网站？

在您的浏览器内运行的工具，因为它使用您已有的登录状态。Grab All Files 和单页保存扩展就是这样工作的。桌面版复制工具往往需要额外设置。

能刷新已保存的副本，只下载有变化的部分吗？

Grab All Files 不行。它有一份 Markdown 变更报告，会与您上一次对同一网站的收集对比，但它会重新保存页面。桌面版网站复制工具才是为更新而设计的方式。

它与下载管理器有什么不同？

下载管理器接收一列文件链接并很好地获取它们。Grab All Files 则先找出文件，包括页面通过脚本加载的文件，以列表形式显示供您检查，并且还可以把页面保存为 HTML。
