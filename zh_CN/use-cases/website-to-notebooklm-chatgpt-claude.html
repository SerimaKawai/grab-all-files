扩展程序做到哪里，从哪里开始由您操作

扩展程序只在浏览器中读取页面，在您的电脑上转换并保存文件。它不会登录 AI 服务，不会上传任何内容，也不会替您提问。

您自己打开喜欢的 AI 服务，把文件添加为资料来源或附件，然后在那里提问。该服务接受哪些文件类型和大小，以及如何处理上传的文件，都由服务本身决定。从仅限会员的网站上传页面之前，请先阅读该服务当前的限制和隐私设置。

操作流程，共五步

  1. 1打开网站首页，或您关心的栏目的目录页。如果页面需要登录，请先在同一个浏览器中登录。
  2. 2打开 Grab All Files，切换到“将网页合并为 HTML”，选择从哪里收集：页面的链接、站点地图、同一路径，或粘贴的网址列表。检查候选列表，去掉不想读取的页面。
  3. 3在输出设置中，打开“AI分析数据（带出处的Markdown）”并选择输出格式。“主要正文（默认）”会保留文章正文，不包含菜单和广告。
  4. 4运行收集。完成后，按“保存AI分析ZIP”或“保存为单个Markdown”。“复制给AI的提示词”会复制一段现成的提示词，可以粘贴到聊天中。
  5. 5自己打开 NotebookLM、ChatGPT、Claude 或其他服务，添加文件并粘贴提示词。查看回答时，请对照回答所依据页面的 source_url 和 captured_at 进行核对。

25 MB 设置的含义

默认的 25 MB 是把 Markdown 文本拆分成多个文件时的目标大小。它不是整个 ZIP 的上限，也不保证服务会接受这么大的文件。完整包是包含 corpus.md、chunks.jsonl、manifest.json、提示词和易读 HTML 的 ZIP，因此比单独的 Markdown 更大。

如果您使用的服务只接受较小的文件，请在“按文件大小”下调低目标值。如果它限制可添加的文件数量，请调高目标值，或选择单个 Markdown 文件。合适的数值取决于服务自身的限制，而这些限制可能会变化。

常见问题

Grab All Files 会把我的页面发送给 NotebookLM、ChatGPT 或 Claude 吗？

不会。它只在您的电脑上保存文件。上传到 AI 服务由您自己完成，之后这些文件适用该服务自己的规则。

应该用单个 Markdown 文件，还是每页一个文件？

想把一个小型网站作为整体来提问时，用一个文件。当文本超过服务的文件限制，或您想分别添加和替换页面时，用按页文件或更小的目标大小。

默认的 25 MB 是什么意思？

它是拆分 Markdown 文本时的目标大小。它不是 ZIP 的大小限制，也不保证服务会接受该文件。

怎样知道 AI 的回答来自哪个页面？

Markdown 中的每个页面都有 source_url 和 captured_at，chunks.jsonl 和 manifest.json 中也有。查到该页面，把回答与原文对照即可。

能读取需要登录的页面吗？

可以，只要您在同一个浏览器中已登录该网站。它使用该会话，不会收集您的密码。输出内容就是浏览器显示的内容，因此上传前请考虑谁会看到这些文件。
