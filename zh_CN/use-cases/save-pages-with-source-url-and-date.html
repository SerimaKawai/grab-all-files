如何自己检查保存的文件

  1. 1先用打算使用的外观和形式保存一两个页面。
  2. 2在浏览器中打开文件。在带目录和搜索的形式中，查看页面标题下方的网址和时间。
  3. 3对于 ZIP 和纵向拼接形式，在浏览器中查看页面源代码并阅读顶部的注释，或用文本编辑器打开文件。
  4. 4对于 Markdown，打开.md 文件，在每个页面处查找 source_url 和 captured_at。
  5. 5如果没有网址或时间，请更换外观或形式，或开启收集信息选项，然后重新保存。

它能告诉您什么，不能告诉您什么

保存的页面会记录读取它的地址和获取它的时间。这让您可以再次找到原页面，并区分旧的获取和新的获取。如果您想随时间对比同一网站的多次获取，“保存与上次收集的变更报告”按钮会写出一份 Markdown 变更报告，按网址、标题和文本对比该网站上一次完成的收集与新的收集。

电脑上的文件和其他文件一样可以编辑，因此网址和时间只是随页面保存的一条记录，而不是封条。本指南不涉及法院、审计人员或平台会如何看待这样的文件。

常见问题

保存的页面会显示原网址吗？

使用“保持原样”和“带目录和搜索的HTML”时会：位于每个页面标题的下方，同时显示获取时间。使用“整理为易读格式”时，每个页面没有网址行。

在分页 HTML 的 ZIP 中，网址保存在哪里？

使用“保持原样”时，保存在每个 HTML 文件顶部的注释中，包括网址和保存日期。它不会打印在页面上。

使用“整理为易读格式”时能得到获取时间吗？

能，请开启“包含收集信息和失败列表”。该选项默认关闭，它会在文档顶部加上获取时间，而不是为每个页面添加网址行。

哪种输出会以机器可读的形式保留网址和时间？

AI Markdown 输出。每个页面都有 source_url 和 captured_at，chunks.jsonl 和 manifest.json 中也有这两项。

打印件上会显示来源吗？

使用“保持原样”和“带目录和搜索的HTML”时会：网址和时间打印在每个标题下方。使用纵向拼接形式时，它们只在 HTML 注释中，因此打印件上不会显示。
