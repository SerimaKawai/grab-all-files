常见问题

Grab All Files 使用起来安全吗？

它只扫描您选择的页面或网址，并且每次只请求访问一个网站。文件发现、下载、ZIP、CSV、PDF合并和页面保存都在您的浏览器中运行。商店版本不含任何分析或错误报告SDK。它是日本一位开发者开发的独立扩展程序，并非由Google、Microsoft或Mozilla制作。请只用于您有权访问的文件。

我的文件或页面会被发送到服务器吗？

不会。文件从来源网站直接到您的电脑。页面内容、网址、文件名和文件内容不会发送给开发者。有两项内容会到达开发者的服务器：许可证检查（其中包括设备管理），以及可选的使用统计，后者默认关闭，只有在您同意后才会发送。统计数据不含页面内容、网址或文件名。

Pro 是订阅还是一次性购买？

一次性购买，价格$19.99。这是永久许可证，无需订阅。

一个许可证可以在多少台设备上使用？

最多3台设备。

免费版能做什么？

检测并列出文件，然后每次下载保存10个文件，ZIP、PDF合并和CSV针对同样的10个文件。在将网页合并为 HTML 中，您可以找出候选页面，并以四种保存文件的形式中的任何一种每次运行保存1个页面，一次一个地把更多页面添加到上次保存的HTML中，并且每次运行保存10个链接文件。无需信用卡。

支持哪些浏览器？

基于Chromium 111或更高版本的Chrome和Edge，以及Firefox 128或更高版本。在Firefox上不能选择保存文件夹，“按网站结构保存到文件夹”不可用，主动抓取也无法捕获由JavaScript发起的下载。

它能用于需要登录的页面吗？它会看到我的密码吗？

它适用于您已经能在同一个浏览器中打开的页面，使用您现有的会话。它不会收集或发送密码、Cookie的值或您在字段中输入的内容。它不会自动登录，也不会绕过验证码。如果会话过期，文件一侧会在受影响的行显示已退出登录的提示，页面一侧则会暂停，直到您重新登录并按“继续”。

为什么它要求这么广泛的权限？

安装它只会授予对许可证服务器的网站访问权限。适用于所有网站的权限被声明为可选，当您从某个网站扫描或保存时，浏览器会请您允许该网站。之后您可以撤销访问权限：在Chrome或Edge中，位于“扩展程序”、Grab All Files、“详细信息”、“网站访问权限”下；在Firefox中，位于“附加组件”、“权限”下。本站的安全页面对每项权限都做了说明。

它会把页面发送给AI服务吗？

不会。它可以准备Markdown、JSONL和清单，每个页面都带有来源网址和获取时间，但要把文件交给哪个AI服务由您自己决定。不会自动发送任何内容。

可以退款吗？

如果技术缺陷导致您无法使用已付费的 Pro 功能，并且您在购买后30天内向 support@grab-all-files.app 报告，开发者会先尝试修复；如果无法在合理的时间内修复，则全额退款。改变主意、目标网站阻止或更改其页面、您没有登录权限的网站，以及网站上未说明的功能，均不在范围之内。退款会退回到原支付方式，许可证密钥会被撤销。您的法定权利不受影响。条款见“条款”页面的第15e节。

它不适合做什么？

流媒体视频、复制数千页或只用有变化的文件来刷新副本、您无法打开或登录的页面，以及受DRM保护的文件。完整列表请参阅限制页面。
