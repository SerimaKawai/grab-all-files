“将网页合并为 HTML”有四种保存文件的形式。其中三种在所有浏览器中都可用；这一种仅限 Chrome 和 Edge，在 Firefox 上通常用 ZIP 代替。

Firefox 就够用的情况

  • ✓您把文件保存到常用的“下载”文件夹，不需要每次选择文件夹。
  • ✓您可以接受用分页 HTML 的 ZIP 代替按网站结构保存到文件夹。
  • ✓您想要的文件直接链接在页面上，扫描能找到它们，无需捕获由脚本发起的下载。

Chrome 或 Edge 更合适的情况

  • –您想选择文件夹，例如磁盘上的共享文件夹。
  • –您想把网站自己的文件夹结构写到磁盘上，通过点击链接来浏览。
  • –下载由运行 JavaScript 的按钮发起，没有指向文件的普通链接。

常见问题

Grab All Files 能在 Firefox 中使用吗？

可以，需要 Firefox 128 或更高版本。有四处不同：不能选择保存文件夹，“按网站结构保存到文件夹”不可用，主动抓取受限且无法捕获由 JavaScript 发起的下载，以及将网页合并为 HTML 读取页面的方式不同。

在 Firefox 中文件保存在哪里？

保存在“下载”文件夹内的 GrabAllFiles 文件夹中。在这个扩展程序中，Firefox 不允许您选择目标文件夹。

支持哪些 Edge 版本？

基于 Chromium 111 或更高版本的 Edge，从 Microsoft Edge 加载项安装。Chrome 支持同样的 Chromium 版本。

一个许可证可以在多少台设备上使用？

最多 3 台设备。它是一次性购买，价格$19.99，无需订阅。
