  • ✓把一组网页(包括需要登录才能看到的)作为一个随处可打开的文件发给客户或同事。

工作流程

  1. 1打开 Grab All Files,选择“将网页合并为 HTML”。可以从浏览器当前打开的网页开始,让扩展自动查找相关网页,也可以把来源切换为“从电脑文件夹”,选择包含 HTML 文件的文件夹或 ZIP。
  2. 2确认要包含的网页。在“外观”中选择“保持原样”。合并同一网站的多个网页时,请开启“每页重复的页眉、菜单和页脚只保留在第一页”。“不保存广告”默认开启,可让文件更小;如需保留广告位,请将其关闭。
  3. 3对于网页,当系统请求访问提供样式表和图片的网站时,请予以允许。所有网站只会请求一次。每个网页都会在标签页中打开并滚动到底部,这样滚动时才加载的图片和内容也会被包含进来。
  4. 4保存。打开 HTML 后,可通过目录和搜索在各网页之间切换。每个网页都会显示来源网址和抓取时间。如果还想在文件中列出未能保留的图片或部分,请开启“包含采集信息和失败列表”。

谁需要保留网页的原有设计

改版或迁移之前

网站团队和代理公司在重建网站、迁移到新系统或下线之前,按页面留存网站当前的样子。

证据与合规记录

法务、合规和广告审核团队留存页面、优惠或公告当时的展示效果,每个网页都附有来源网址和抓取时间。

即将关闭的网站和服务

研究人员、社区和爱好者留存即将停止运营的服务的网页,保存为不依赖网站继续在线的文件。

分享需要登录的网页

把门户、内网或客户专区的网页,以一个可在任意浏览器中离线打开的文件发给没有访问权限的人。

设计与竞品参考

设计师和营销人员按真实的字体、配色和间距收集落地页和竞品网站。

已保存的网站与导出的帮助文档

网站备份文件夹,或导出为 HTML 的帮助和手册页面,可变成一个仍保持原貌的文件。

保存的文件中包含什么

版式、字体和配色

嵌入每个网页的样式表、所用的网页字体(每种字体一种格式,优先 WOFF2)以及图片,包括背景图。

网页呈现的样子

在页面稳定后、打开任何菜单之前抓取,因此关闭的菜单保持关闭。滚动时渐显的内容会以可见状态保存。

稍后加载的内容

延迟加载的图片、边滚动边变长的网页、扩展有权读取的网站的内嵌框架、Web 组件的样式,以及由 SVG 精灵文件绘制的图标。

禁止外部引用的图片

在其他地方请求时会被拒绝的图片,会按原网页加载它们的方式重新获取,每张只获取一次。

来源与抓取时间

在每个网页标题下方显示来源网址和抓取时间。指向其他已保存网页和文件的链接,会在文件内或保存文件夹中打开。

更小的文件

多个网页使用的同一个样式表、图片或字体只存储一份。广告联盟的广告位默认不保存,也可以选择保留。

常见问题

免费版可以使用“保持原样”吗?

可以。外观选项不受套餐限制。免费版每次运行保存一个网页,因此您可以把任意单个网页按原有设计保存为一个 HTML 文件。若要把多个网页合并为带共享目录的一个文件,则需要 Pro($19.99,一次性付费,最多 3 台设备)。

这与“另存为”或单页保存工具有什么区别?

“另存为”会在 HTML 旁边生成一个文件夹,单页保存工具则是每个网页生成一个文件。Grab All Files 把多个网页放进一个文件,并让每个网页保留在各自的框架中,因此不同网页的设计互不冲突。共享的样式表、图片和字体只存储一份,已保存网页之间的链接在文件内部跳转,还可以一次搜索全部网页。

菜单、标签页和滑块还能用吗?

出于安全考虑,网站的脚本会被移除,因此依赖脚本的功能,如地图、搜索表单、登录或按需加载的视频播放器,将无法运行。常见的组件已做处理,无需网站脚本也能工作:使用标准无障碍标记或 Bootstrap 构建的标签页和折叠面板可以展开和收起,轮播箭头(Swiper、Slick、Splide、Glide、Flickity)可逐张切换。表单不会被提交。

滚动后才出现的图片也会保存吗?

会。对于网页,每个网页在抓取前都会在标签页中打开并滚动到底部,因此延迟加载的图片以及边滚动边追加内容的网页都会被包含。当页面不再变长,或“滚动时间”设置的时间(45、90 或 180 秒)用完时,滚动即停止。固定页眉、Cookie 提示和吸顶标题在您滚动已保存的文件时,会出现在原来的位置。

保存的文件可以放心打开和分享吗?

文件不含脚本,并且在打开时会阻止向互联网发出请求,因此不会加载来自其他网站的跟踪器或广告。链接中带有的登录信息会被移除。网页在您自己的浏览器中收集并保存到您的设备,内容不会发送到我们的服务器。分享之前,请确认您有权分享所保存的网页。

什么时候应该改选“整理为易读格式”?

当您更看重文字而不是设计时,请选择“整理为易读格式”:例如阅读长篇资料、打印、减小文件体积,或为 AI 工具准备 Markdown 和数据。它会以统一、简洁的样式显示所有网页,不含网站的页眉、菜单和页脚。“保持原样”则用于按网页原本的样子保存和分享。

需要登录的页面怎么办？

收集直接使用您浏览器的登录状态，不收集凭据。页面显示“需要登录”时，请点击“打开网站进行登录”，在打开的标签页中登录后点击“继续”。仍需登录的页面不会被保存，结果中会显示剩余页面数。
