常见问题

可以选择要收录哪些页面吗？

可以。Free 每次始终仅选中1个候选；选择其他页面时，选中项会自动切换。Pro 可选择多个页面、删除不需要的页面并调整其余页面的顺序。

结果可以离线阅读吗？

可以。您可以嵌入图片以便离线阅读，也可以保留在线引用以减小 HTML 文件的大小。链接的文档也可与 HTML 文件一并保存。

页面内容会上传到开发者的服务器吗？

不会。所有处理均在您的设备上完成。Free 仅保存所选的1个候选页面；Pro 将多个所选页面正文合并。安全、身份验证、权限、源网站和设备保护限制仍然适用。

这与 SingleFile 等单页面保存工具有何不同？

单页面保存工具保留当前打开的页面。Grab All Files 还会查找相关候选：Free 保存所选的1页，Pro 将多个所选页面中便于阅读的正文合并为一个带统一目录的 HTML。

需要登录的页面怎么办？

收集直接使用您浏览器的登录状态，不收集凭据。页面显示“需要登录”时，请点击“打开网站进行登录”，在打开的标签页中登录后点击“继续”。仍需登录的页面不会被保存，结果中会显示剩余页面数。

为什么保存的页面缺少部分文字？

有些网站要滚动或点击后才显示正文。请打开“页面缺少文字时：内容和 JavaScript 设置”，开启“点击‘显示更多’以包含后续内容”，然后重新收集。如果保存的是页面的其他部分，可在那里用“在屏幕上选择”指定正文范围。
