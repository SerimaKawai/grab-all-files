工作流程

  1. 1打开起始页面，在 Grab All Files 中选择“将页面合并为 HTML”。
  2. 2查找相关页面，然后在收集前删除不需要的项目或调整顺序。
  3. 3选择图片和链接文档选项，然后保存为一个带目录的 HTML 文件。

常见问题

可以选择要收录哪些页面吗？

可以。收集前请检查页面标题，删除不需要的页面，并调整其余页面的顺序。

结果可以离线阅读吗？

可以。您可以嵌入图片以便离线阅读，也可以保留在线引用以减小 HTML 文件的大小。链接的文档也可与 HTML 文件一并保存。

页面内容会上传到你们的服务器吗？

不会。页面收集和 HTML 生成均在您的设备上运行。Free 每 20 个页面暂停一次以供确认；Pro 会自动继续，直到所选的安全上限。

这与 SingleFile 等单页面保存工具有何不同？

单页面保存工具只会保留当前打开的页面。Grab All Files 可以查找相关页面，让您检查并调整其顺序，再将所选页面中便于阅读的内容合并为一个带统一目录的 HTML 文件。
