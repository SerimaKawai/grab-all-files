工作流程

  1. 1打开允许保存的来源，在扩展中选择“将网页合并为 HTML”。选择含表格的页面。
  2. 2收集前启用“AI分析数据（带出处的Markdown）”，选择“按页Markdown”或“完整包”并启用“同时将表格导出为CSV/JSON”。
  3. 3收集页面后点击“保存AI分析ZIP”。将CSV、JSON表格文件的列名、单元格、单位与注释同原表核对。
  4. 4将CSV导入Excel，或手动将支持的文件交给外部AI。检查日期、标识编号与分析结果。

常见问题

这是文件列表CSV吗？

不是。文件列表CSV记录文件URL和信息，此流程通过收集器的AI输出提取HTML表格数据。

任何表格都能变成CSV吗？

选择按页面或完整包并启用表格导出后，在支持范围内提取有意义的HTML表格。布局表格被排除，不保证图片或PDF画面中的表格能转为数据。

能直接输出XLSX吗？

此流程生成CSV、JSON。由您在Excel中打开或导入CSV，并非直接导出XLSX。

可以从免费版开始吗？

Free收集所选1页，Pro可选择多个页面正文。文件在设备上准备，由您交给Excel或外部AI。

需要登录的页面怎么办？

收集直接使用您浏览器的登录状态，不收集凭据。页面显示“需要登录”时，请点击“打开网站进行登录”，在打开的标签页中登录后点击“继续”。仍需登录的页面不会被保存，结果中会显示剩余页面数。

表格要滚动或点击“显示更多”后才出现，怎么办？

请打开“页面缺少文字时：内容和 JavaScript 设置”，开启“向下滚动以加载稍后出现的内容”或“点击‘显示更多’以包含后续内容”，然后重新收集。以图片形式绘制的表格或PDF中的表格不会导出为CSV。
