見落としがちなファイルも検出

708種類（拡張子）のファイルに対応。iframe内のPDF、遅延読み込み画像、fetch/XHRで取得されるファイル、blob URL、CMSダウンロードルート、hidden inputの値、39種類のdata-*属性まで網羅。通常のリンクスクレイパーでは拾えないファイルも検出します。さらにShadow DOM／Web Components内、SPAのハイドレーションデータ（Next.js・JSON-LD）、Cache Storage／OPFS／IndexedDB、署名付きクラウドストレージURL（Cloudflare R2・Firebase・Supabase・Vercel Blob）にも対応します。

よくある質問

対応しているファイル形式は？

708種類（拡張子）のファイルに対応しています（PDF・Word・Excel・PowerPoint・画像・ZIP・CSVなど）。分割・マルチボリュームアーカイブ（.000/.001…、WinRAR .r00/.s00、WinZip .z01）も検出し、圧縮アーカイブとして分類します。拡張子で絞り込み、必要なものを選んでワンクリックで一括ダウンロードできます。

無料で使えますか？

はい。無料版はファイルを1回のダウンロードで10件まで一括保存でき、関連ページを探して候補から常に1ページだけ選んでHTML保存できます。選んだページ内の画像にはプラン上の件数制限がなく、直接リンクされたファイルは10件ずつ保存します（結果画面の「次の10件を保存」で続きを保存）。安全上限・サイト側制限は適用されます。Proは$19.99の買い切りで、ファイル上限を解除し、選んだ複数ページの本文を1つのHTMLに結合します。

10件の上限に達するとどうなりますか？

何もロックされません。無料版は1回のダウンロードで10件まで保存します。保存が終わったら、一覧で次のファイルを選んで、もう一度「選んだファイルを保存」を押してください。繰り返せば残りも保存できます。Proには1回あたりの上限がありません。

複数のWebページを1つのHTMLにまとめられますか？

はい、Proで利用できます。無料版でも関連候補を探索・一覧表示できますが、HTML保存するのは選んだ1ページです。Proでは複数候補を選び、各ページの読みやすい本文を共通目次付きで検索・印刷できる1つのHTMLにまとめます。

Proの料金は？

$19.99 USDの買い切りで、永続ライセンス（サブスクなし）です。最大3台で利用できます（1台＝1台のパソコン上のブラウザープロファイル1つ）。拡張機能のライセンス画面から端末を解除すれば、その枠を別の端末で使えます。

購入後、Proはどう有効化しますか？

ライセンスキーは決済直後の購入完了ページに表示され、メールでも届きます。拡張機能を開き、右上の「無料」（または「⋯」メニュー →「Pro・ライセンスキー」）から入力欄を開いてキーを貼り付け、「有効化」を押してください。右上の表示が「Pro」に変われば完了です。

閲覧データはどこかへ送信されますか？

いいえ。ファイルはソースサイトから端末へ直接ダウンロードされます。当社サーバーへ送信されるのはライセンス検証と、任意の仮名化利用統計だけです。利用統計は初期設定でオフで、明示的に同意した後にだけ送信され、内容はランダムなインストールID、拡張機能のバージョン、プラン、件数などの大まかな数値やラベル（例：見つかったファイル数）に限られます。ページ内容・URL・ファイル名は一切送信しません。詳しくはセキュリティと権限をご覧ください。

Google Chrome および Microsoft Edge（Chromium 111 以降）、および Mozilla Firefox（128 以降）。

即時提供のデジタル製品のため、原則として返金には応じておりません。無料版で互換性と1ページHTML保存・1回10件のファイル保存を確認してからProをご購入いただけます。技術的な不具合により動作しない場合は、購入日から30日以内にお問い合わせフォームからご連絡いただければ全額返金いたします。

Webページ上のファイルをまとめてダウンロードするには？

Grab All Files を Google Chrome、Microsoft Edge、または Mozilla Firefox にインストールし、対象ページを開く（またはURLを貼り付ける）だけで、iframe、ビューア、遅延読み込み、fetch/XHR、blob URL、CMSダウンロードルートに隠れたファイルまで含めて検出・一覧表示します。必要なファイルを選んでワンクリックで一括保存できます。

サイト上のPDFをすべてダウンロードするには？

iframe埋め込みPDFやPDFビューアのURLも含めてページ上のPDFを検出し、同一サイト内を1回の実行で最大10万ページまでクロールできます。PDFで絞り込んで全選択し、一括ダウンロード、またはブラウザ内で1つのPDFに結合できます。

ファイル一括ダウンロードに向いているChrome拡張機能は？

Grab All Files は Google Chrome・Microsoft Edge・Mozilla Firefox 向けのファイル一括ダウンロード拡張機能です。通常のリンク抽出では見落としがちなPDF・Office文書・画像・ZIP・CSVを検出し、選んだファイルをワンクリックで保存、PDF結合、ZIP作成、ファイルURLのCSV出力ができます。無料版は1回のダウンロードで10件まで（繰り返して続きを保存可能）、$19.99の買い切りのProで1回あたりの上限を解除できます。

Webページ上の画像をすべて保存するには？

遅延読み込み画像、CSS背景画像、blob URLも含めて画像を検出します。画像種別で絞り込んで選択し、一括ダウンロード、または画像URLの一覧をCSV出力できます。

PDFをサーバーにアップロードせずに結合できますか？

はい。選択したPDFはブラウザ内（ローカル）で結合されます。アップロードは一切なく、ファイルが端末の外に出ることはありません。

大容量・長時間のダウンロードに対応し、一時停止・再開できますか？

はい。Grab All Files はビルトインのダウンロードマネージャを備え、並列数の調整・一時停止/再開・自動リトライ・失敗分のみのワンクリック再試行に対応します。回線が切れても大量のバッチを継続できます。数GBの単一ファイルや長時間の無人ジョブは、URLリストを書き出して専用のダウンロードマネージャに渡すこともできます。

JDownloader や aria2 などのダウンロードマネージャと併用できますか？

はい。互いに補完します。Grab All Files は、iframe・ビューア・JavaScript・CMSルートの奥にあるファイルなど、複雑なページやログイン必須ページでの「発見」が得意です。結果を CSV や URL リストとして書き出し、専用のダウンロードマネージャに渡せば大量の一括ダウンロードを任せられます。発見は Grab All Files、重いダウンロードは専用のダウンロードマネージャ、という役割分担です。

JavaScriptのSPAやログイン必須ページ、ボット対策のあるサイトでも動きますか？

はい。React・Next.js・Nuxt・Vue などの JavaScript 描画後のSPAを読み取り、すでに正当にアクセスできるページではお使いのブラウザセッションを利用します。CSRF保護されたダウンロードフォームにも追従し、Cloudflare/WAF のボット対策を検出して回復を案内します。拡張子だけでなく署名（マジックバイト）でファイル種別を確認します。アクセス制御やセキュリティ保護を回避することはありません。

ファイルを一括保存。必要なページをHTMLに。

無料版はファイルを1回のダウンロードにつき10件まで保存し、候補から選んだ1ページをHTML保存。Proはファイル上限を解除し、複数ページの本文を1つのHTMLに結合します。
