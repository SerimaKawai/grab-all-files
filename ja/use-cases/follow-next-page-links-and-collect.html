ページ収集が次のページを見つける仕組み

ページの探し方で、開いているページのリンクをたどる方法を選びます。次のページへのリンクもほかのリンクと一緒に拾われ、保存の前に候補の一覧で確かめられます。

全ページのファイルを集める（Pro）

  1. 1一覧の1ページ目を開き、Grab All Files の「ファイル一括ダウンロード」を開きます。
  2. 2「ページを自動でスクロールして最後まで読み込む」をオンにして、「全ページをスキャン」を押します。
  3. 3どこまで行くかは「読み込み時間」で選びます。通常（45秒）は6ページまで、長め（90秒）は20ページまで、徹底（180秒）は100ページまで。選ばなければ徹底になります。
  4. 4100ページに達して一覧がまだ続くときは、「続きの100ページを読む」を押します。
  5. 5まとまった一覧を種類で絞り込み、保存します。

無料プランでは、長い一覧は自分で最後までスクロールしてからスキャンし、一覧の各ページを順に開いて行います。

全ページの本文を集める

  1. 1一覧の1ページ目を開き、「ページをHTMLにまとめる」を開きます。
  2. 2「このページのリンクをたどる」を選び、候補を探します。「次へ」のページは、無料も Pro も候補の一覧に入ります。
  3. 3一覧を確かめ、要らないものを外します。
  4. 4Pro：ページを選び、見た目と保存の形を決めて、1回で保存します。無料：1ページを選んで保存し、次のページを同じ保存先に足していきます。

向いている場面

  • ✓「次へ」や「古い記事」のリンクが素直にある一覧。資料の一覧や、ブログの過去記事など。
  • ✓一覧の全ページのファイルを、ひとまとまりで欲しい。

確かめる、または別の方法

  • –「次へ」のリンクではなく、スクロールで続きが出る一覧。無限スクロールのガイドを見てください。
  • –ページ番号がリンクのないボタンの並びだけのとき。候補が少なくなることがあるので、一覧を確かめてください。
  • –とても大きなアーカイブ。数百ページを超えるなら、パソコン用のサイト巡回ソフトのほうが向きます。

よくある質問

「次へ」を自動でクリックして、全ページを回れますか？

回れます。ファイルは Pro の「全ページをスキャン」で行います。ページは、無料も Pro も「次へ」をたどって候補の一覧を作り、Pro はそれを1回で全部保存できます。

ファイルを集めるとき、無料でも「次へ」をたどりますか？

たどりません。無料のファイルスキャンは、画面に出ている分を読みます。長い一覧は自分で最後までスクロールし、一覧の各ページを順にスキャンしてください。

「全ページをスキャン」は何ページまでたどりますか？

「読み込み時間」（45・90・180秒）に応じて6・20・100ページです。選んでいなければ100ページまでです。それを超えるときは「続きの100ページを読む」を押します。

無料で何ページ保存できますか？

1回1ページです。同じ保存先に1ページずつ足していくことはできます。Pro は選んだページを一度に保存します。

次のページがリンクではなく、スクロールで出る場合は？

別のケースです。無限スクロールのページのガイドを見てください。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
