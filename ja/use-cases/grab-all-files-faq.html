3つにまとめると

Grab All Files は、Chrome・Edge・Firefox で、ページ内のファイルを見つけて保存し、ページを HTML に保存します。処理はブラウザの中で行い、ページの内容・URL・ファイル名は開発者に送りません。

無料プランはクレジットカードなしで使えます。Pro は $19.99 の買い切りで、3台までです。

配信される動画は保存しません。何千ページものコピーにも向きません。

よくある質問

Grab All Files は安全に使えますか？

選んだページや URL だけをスキャンし、サイトへのアクセスは1サイトずつ許可を求めます。ファイルの検出、ダウンロード、ZIP、CSV、PDF結合、ページの保存はブラウザの中で動きます。ストア版には、解析用や不具合報告用の SDK は入っていません。日本の個人の開発者による独立した拡張機能で、Google・Microsoft・Mozilla の製品ではありません。アクセスしてよいファイルにだけ使ってください。

ファイルやページはサーバーに送られますか？

送られません。ファイルは元のサイトからパソコンに直接保存されます。ページの内容・URL・ファイル名・ファイルの中身は、開発者に送りません。開発者のサーバーに届くのは2つだけです。端末の管理を含むライセンスの確認と、任意の利用統計です。利用統計は初期設定ではオフで、同意したときだけ送られ、ページの内容・URL・ファイル名は含みません。

Pro はサブスクですか、買い切りですか？

$19.99 の買い切りです。永続ライセンスで、サブスクはありません。

1つのライセンスは何台で使えますか？

3台までです。

無料でできることは何ですか？

ファイルを検出して一覧にし、1回のダウンロードで10件まで保存できます。同じ10件で、ZIP・PDF結合・CSV も使えます。「ページをHTMLにまとめる」では、候補ページを探し、1回1ページを4つの保存の形のどれでも保存できます。前回保存した HTML に1ページずつ足すこと、1回10件のリンク先ファイルの保存もできます。クレジットカードは要りません。

どのブラウザで使えますか？

Chromium 111 以降の Chrome と Edge、Firefox 128 以降です。Firefox では、保存先のフォルダを選べず、「サイトの形でフォルダに保存」は使えず、アクティブ取得は JavaScript で始まるダウンロードを捕まえられません。

ログインが必要なページでも使えますか。パスワードは見られますか？

同じブラウザで開けるページなら、今のログイン状態で使えます。パスワード・Cookie の値・入力欄の内容は集めず、送りません。ログインの自動化や CAPTCHA の突破はしません。ログインが切れたときは、ファイル側は該当の行にサインアウトの表示が出て、ページ収集側は一時停止します。ログインし直して「再開」を押してください。

権限が広いのはなぜですか？

入れた時点でサイトへのアクセスが許可されるのは、ライセンスのサーバーだけです。すべての Web サイトへの権限は「任意」として宣言されていて、スキャンや保存をするサイトごとに、ブラウザが許可を聞きます。あとから取り消せます。Chrome・Edge は「拡張機能」→ Grab All Files →「詳細」→「サイトへのアクセス」、Firefox は「アドオン」→「権限」です。権限ごとの理由は、このサイトのセキュリティのページに書いてあります。

ページを AI サービスに自動で送りますか？

いいえ。Markdown・JSONL・manifest を作れます。各ページに元の URL と取得日時が付きます。そのファイルを、自分で選んだ AI サービスに渡すのは利用者です。自動では何も送りません。

返金はできますか？

購入した Pro の機能が技術的な不具合で使えず、購入日から30日以内に support@grab-all-files.app へ連絡いただいた場合は、まず解決を試み、合理的な期間内に解決できなければ購入代金の全額を返金します。気が変わった場合、対象サイトによる遮断やページの変更、お持ちでないログインが必要なサイト、サイトに書かれていない機能は対象外です。返金は元の支払方法に行い、ライセンスキーは失効します。法定の権利には影響しません。条件は利用規約の第15e条にあります。

向かないことは何ですか？

配信される動画、何千ページものコピーや、変わったファイルだけの更新、開けない・ログインできないページ、DRM のかかったファイルです。全体は「できること・できないこと」のページにあります。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
