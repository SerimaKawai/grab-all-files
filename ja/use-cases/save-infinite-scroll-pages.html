自分で確かめること

  • –一般の一覧ページは既定で10回のスクロールで止まります。長い商品一覧は途中で切れることがあります。
  • –Canvas だけで描かれた文字や、閉じた Shadow DOM の中は読めません。
  • –別のドメインのフレームは、許可したあとで読めます。
  • –自分のブラウザーで開けないページ。持っていないログインが要るページなど。

長いタイムラインやコメント欄を保存する手順

  1. 1ログインが要るページなら、ログインしているブラウザーのタブで開きます。
  2. 2Grab All Files を開いて「ページをHTMLにまとめる」に切り替え、現在のページだけを選びます。
  3. 3見た目と保存の形を選んで、保存を始めます。ページは自動でスクロールされます。
  4. 41,000件ごとに、続けるかを聞かれます。答えるか、そのままにします。10分答えがなければ、そこまで読んだ分を保存します。
  5. 5保存したファイルを開き、最後の項目を元のページの終わりと見比べます。ページに件数が出ていれば、それとも見比べます。

長いページのファイル一覧を取るとき

無料プランでは、自分でページを最後までスクロールしてからスキャンを押します。スキャンは読み込み済みの分を読みます。

「必ず最後まで」とは言わない理由

ページは、いつ続きを読み込むかを自分で決めています。上に書いた上限は処理が終わるための値で、すべての項目に届く保証ではありません。

だから最後の確認が大事です。保存したファイルの終わりを、元のページの終わりと見比べます。途中で切れていたら、もう一度保存します。ファイル側なら、さらにスクロールして再スキャンします。

よくある質問

スクロールで増えるページを、最後まで保存できますか？

タイムラインやコメント欄などのフィードは、フィードが終わるまでスクロールします。それ以外のページは、既定では10回のスクロールで止まります。どちらも、保存したファイルの終わりを元のページと見比べてください。

コメントや投稿は何件まで読めますか？

フィードに件数の上限はありません。1,000件ごとに続けるかを聞き、10分答えがなければそこまでを保存します。

自分でスクロールする必要はありますか？

ページの保存では要りません。無料プランでファイルをスキャンするときは必要で、画面に出ている分を読みます。Pro のスキャンはページを自動でスクロールします。

Pro のスキャンは何ページまでたどりますか？

「読み込み時間」の設定（45秒・90秒・180秒）で 6・20・100 ページです。選ばなければ 100 ページです。続きの100ページは、ボタンで読みます。

タイムラインやコメントで、確認済みのサイトはどこですか？

X の投稿と返信、YouTube のコメント、Reddit、Bluesky、Yahoo!ニュースのコメントです。ほかのサイトでも動くことはありますが、この一覧には入っていません。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
