✓元の見た目のまま

見たままのデザインで、ページを1つのHTMLに保存。

「元の見た目のまま」を選ぶと、Grab All Files は各ページを、そのサイトのスタイルシート・フォント・画像ごと保存します。ブラウザで見ていたレイアウト・配色・文字組みのまま、1つのファイルに入ります。Webサイトやパソコンのフォルダから複数ページをまとめても、ページごとに独立した枠に入るのでデザインがぶつからず、目次と全ページ横断の検索で行き来できます。スクリプトは取り除くため、オフラインで開けて、追跡やポップアップもありません。

使い方

  1. 1Grab All Files で「ページをHTMLにまとめる」を選びます。ブラウザで開いているページから始めるか、関連ページを探させるか、取得元を「パソコンのフォルダから」に切り替えてHTMLのフォルダやZIPを選びます。
  2. 2まとめるページを確認し、「見た目」で「元の見た目のまま」を選びます。「毎ページ共通のヘッダー・メニュー・フッターは最初のページだけに残す」はオンのままで、ファイルを軽くしたいときは「広告を省く」もオンにします。
  3. 3Webページの場合は、スタイルシートと画像の配信元へのアクセス許可を求められたら許可します（まとめて1回で聞きます）。各ページはタブで開いて最後までスクロールするので、スクロールで読み込まれる画像や続きも入ります。
  4. 4保存します。HTMLを開くと、目次と検索でページ間を移動できます。各ページには取得元のアドレスと取得日時が出ます。残せなかった画像や部分は、まとめの報告に出ます。

よくある質問

無料版でも「元の見た目のまま」を使えますか？

使えます。見た目の選択に料金プランの制限はありません。無料版は1回1ページなので、好きなページを1つ、元のデザインのまま1つのHTMLに保存できます。複数ページを目次つきで1ファイルにまとめるには Pro（$19.99・買い切り・最大3台）が必要です。

ブラウザの「名前を付けて保存」や、1ページずつ保存する拡張機能とは何が違いますか？

「名前を付けて保存」はHTMLの横にファイルのフォルダができ、1ページ保存型の拡張機能は1ページにつき1ファイルです。Grab All Files は複数ページを1つのファイルに入れ、各ページを独立した枠に収めるので、ページ同士のデザインがぶつかりません。共通のスタイルシート・画像・フォントは1回だけ入れ、保存したページ同士のリンクはファイル内で移動し、全ページをまとめて検索できます。

メニューやタブ、スライダーは動きますか？

安全のためサイトのスクリプトは取り除くので、地図・検索フォーム・ログイン・あとから読み込む動画プレーヤーなど、スクリプトが必要な機能は動きません。よく使われる部品は、サイトのスクリプトなしで動くようにしています。アクセシビリティの作法どおりに作られたタブやアコーディオン、Bootstrap の折りたたみは開閉でき、カルーセルの矢印（Swiper・Slick・Splide・Glide・Flickity）は1枚ずつ動きます。フォームが送信されることはありません。

スクロールしないと出てこない画像も入りますか？

入ります。Webページは1ページずつタブで開き、最後までスクロールしてから写すので、遅延読み込みの画像や、下へ進むと続きが足されるページも入ります。スクロールは、ページが伸びなくなるか、「読み込み時間」の設定（45秒・90秒・180秒）に達した時点で終わります。固定ヘッダー・Cookieの案内・スクロールで貼り付く見出しも、保存ファイルで元の位置に出ます。

保存したファイルは安全に開けて、人に渡せますか？

ファイルにはスクリプトが入っておらず、開いたときにインターネットへの通信も止めるので、ほかのサイトの追跡や広告は読み込まれません。リンクに含まれる認証情報も取り除きます。ページはご自身のブラウザで集めて端末に保存し、内容が当方のサーバーに送られることはありません。共有する前に、そのページを共有してよいかはご確認ください。

「読みやすく整える」を選ぶのはどんなときですか？

デザインより文字が大事なとき、つまり長い資料を読む・印刷する・ファイルを小さくする・AI向けのMarkdownやデータを作るときです。サイトのヘッダー・メニュー・フッターを除き、全ページを同じ読みやすい書式で表示します。「元の見た目のまま」は、見えていたとおりに残す・渡すための選択肢です。
