サイトがなくなる、作り直される。何から保存するか。

サイトに「この日を過ぎたら変わる、消える」という日があるとき、問題はページの保存の仕方ではなく、時間が尽きる前にどのページを取るかです。このガイドは作業を順に並べます。ほかにない内容のページ、それがリンクする文書、見た目と構成、残り、の順です。取れないものも先に挙げるので、期限の近くで慌てることが減ります。

何をどの順で保存するか

上から順に進めます。時間が尽きたらそこまで。上の行ほど、あとから代わりを見つけにくいものが多いはずです。

優先順位取るものGrab All Files での方法
1そのサイトにしかないページ。お知らせ・料金・手続き・沿革・連絡先など「ページをHTMLにまとめる」で、見た目は「元の見た目のまま」、保存の形は「サイトの形でフォルダに保存」（Chrome・Edge）か「ページ別HTML（ZIP）」。各ページのスタイル・フォント・画像が残り、複数のページで共通のファイルは1回だけ保存されます。
2ページからリンクされた PDF と Word・Excel・PowerPoint のファイルリンク先ファイルをページと一緒に保存するオプションを使う（無料は1回10件、Pro は100件）。または「ファイル一括ダウンロード」で深さ1〜5にして、種類で絞り込み、ZIP で保存。
3それ以外。古いお知らせ、タグや過去分のページ最後に、時間があれば。サイトマップがあれば、サイトが何ページを載せているかが分かります。

保存したコピーに残る3つ

保存できるもの

  • ✓ブラウザに表示されたとおりのページ。JavaScript で作られたページや、自分のログインの先のページも含みます。
  • ✓ページからリンクされた PDF・Word・Excel・PowerPoint のファイル。
  • ✓ページから直接リンクされた動画・音声のファイル（mp4・mp3 など）。
  • ✓失敗したファイル。再試行できるほか、失敗した URL と理由を書き出せます。

保存できないもの

  • –配信（ストリーミング）の動画。HLS・DASH の配信や、blob: のアドレスで再生するプレーヤーなど。
  • –サーバーに問い合わせる検索欄やフォーム。保存したページはネットワークにつながりません。
  • –自分のブラウザで開けないページや、持っていないログインが要るページ。
  • –DRM・暗号化されたビューアの中のファイルや、Canvas だけで描かれた文字。

最後の1週間のチェックリスト

  • ✓起点にするページを書き出します。トップページ、資料の置き場、お知らせの一覧、連絡先のページなど。
  • ✓会員向けの部分があるなら、先にログインします。長い処理の途中でログインが切れると一時停止するので、ログインし直して「再開」を押します。保存済みのページは残ります。
  • ✓リンク先の文書の数を早めに数えます。リンク先ファイルは無料で1回10件、Pro で100件ずつ保存し、残りは結果画面のボタンで続けます。数百件の資料があれば何回かに分かれます。
  • ✓保存したコピーを、ネットワークを切って開きます。いくつかのページをたどり、保存したページ同士のリンクが保存したファイルを開くことを確かめます。
  • ✓日付を残します。「元の見た目のまま」の「目次・検索付きHTML」では、各ページのタイトルの下に、元の URL と取得日時が出ます。

何千ページもあるサイトのとき

Grab All Files は、ブラウザの中でページを1つずつ読みます。そのため、ログインの先のページにも届きます。ただし、とても大きなサイトでは時間がかかります。何千ページもあって残り時間が少ないなら、サーバーに直接ページを求めるパソコン用のサイト複製ソフトのほうが、1時間に進む量が多くなります。そのツールに見えないページと、リンク先の文書を種類別に取り出す場面に、Grab All Files を使ってください。

よくある質問

閉鎖されるサイトは、何から保存すればよいですか？

そこにしかないページ（お知らせ・料金・手続きなど）と、それがリンクする PDF・Office 文書です。見た目や古い過去分のページはそのあとにします。

保存したサイトを、リンクをクリックしてオフラインで見られますか？

はい。Chrome・Edge の「サイトの形でフォルダに保存」か、「ページ別HTML（ZIP）」で保存した場合、保存したページ同士のリンクは保存したファイルを開きます。保存していないページへのリンクは、元のサイトを指したままです。

PDF や Word も保存されますか？

はい。ページからリンクされたファイルは、ページと一緒に保存するか（無料は1回10件、Pro は100件）、「ファイル一括ダウンロード」で集められます。文書の本文は HTML には入らず、ページにはリンクが残ります。

サイトの動画も保存できますか？

ページから直接リンクされた動画ファイル（mp4 など）だけです。配信の動画は保存せず、DRM や透かしも回避しません。

何千ページもあるサイトには何を使えばよいですか？

サーバーに直接ページを求めるパソコン用のサイト複製ソフトです。大きな公開サイトでは速くなります。Grab All Files は、ログインのページや、文書を取り出す場面に使います。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
