使い方

  1. 1保存したいポスト・動画・スレッド・記事のコメント欄を、ブラウザで開きます。
  2. 2Grab All Filesで「ページをHTMLにまとめる」を選び、収集範囲を「現在のページのみ」にして保存を始めます。
  3. 3ページが収集用のタブで開き、最後まで自動でスクロールします。「返信○件」「他の返信を表示」「コメントをさらに表示」などのボタンも自動で押します。画面には読み込んだ件数が表示されます。
  4. 41,000件読むごとに、続けて読むか、ここまでの分を保存するかを聞かれます。10分たっても応答がなければ、それまでに読んだコメントを保存します。
  5. 5読み終わると、コメントと返信が1つのHTMLファイルとして保存されます。AIで分析するときは、続けて「本文をコピー」「1つのMarkdownを保存」「テキスト（.txt）で保存」のいずれかを使います。

確かめているサイトと、保存できる範囲

X（旧Twitter）

YouTube

動画のコメント欄を最後まで読み込み、「返信○件」「他の返信を表示」を押して返信も開きます。

Reddit

スレッドのコメントを、返信の返信まで保存します。「その他の返信」と「コメントをさらに表示」も自動で押します。サブレディットの投稿一覧も保存できます。

Bluesky

ポストのスレッドとプロフィールの投稿一覧を保存します。「さらに返信を読む」の先のページは、Proなら「現在のページのみ」を選んでいてもたどって読みます。

Yahoo!ニュース

記事のコメント一覧で「返信○件」「もっと見る」を押して開きます。2ページ目以降は、Proなら「現在のページのみ」を選んでいてもたどって集めます。

そのほかのサイト

スクロールすると続きが出てくるタイムラインやコメント欄なら、最後までスクロールして保存できることがあります。サイトの作りによっては、返信を開くボタンが押されないことがあります。

よくある質問

どのサイトのコメントを保存できますか？

実際のページで動作を確かめているのは、X（旧Twitter）のポストと返信、YouTubeの動画のコメント、Redditのスレッド、Blueskyのスレッドとプロフィール、Yahoo!ニュースの記事のコメントです。これ以外のサイトでも、スクロールすると続きが出てくる一覧なら、最後までスクロールして保存できることがあります。

閉じている返信も保存されますか？

保存されます。YouTubeの「返信○件」「他の返信を表示」、Redditの「その他の返信」「コメントをさらに表示」、Yahoo!ニュースの「返信○件」「もっと見る」は、自動で押して開きます。Blueskyの「さらに返信を読む」のように別のページに続く返信は、Proなら「現在のページのみ」を選んでいても、その先のページまでたどって読みます。

何件まで保存できますか？

件数の上限はありません。1,000件読むごとに、続けて読むか、ここまでの分を保存するかを確認します。10分たっても応答がなければ、それまでに読んだコメントを保存します。スクロールしても新しいコメントが増えなくなったら、最後まで読んだものとして終了します。

無料プランでも使えますか？

使えます。コメントを最後まで読み込む機能と返信を開く機能は、無料プランもProも同じです。無料プランで、YouTube・Reddit・Blueskyのコメント欄を最後まで保存できることも確かめています。違うのは1回に保存できるページの数で、無料プランは1ページずつ、Proは複数のページを1つのHTMLにまとめられます。Yahoo!ニュースのようにコメント一覧が複数のページに分かれているサイトでは、無料プランで保存できるのは1ページ目だけです。

広告は入りますか？

Xでは、タイムラインや返信に混ざっているプロモーション（広告）のポストを見分けて、保存しません。開いているポスト自体は保存されます。

動画もダウンロードされますか？

このページで紹介しているのは、コメントと返信をページとして保存する機能です。動画ファイルそのものはダウンロードしません。

ログインしないと見えないコメントは？

保存できるのは、ブラウザで見えているコメントです。会員限定のコメントのように、ログインしないと見えないものは入りません。YouTubeでは、保存した件数が動画に表示されているコメント数よりやや少なくなることがあります。表示されている数には、ログインしていない人には見えない返信も含まれているためです。

保存したコメントはどこかに送られますか？

送られません。コメントはお使いのブラウザで読み込み、パソコンに保存します。コピーした本文や保存したファイルをAIサービスに渡すかどうか、どのサービスに渡すかは、ご自身で決められます。人の投稿を共有したり公開したりするときは、各サイトの規約と投稿した人の権利に気をつけてください。
