用途別

目的に近いガイドを選んでください。各ガイドで、実際の手順、拡張機能に表示される名前、無料プランでできる範囲（1回のダウンロードで10件、ページ収集は1回1ページ）を紹介します。

製品カタログ・仕様資料

比較する製品のカタログ・仕様書・データシートを、型番が分かる名前で元URLと一緒に保存。無料プランは1回10件までダウンロードできます。

IR・決算資料PDF

1社の決算短信・決算説明資料・統合報告書などを、年度・四半期ごとに保存。タイトルに期間を付け、元URLも記録できます。無料プランは1回10件までダウンロードできます。

入札・公募書類一式

1件の入札・公募の公告、仕様書、様式、質問回答を元の形式のまま保存。役割が分かる名前を付け、公式の資料一覧と照合できます。無料プランは1回10件まで。

資料リンクをCSV一覧に

選択したファイルのURL・ファイル名・タイトル・種類・サイズ・更新日・リンク元をCSVに書き出し、Excelで確認。無料プランは1回10行まで出力できます。

SDS・技術資料を保存

製品ごとのSDS・TDS・技術資料PDFを、言語と改訂日が分かる名前で元URLと一緒に保存。無料プランは1回10件までダウンロードできます。

arXivのPDF・研究資料

arXivで絞り込んだ論文一覧をスキャンし、必要なPDFを選んで保存。タイトルでの命名、フォルダ分け、ZIP、ファイル一覧CSVを実画面と図解で紹介します。

PDFのファイル名変更・整理

PDFを本来のタイトルでファイル名変更してから保存し、種類別・サイト別のフォルダに整理。タイトルは編集でき、無料プランは1回10件まで保存できます。

官公庁・自治体の公開資料

官公庁・自治体の制度案内ページをHTMLで、添付のPDF・Wordをファイルで保存し、出典も記録。無料プランは1回1ページ、ファイルは1回10件までです。

PDFを一括ダウンロード

WebページをスキャンしてPDFを一覧にし、必要なものを選んでまとめて保存します。無料プランは1回の保存で10件まで。Chrome・Edge・Firefox対応。実際に保存したPDFのサンプルも見られます。

画像を一括ダウンロード

表示中の画像、遅延読み込み画像、CSS背景、blob画像を検出し、選んだ画像を一括保存・ZIP化・URLのCSV出力。無料プランは1回のダウンロードで10件まで。

ページ上のファイルを保存

Webページ上のPDF・Office文書・画像・ZIP・CSVを検出し、絞り込んで一括保存やZIP化。無料プランは1回のダウンロードで10件まで保存できます。

社内ポータル・LMS

社内イントラネット・LMS・会員エリアから、既存のブラウザのログイン状態で権限のあるファイルを保存。認証情報は収集せず、ファイルは端末へ直接保存されます。

PDFをローカル結合

Webページで見つけたPDFを、アップロードせずブラウザ内で1つに結合。ドラッグで順番を決め、保存名も指定できます。無料プランは1回の結合で10件まで。

Word・Excel・PowerPoint を一括保存

ページにリンクされた Word・Excel・PowerPoint を見つけて、「文書」「表計算」「プレゼン」で絞り込み、まとめて保存。無料は1回10件まで。

「次へ」をたどって全ページから集める

一覧が1・2・3ページに分かれているとき。ファイルは Pro で「次へ」を自動でたどり、ページ収集は無料も候補を探し、Pro は全部を1回で保存します。

複数ファイルを ZIP 1 つで保存

ページで選んだファイルを「ZIP」ボタンで1つにまとめて保存。無料は10件まで。200MB を超えると確認が出て、上限は256MB。分割はしません。

リンクされた動画・音声ファイルを保存

ページが直接リンクしている動画・音声ファイル（mp4・mp3 など）を保存。HLS・DASH などの配信、動画サイト、DRM は対象外です。無料・Pro 共通。

保険の約款・パンフ集め

保険会社の商品ページから約款・パンフレット・重要事項説明書・改定のお知らせの PDF を集め、PDF のタイトルで名前を付けて保存。商品名と版は自分で記録します。

法令・判例・特許のPDF

公的な法令・判例・特許の検索結果から PDF を選び、タイトルで名前を付けて保存。出典の一覧も作れます。大量取得は提供元の一括ダウンロードを。

授業資料・シラバス保存

受講している授業のスライド・配布資料・シラバスを、学習管理システムや教員のサイトのページから保存。保存先は授業ごとに自分で選びます。

物件資料・図面のPDF集め

権利のある物件概要書・間取り図・図面・仕様書・重要事項の資料の PDF と画像を、サイト別・種類別のフォルダに保存し、CSV で一覧にします。

Web表をCSVで活用

Webページの表をCSVに保存し、Excelで集計・比較、外部AIで分析する手順。表の出力設定、単位・注記の確認、ファイル一覧CSVとの違いを紹介します。

改訂前後の資料を比較

改訂前後の資料を分けて保存し、前回との差分レポートで対象ページを確認。原文や外部AI・比較ツールで、手順・条件・例外の変更を確かめる使い方です。

Web資料をMarkdownで再利用

Webページの見出し・本文・箇条書き・表をMarkdownに書き出し、出典URLと取得日時を残します。無料プランは1ページ、複数ページはPro。実際に保存した.mdファイルのサンプルつき。

業務マニュアル・ナレッジを保存

章に分かれたオンラインマニュアルから必要な章を選び、読む順番を整えて、目次と検索で探せるHTMLに保存します。無料プランは1ページ、複数ページはPro。保存した実物のサンプルつき。

集めて読む・AIで分析する

Web情報を集めてHTMLで読み返す。AI向け資料を出典付きで書き出し、外部AIで要約・比較・条件抽出する手順と質問例を紹介します。

コメントを一括保存・分析

YouTube・X（旧Twitter）・Reddit・Bluesky・Yahoo!ニュースのコメント欄を最後まで自動で読み込み、閉じている返信も開いて1つのHTMLに一括保存します。AIに渡せば、意見の傾向を分析できます。無料プランでも使えます。

ページをHTMLにまとめる

関連するWebページを選び、順番を整えて、目次と本文検索つきの1つのHTMLにまとめます。無料プランは1ページ、複数ページの結合はPro。保存したHTMLの実物サンプルも見られます。

パソコン内のHTMLを1つに

パソコンのフォルダやZIPにある複数のHTMLファイルを、目次付きの1つのHTMLにまとめます。画像は埋め込み、ページ間リンクはファイル内で移動。アップロードはしません。

見た目そのままHTML保存

「元の見た目のまま」を選ぶと、サイトのスタイル・画像・フォントを使った1つのHTMLに保存します。無料プランは1ページ、複数ページの結合はPro。元ページと保存後の比較サンプルつき。

サイトを丸ごと保存

数十〜数百ページのサイトを、見た目・リンク・添付PDFごとブラウザーで保存。ログインが要るページやJavaScriptで作られたページにも対応。Chrome・Edge・Firefox。

サイトをAIに読ませる

サイトのページを、各ページに source_url と captured_at が付いた Markdown にして保存。NotebookLM・ChatGPT・Claude へは自分で渡します。自動では送りません。

ブログ・ニュースの全記事を保存

ブログやニュースの全記事を、サイトマップ・同じパス・「次へ」から見つけ、目次・検索付きHTML・印刷用HTML・Markdownで保存。無料は1記事ずつ。

閉鎖前にサイトを保存

サイトが閉鎖・作り直される前に、何から保存するかを決め、元の見た目のままフォルダに保存。リンク先の PDF・Office 文書も。取れないものも先に確認。

ログイン後のページと資料を保存

会員サイト・取引先ポータル・学習サイトのページと資料を、自分のアカウントで保存。ブラウザーのログイン状態を使い、パスワードや Cookie は集めません。

スクロールで増えるページを保存

スクロールすると増えるページを Grab All Files でどう扱うか。フィード・コメント欄、一般の長いページ、ファイルのスキャンで、上限が違います。その一覧です。

元のURLと日時付きで保存

Grab All Files の保存の形ごとに、元の URL と取得日時がどこに残るか。画面に出る形、出ない形、ページごとの URL を記録しない形を表にまとめました。

競合の価格表・製品ページ

競合の価格表と製品ページを月に 1 回保存し、表を CSV にして、差分レポートで変更を見る流れ。実行は手で行います。自動の定期実行機能はありません。

できること・できないこと

上限を1つの表に。無料は1回10件、Pro はリンク先ファイル1回100件、巡回は1回100,000ページ、ZIP は256MB。保存できないものも書きます。

巡回ソフト・1ページ保存・ダウンロード管理の違い

Web の内容を保存する4つの方式を比較。パソコン用の巡回ソフト、1ページ保存の拡張機能、ダウンロード管理ソフト、Grab All Files。向かない行も書きます。

Chrome・Edge・Firefox の違い

Chrome・Edge（Chromium 111以降）・Firefox 128以降の入手先と、Firefox でできないこと（保存先の選択、サイトの形でフォルダに保存、アクティブ取得）。
