Chrome・Edge・Firefox で使える一括ダウンロード拡張機能。入手先と、Firefox での違い。

Grab All Files は、Chrome、Edge（Chromium 111 以降）、Firefox 128 以降で動きます。「ファイル一括ダウンロード」と「ページをHTMLにまとめる」の2つのツールは、3つとも使えます。Firefox では4つの点が違うか、使えません。入れる前に判断できるよう、下にまとめました。

Firefox でできないこと

次の4つの違いは、拡張機能のコードで確かめました。ほかに違いがないとは、このページでは言っていません。

Chrome・EdgeFirefox
保存先のフォルダを選ぶ保存先のフォルダを選べます。選べません。ダウンロードフォルダの中の GrabAllFiles フォルダに、自動で保存します。
「サイトの形でフォルダに保存」使えます。選んだフォルダに、元のサイトと同じフォルダの形でページを書き込みます。使えません。保存したページ同士のリンクをオフラインで開けるコピーが欲しいときは「ページ別HTML（ZIP）」を使います。
アクティブ取得（JavaScript で始まるダウンロード）使えます。スクリプトで始まるダウンロードを1つずつクリックして、ファイルを捕まえます。制限があります。アクティブ取得は、JavaScript で始まるダウンロードを捕まえられません。スキャンで直リンクとして見つかったファイルは、そのままダウンロードできます。
「ページをHTMLにまとめる」でのページの読み取り方Chrome・Edge で使う方式です。ブラウザが表示したタブから、ページを読み取ります。

サイトの形かZIPか：ブラウザで変わります

「ページをHTMLにまとめる」の保存の形は4つあります。3つはどのブラウザでも選べます。この形は Chrome・Edge のみで、Firefox では ZIP が代わりになります。

Firefox で足りる場面

  • ✓いつものダウンロードフォルダに保存すればよく、毎回フォルダを選ぶ必要がない。
  • ✓サイトの形のフォルダの代わりに、ページ別 HTML の ZIP で足りる。
  • ✓欲しいファイルがページに直接リンクされていて、スクリプトで始まるダウンロードを捕捉しなくても、スキャンで見つかる。

Chrome・Edge が向く場面

  • –保存先のフォルダを選びたい。たとえばドライブの共有フォルダ。
  • –サイト本来のフォルダの形をディスクに書き出し、リンクをクリックして見て回りたい。
  • –ファイルへの普通のリンクがなく、JavaScript を実行するボタンでダウンロードが始まる。

よくある質問

Grab All Files は Firefox で使えますか？

はい。Firefox 128 以降で使えます。違いは4つあります。保存先のフォルダを選べないこと、「サイトの形でフォルダに保存」が使えないこと、アクティブ取得に制限があり、JavaScript で始まるダウンロードを捕まえられないこと、「ページをHTMLにまとめる」のページの読み取り方が変わることです。

Firefox では、ファイルはどこに保存されますか？

ダウンロードフォルダの中の GrabAllFiles フォルダです。この拡張機能では、Firefox で保存先のフォルダを選べません。

Edge は、どのバージョンから使えますか？

Chromium 111 以降の Edge で、Microsoft Edge アドオンから入れられます。Chrome も同じ Chromium 111 以降が対象です。

1つのライセンスは何台で使えますか？

3台までです。$19.99 の買い切りで、サブスクはありません。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
