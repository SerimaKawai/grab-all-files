保存の前に選ぶこと

保存の形は4つ

4つとも「元の見た目のまま」で使えます。無料プランは1回1ページを、どの形でも保存できます。Pro は複数のページを1回で保存します。

手順（Pro の場合）

  1. 1ログインが要るサイトなら、同じブラウザでログインしておきます。起点にするページ（たいていはトップページか目次のページ）を開きます。
  2. 2Grab All Files を開き、「ページをHTMLにまとめる」に切り替えます。どこまで集めるかで「リンク先のページも探す」を選びます。細かく決めたいときは、サイトマップや貼り付けた URL の一覧も使えます。
  3. 3候補の一覧を確かめ、要らないページを外し、残りを読みたい順に並べます。
  4. 4見た目で「元の見た目のまま」、保存の形で「サイトの形でフォルダに保存」（Firefox なら ZIP）を選び、保存先のフォルダを決めて始めます。
  5. 5ページから PDF や Office 文書にリンクしていれば、ページと並べて保存されます。Pro は1回100件まで。残りは結果画面のボタンで続けます。

保存したページの動き方

各ページは、そのページのスタイルシート・Web フォント・画像を持ったまま保存されます。複数のページで共通のファイルは1回だけ保存します。サイトのスクリプトは外し、保存したページは開いてもネットワークにつなぎません。タブ・アコーディオン・カルーセルの矢印は動きますが、送信フォーム、サーバーに問い合わせる検索欄、埋め込みの動画プレーヤーは動きません。

保存の前に、各ページをタブで開いてスクロールし、遅延読み込みの画像を出します。そのためにかける時間は「読み込み時間」の設定（45秒・90秒・180秒）に従います。広告は既定で外します。毎ページ同じヘッダー・メニュー・フッターは、最初のページだけに残すこともできます。

何千ページもあるサイトのとき

Grab All Files は、ブラウザの中で1ページずつ読んでいきます。ログイン後のページや JavaScript のページを保存できるのはこのためで、何千ページものサイトだと時間がかかるのも同じ理由です。何千ページも必要なときや、前回から変わったファイルだけを取り直したいときは、パソコン用のサイト巡回ソフト（ウェブサイトコピーツール）を使ってください。サーバーから直接ページを取るので大きな公開サイトでは速い一方、ログインが要るページやブラウザの中で作られるページは見えません。

よくある質問

保存したコピーは、リンクをクリックしてオフラインで見て回れますか？

はい。「サイトの形でフォルダに保存」（Chrome・Edge）か「ページ別HTML（ZIP）」で保存した場合、保存したページ同士のリンクは保存したファイルを開きます。保存していないページへのリンクは、元のサイトを指したままです。

ログインが必要なページでも使えますか？

同じブラウザで開けるページなら使えます。今のログイン状態をそのまま使い、パスワードを保存したり送ったりはしません。長い処理の途中でログインが切れたら一時停止するので、ログインし直して「再開」を押します。

無料で何ページ保存できますか？

1回1ページです。同じ保存先に1ページずつ足していくことはできます。Pro は選んだページを1回で全部保存します。

サイトをそっくりそのまま複製できますか？

ブラウザに表示された内容を、サイトのスタイルと画像ごと保存します。検索・フォーム・ログインなどサーバー側の機能はコピーでは動かず、配信される動画は保存しません。

ページはどこかに送られますか？

送られません。ページの読み取りと保存はパソコンの中で行います。開発者のサーバーに届くのは、ライセンスの確認と、オンにした場合の利用統計だけです。
