ページにリンクされた動画・音声ファイルを保存する。対象外も先に確かめる。

ページが、ファイルをそのままリンクしていることがあります。講義の録画が .mp4、ポッドキャストの1回分が .mp3、製品デモが .mov、といった形です。Grab All Files は、そうしたリンクを見つけて一覧にし、選んだものを保存します。配信（ストリーミング）の動画は保存しません。権利のある素材にだけ使ってください。

絞り込みのカテゴリ名は「動画」と「音声」です。

上は例です。ほかにも対応する拡張子のファイルは検出されます。見つかったファイルは種類つきで一覧に出るので、保存の前に何が見つかったかを確かめられます。

保存の前に一覧を確かめる

メディアのファイルは大きいことが多いので、先に一覧を見ます。種類で絞り込み、サイズで並べ替え、名前やタイトルで検索できます。

手順

  1. 1ファイルへのリンクがあるページを開きます。ログインが要るなら、先にログインします。
  2. 2Grab All Files の「ファイル一括ダウンロード」を開き、ページをスキャンします。リンク1つ先のページのファイルも欲しいときは、スキャンの深さを上げます。
  3. 3「動画」または「音声」に絞り込みます。サイズと名前を確かめます。
  4. 4選んだものを保存します。無料は1回のダウンロードが10件までで、続きは次のファイルを選んでもう一度保存します。Pro は件数の上限がありません。
  5. 5合計が大きいときは、ZIP 1つではなくフォルダに保存します。ZIP は上限が 256MB で、分割されません。

欲しい動画が一覧に出ないとき

ページのプレーヤーで再生できるのに、ファイルが一覧に出ないときは、そのページが配信（ストリーミング）で再生していることが多く、Grab All Files では保存しません。サイト側のダウンロードの案内を探すか、公開している人にファイルを頼んでください。

権利の確認は利用者の責任です。手が届くファイルを保存できても、自由に再利用してよいことにはなりません。自分で録画したもの、利用許諾のある素材、所有者がダウンロードを認めているファイルに使ってください。

よくある質問

Web ページの mp4 ファイルをダウンロードできますか？

ページが mp4 ファイルを直接リンクしていれば、できます。一覧の「動画」にファイルが出るので、選んで保存します。

動画共有サイトの動画や、配信の動画は保存できますか？

できません。動画サイトの動画、HLS・DASH の配信、DRM で保護された内容は保存せず、ストリームの録画や再構成もしません。

mp3 などの音声ファイルも見つかりますか？

見つかります。直接リンクされた音声ファイルは「音声」に出ます。例：mp3、m4a、wav、flac。

ファイルの件数に上限はありますか？

講義の録画が25本あるなら、無料は10本・10本・5本の3回に分けます。Pro は件数の上限がありません。

見つけた動画は、何でもダウンロードしてよいですか？

保存してよい権利があるものだけです。ファイルに届くことは、コピーや再利用が許されていることを意味しません。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
