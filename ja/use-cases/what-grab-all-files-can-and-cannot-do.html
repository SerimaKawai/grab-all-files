Grab All Files でできること・できないこと。数字つきで。

Grab All Files は、Chrome・Edge・Firefox の拡張機能です。ページ内のファイルを見つけて保存し、ページを HTML にも保存します。このページは、上限、無料と Pro の違い、保存できないページやファイルと、そのときに使うツールの種類をまとめたものです。

Pro は US$19.99 の買い切りで、サブスクはありません。1つのライセンスを3台まで使えます。無料プランはクレジットカードなしで使えます。

Pro の「100」は何の数か、何の数でないか

Pro には、ダウンロードするファイル数の上限はありません。Pro の100は、「ページをHTMLにまとめる」で、HTML と並べて1回に保存するリンク先ファイル（保存したページがリンクする PDF や Office 文書）の数です。無料は1回10件です。それより多くリンクされているときは、結果画面のボタンで次の分を保存します。

間違えやすい数字がほかに2つあります。100,000は1回の巡回で読むページの上限です。100は、Pro のスキャンが「読み込み時間」を最長にしたとき「次へ」でたどるページ数でもあります。3つは別々の設定です。

よくある質問

無料プランでは、一度に何件までダウンロードできますか？

1回の保存で10件までです。選んだものから作る ZIP・PDF結合・CSV も同じ上限です。続きは次の10件を選んで、もう一度ボタンを押します。Pro にはファイル数の上限はありません。

Pro は100件までしかダウンロードできないのですか？

いいえ。Pro のファイル一括ダウンロードに、件数の上限はありません。100は、「ページをHTMLにまとめる」の1回で、HTML と並べて保存するリンク先ファイルの数です。結果画面のボタンで次の分を保存できます。

何ページまで巡回できますか？

1回の巡回で最大100,000ページです。深さは「このページのみ」・1〜5・無制限から選びます。sitemap.xml と robots.txt も読みます。

ZIP は何MBまで作れますか？

256MBまでです。合計200MBを超えると確認が出ます。ZIP を複数に分けることはしないので、上限に当たったら選ぶファイルを減らしてください。

配信されている動画も保存できますか？

いいえ。ページから直接リンクされた動画ファイル（.mp4 や .webm など）は保存します。HLS・DASH の配信、blob: の再生、動画配信サイトの動画は保存しません。

何千ページもあるサイトには、何を使えばよいですか？

パソコン用のサイト巡回ソフトです。Grab All Files はブラウザの中で1ページずつ読みます。ログイン後のページや JavaScript で作られたページを保存できるのはそのためで、何千ページにもなると遅いのも同じ理由です。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
