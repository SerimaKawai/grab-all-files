組み合わせて使う

方式は競争相手ではありません。たとえば、大きな公開サイトはパソコン用の巡回ソフトで、同じサイトのログイン後の部分や、数ページに散らばった PDF は Grab All Files で、という分け方があります。Grab All Files のファイル一覧は、各ファイルの URL つきで CSV に書き出せるので、ほかの道具に渡したいときの材料になります。

よくある質問

Grab All Files はサイト巡回ソフトですか？

一般的な意味では違います。ブラウザーの中で1ページずつ保存し、サイトのフォルダの形をパソコンに書き出すこともできます。限られた数のページに向いています。何千ページもあるサイトは、パソコン用のサイト巡回ソフトのほうが向いています。

ログインが必要なサイトには、どの方式が向きますか？

ブラウザーの中で動く道具です。今のログイン状態をそのまま使えるからです。Grab All Files や、1ページ保存の拡張機能がそうです。パソコン用の巡回ソフトは、追加の設定が要ることが多くあります。

保存したコピーを更新して、変わった分だけ取れますか？

Grab All Files ではできません。同じサイトの前回の収集と比べる Markdown の差分レポートはありますが、ページはもう一度保存します。更新には、パソコン用のサイト巡回ソフトが向いています。

ダウンロード管理ソフトとの違いは何ですか？

ダウンロード管理ソフトは、ファイルのリンクの一覧を受け取って、うまく取ってきます。Grab All Files は、スクリプトで読み込まれるファイルも含めて先に見つけ、一覧で確かめてから保存します。ページを HTML に保存することもできます。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
