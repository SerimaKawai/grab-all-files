拡張機能がやることと、自分でやること

拡張機能が行うのは、ブラウザでページを読み、パソコンの中で変換してファイルに保存するところまでです。AI サービスへのログイン、ファイルのアップロード、代わりの質問はしません。

使いたい AI サービスを自分で開き、ファイルをソースや添付として追加して、質問もそちらで行います。受け付けるファイルの種類や大きさ、アップロードしたファイルの扱いは、サービス側で決まっています。会員限定サイトのページを渡す前に、サービスの最新の上限とプライバシー設定を確かめてください。

流れは5つの手順

  1. 1サイトのトップページか、読ませたい範囲の目次ページを開きます。ログインが要るサイトなら、先に同じブラウザでログインします。
  2. 2Grab All Files を開いて「ページをHTMLにまとめる」に切り替え、どこから集めるかを選びます。ページのリンク・サイトマップ・同じパス配下・貼り付けた URL の一覧が使えます。候補の一覧を見て、読ませたくないページを外します。
  3. 3出力設定で「AI分析用データ（Markdown・出典付き）」を開き、出力する形式を選びます。「主要本文（既定）」は、記事の本文を残してメニューや広告を除きます。
  4. 4収集を実行し、終わったら「AI分析用ZIPを保存」か「1つのMarkdownを保存」を押します。「AIへの依頼文をコピー」を押すと、チャットに貼れる依頼文がコピーされます。
  5. 5NotebookLM・ChatGPT・Claude などを自分で開き、ファイルを追加して依頼文を貼ります。回答を読むときは、元になったページの source_url と captured_at で原文を確かめます。

25MB の設定の意味

既定の25MBは、Markdown の本文をファイルに分ける目安です。ZIP 全体の上限ではなく、サービスがそのサイズのファイルを受け付けるという保証でもありません。フルパッケージは corpus.md・chunks.jsonl・manifest.json・依頼文・閲覧用 HTML を入れた ZIP なので、Markdown だけより大きくなります。

使うサービスが小さいファイルしか受け付けないなら、「ファイルサイズを指定」の目標を下げます。ファイルの数に上限があるなら、目標を上げるか、1つの Markdown にします。適切な目安サイズはサービス側の上限で決まり、その上限は変わることがあります。

よくある質問

Grab All Files はページを NotebookLM・ChatGPT・Claude に送りますか？

送りません。ファイルをパソコンに保存するだけです。AI サービスへは自分でアップロードします。そのあとのファイルの扱いは、サービス側の規約に従います。

1つの Markdown とページ別のファイルは、どちらがよいですか？

小さなサイトを丸ごと質問するなら1つのファイルです。本文がサービスの上限を超えるときや、ページを分けて追加・差し替えたいときは、ページ別にするか、目標サイズを小さくします。

既定の25MBは何の大きさですか？

Markdown の本文を分けるときの目標サイズです。ZIP 全体の上限ではなく、サービスが受け付けることを保証する数字でもありません。

AI の回答が、どのページから来たのかをどう確かめますか？

Markdown の各ページに source_url と captured_at があり、chunks.jsonl と manifest.json にも入っています。そのページを開いて、回答を原文と見比べます。

ログインが必要なページも読ませられますか？

同じブラウザでログインしていれば、集められます。そのログイン状態を使い、パスワードは集めません。出力にはブラウザに表示された内容が入るので、アップロードの前に、そのファイルを誰が見られるかを考えてください。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
