記事の見つけ方は3つ

候補の一覧は、指定したものから作られます。ほかに「このページのリンクをたどる」と「URLを貼り付ける」も選べます。

サイトマップ

サイトがサイトマップを公開していれば、載っている URL がすべて候補になります。候補の件数を見れば、サイトが記事を何本載せているかをすぐ知れます。

同じパス配下

ブログの一覧ページから始め、同じパスの下にあるページを集めます。ブログのフォルダの下だけ、のような指定で、サイトのほかの部分は入りません。

一覧の「次へ」

rel=next や「次へ」「next」「older」などのリンクを見つけます。一覧を1ページずつたどって候補を探します。候補は最大 100,000 件です。

候補の一覧

候補はタイトルとアドレスと一緒に並び、2つの入力欄で絞り込めます。

保存するファイルの形を選ぶ

形できるもの向く場面
目次・検索付きHTML全記事を1つの HTML にまとめ、目次と検索欄を付けたもの画面で読む。数百本の記事から語句を探す。4つの形で最も小さい。
縦につないだHTML（印刷向け）記事を上から順につなぎ、印刷時は記事ごとに改ページするもの印刷や PDF。ブラウザーの印刷で「PDF に保存」を選びます。PDF そのものを Grab All Files が作るわけではありません。
Markdown1つの Markdown か記事ごとの Markdown。各ページに source_url と captured_at が入るノート、個人の資料庫、自分で選んだ AI サービスに渡すテキスト。下の Markdown のガイドを参照。

記事なら、見た目は「読みやすく整える」が合うことが多いです。速く、ファイルも軽くなります。「元の見た目のまま」は記事ごとのレイアウト・フォント・画像を残しますが、時間がかかり、ファイルも大きくなります。

ブログ全体を保存する手順

  1. 1ブログの一覧ページ（新しい記事が並んでいるページ）を開きます。個々の記事ではありません。ログインが要るサイトは先にログインします。
  2. 2Grab All Files を開いて「ページをHTMLにまとめる」に切り替えます。どこから集めるかで、サイトマップ・「同じパス配下」・このページのリンクのどれかを選びます。
  3. 3候補の一覧が出るのを待ちます。絞り込み欄と除外欄で、記事ではないページを外します。タグ・カテゴリ・著者のページや、サイトの紹介ページなどです。
  4. 4Pro なら、記事を選んで読みたい順に並べます。新しい順になるとは限らないので、並びを確かめます。
  5. 5見た目と保存の形を選んで保存します。保存したら、最初と最後の記事、件数、途中にあるはずの語句の検索を確かめます。

向かない場面

Grab All Files はブラウザーを通して記事を開くので、数千本の記事になると時間がかかり、ファイルもとても大きくなります。それほど大きなニュースの蓄積には、サーバーから直接ページを取るパソコン用のサイト巡回ソフトのほうが向きます。ただし、ログインが要るページは見えません。

「次へ」ではなく、スクロールすると記事が増える一覧は別の場面です。始める前にスクロールで増えるページのガイドを読んでください。

よくある質問

ブログの全記事を一度に保存するには？

ブログの一覧ページを開き、サイトマップ・「同じパス配下」・ページのリンクのどれかを選びます。記事ではないページを候補から外し、Pro なら1回で保存します。無料プランは1回1記事で、残りは1つずつ足します。

「次へ」や「古い記事」のリンクもたどりますか？

はい。next・「次へ」・「older」などのリンクを見つけ、たどって候補を探します。Pro なら、続きのページを全部1回で保存することもできます。

全記事の PDF は作れますか？

「縦につないだHTML（印刷向け）」で保存し、ブラウザーで開いて印刷の画面から PDF に保存します。印刷すると、記事ごとに改ページされます。

保存した全記事を横断して検索できますか？

「目次・検索付きHTML」で保存します。1つの HTML に目次と検索欄が付き、ブラウザーでオフラインのまま検索できます。

コメントも保存されますか？

コメント欄は別の作業です。コメントの保存と分析のガイドを見てください。このページは記事そのものを扱います。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
