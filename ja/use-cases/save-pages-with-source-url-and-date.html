2つの見た目と AI 用の出力

目的で選ぶ

読む・印刷するときに、出典を見える位置に置きたい

「元の見た目のまま」の「目次・検索付きHTML」。各タイトルの下に URL と日時が出るので、印刷した紙にも載ります。

1ページ1つの HTML で残したい

「元の見た目のまま」の「ページ別HTML（ZIP）」。各ファイルの先頭のコメントに URL と日付が入り、ページの一覧は index.html にあります。

あとで本文を検索する、または AI サービスに渡す

AI 用 Markdown。各ページに source_url と captured_at が文字で入り、JSONL と manifest の各項目にも入ります。

保存したファイルを自分で確かめる手順

  1. 1まず、使うつもりの見た目と保存の形で、1〜2ページを保存します。
  2. 2ファイルをブラウザーで開きます。目次・検索付きの形なら、ページのタイトルの下に URL と日時があるかを見ます。
  3. 3ZIP と縦につないだ形では、ブラウザーでページのソースを表示して先頭のコメントを読むか、テキストエディターで開きます。
  4. 4Markdown なら、.md を開いて、各ページに source_url と captured_at があるかを見ます。
  5. 5URL や日時がなければ、見た目か保存の形を変えるか、「取得情報と失敗一覧を入れる」を ON にして、保存し直します。

分かることと、分からないこと

保存したページには、読み取ったアドレスと、取得した時刻が残ります。それで元のページを探し直せ、古い取得と新しい取得を見分けられます。同じサイトを時間をおいて取り直して比べるなら、Markdown の変更レポートが、同じサイトの直前の完了した収集と今回を、URL・タイトル・本文で比べます。

パソコンの中のファイルはほかのファイルと同じように編集できるので、URL と日時は、ページに添えたメモであり、封印ではありません。このようなファイルを、裁判所・監査人・サービス事業者がどう扱うかは、このガイドでは述べません。

よくある質問

保存したページに、元の URL は出ますか？

「元の見た目のまま」の「目次・検索付きHTML」なら、各ページのタイトルの下に、取得日時と一緒に出ます。「読みやすく整える」では、ページごとの URL の行はありません。

ページ別HTML（ZIP）では、URL はどこにありますか？

「元の見た目のまま」なら、各 HTML の先頭のコメントに、url と saved date として入っています。ページの上には表示されません。

「読みやすく整える」でも取得日時を残せますか？

「取得情報と失敗一覧を入れる」を ON にします。既定は OFF です。文書の先頭に取得日時が入りますが、ページごとの URL の行は入りません。

URL と日時を、機械が読める形で残せるのはどれですか？

AI 用 Markdown です。各ページに source_url と captured_at があり、chunks.jsonl と manifest.json にも両方入ります。

印刷した紙に、出典は載りますか？

「元の見た目のまま」の「目次・検索付きHTML」なら、各タイトルの下の URL と日時が印刷されます。縦につないだ形では HTML のコメントにしか入らないので、紙には載りません。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
