使い方

  1. 1起点ページを開き、Grab All Files で「ページをHTMLにまとめる」を選びます。
  2. 2関連ページを探し、収集前に不要なページを除外または並べ替えます。
  3. 3画像とリンク先文書の保存方法を選び、目次付きの1つのHTMLを保存します。

よくある質問

収録するページを選べますか？

はい。収集前にページタイトルを確認し、不要なページを除外して、残すページの順番を変更できます。

作成したHTMLはオフラインで読めますか？

はい。画像を埋め込めばオフラインで閲覧できます。HTMLを軽くしたい場合はオンライン参照も選べ、リンク先の文書をHTMLと一緒に保存することもできます。

ページ内容はサーバーへアップロードされますか？

いいえ。ページ収集とHTML生成は端末内で処理します。無料プランは20ページごとに確認し、Proは指定した安全上限まで自動で続行します。

SingleFileのような1ページ保存ツールとの違いは？

1ページ保存ツールは、現在開いているページを保存する用途に向いています。Grab All Files は関連ページを探し、対象と順番を確認して、選択した読みやすい本文を共通の目次付きで1つのHTMLにまとめます。
