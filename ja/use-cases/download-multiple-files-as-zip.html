ページの複数のファイルを、ZIP 1つにまとめてダウンロードする。

ページに PDF や表計算が30件あるとき、1件ずつ保存すると、ダウンロードフォルダにファイルが30個ばらばらに残ります。Grab All Files の「ZIP」ボタンは、選んだファイルを1つの ZIP ファイルにまとめて保存します。サイズの上限があり、分割はしないので、大きな組み合わせを選ぶ前に下の数字を確かめてください。

ZIP ボタンの場所

数字で確かめる

ZIP
無料での1つの ZIP の件数10件まで。1回のダウンロードと同じです。次の10件を選んでもう一度 ZIP を押すと、別の ZIP ファイルができます。
Pro での1つの ZIP の件数件数の上限はありません。下のサイズの上限は同じです。
ZIP の名前サイトのホスト名と今日の日付。例：docs.example.com_2026-11-17.zip（先頭の www. は除きます）。
確認合計が 200MB を超えると、確認が出ます。
上限合計 256MB。
超えたとき複数の ZIP には分割しません。選ぶ件数を減らすか、フォルダに保存します。

手順

  1. 1ページを開き、「ファイル一括ダウンロード」でスキャンします。
  2. 2一覧を絞り込み、欲しいファイルにチェックを入れます。サイズを見て、200MB に近いときは合計を確かめます。
  3. 3「ZIP」を押します。サイズの確認が出たら応じます。
  4. 4ダウンロードフォルダの ZIP を開きます。無料で件数が多いときは、次のファイルを選んでもう一度 ZIP を押します。

ZIP は出力の方法の1つ

同じ選択を、別々のファイルとして保存したり、結合（PDF）したり、ファイルの一覧（CSV）にしたりもできます。処理はすべてブラウザーの中で行います。

「ページ別HTML（ZIP）」とは別の機能です

「ページ別HTML（ZIP）」は、もう一つの道具である「ページをHTMLにまとめる」の保存の形です。保存した Web ページを、1ページ1つの HTML と index.html にして ZIP に入れます。「ファイル一括ダウンロード」の ZIP ボタンは、PDF や Office 文書などをそのままの形でまとめます。2つは別々の機能で、ここに書いた上限は ZIP ボタンの数字です。

よくある質問

ページの複数のファイルを ZIP 1つでダウンロードするには？

「ファイル一括ダウンロード」でページをスキャンし、ファイルにチェックを入れて、「ZIP」を押します。ZIP ファイル 1つになります。

無料では、1つの ZIP に何件入れられますか？

10件です。30件ある報告書なら、10件ずつ3つの ZIP ファイルになります。次の10件を選んで、もう一度 ZIP を押します。

作れる ZIP の最大サイズは？

合計 256MB です。200MB を超えると確認が出ます。複数の ZIP への分割はしません。

ZIP のファイル名はどうなりますか？

サイトのホスト名と日付です。例：docs.example.com_2026-11-17.zip。先頭の www. は付きません。

選んだ分が ZIP には大きすぎます。どうすれば？

1つの ZIP に入れる件数を減らすか、ZIP にせずフォルダに保存してください。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
