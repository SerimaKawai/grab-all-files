✓ログインが要るサイト

ログインが必要なサイトのページと資料を、自分のアカウントで保存する。

対象は、自分が権限のあるアカウントを持っているサイトです。会員サイト、取引先のポータル、受講中の講座などです。Grab All Files は、すでにログインしているブラウザーの中で動くので、自分に見えるものがそのまま見えます。ログインを代わりにすることはなく、アカウントで開けないものは開けません。

前提：自分のアカウントで使う

使ってよいアカウントで、保存してよい資料にだけ使ってください。コピーを残してよいか分からないときは、サイトの利用規約を確かめてください。ログインできることと、保存してよいことは別です。

Grab All Files は、ブラウザーにあるログイン状態をそのまま使います。パスワード、Cookie の値、入力欄に入れた内容は集めず、送りません。ログインの自動化や突破はしません。CAPTCHA が出たら、ページの中で自分で解きます。

手順

  1. 1Grab All Files を入れたブラウザー（Chrome・Edge・Firefox）で、対象のサイトにログインします。そのタブは開いたままにします。
  2. 2資料を保存するとき：資料が並んでいるページを開き、Grab All Files の「ファイル一括ダウンロード」を使います。見つかったファイルが一覧に出るので、種類・サイズ・日付で絞り込み、保存したいものにチェックを入れて保存します。
  3. 3ページそのものを保存するとき：「ページをHTMLにまとめる」に切り替え、ページの探し方（このページのリンク・同じパス配下・サイトマップ・貼り付けた URL）を選び、候補の一覧を確かめて保存します。ブラウザーが表示したとおりに保存するので、ログイン後にだけ見える内容も入ります。
  4. 4ページが PDF や Office 文書にリンクしているときは、ページ収集でページと並べて保存できます。無料は1回10件、Pro は1回100件です。

途中でログインが切れたとき

サイトによっては、しばらく操作しないと、または一定時間でログアウトされます。どちらの道具も止まってそれを知らせ、保存済みの分は残します。

処理が行われる場所

ページとファイルの読み取りはブラウザーの中で行い、パソコンに保存します。開発者のサーバーには送りません。

向いている場面

  • ✓価格表や図面が多くのページに添付された、取引先のポータル。
  • ✓会員向けライブラリーや講座のサイトで、授業のページと配布資料をまとめて残したい。
  • ✓ログインしたあとに JavaScript で描かれるページ。ブラウザーが描いた結果を保存します。

できないこと

  • –アカウントに権限のないページやファイルを開くこと。
  • –ログインの自動化と、CAPTCHA の突破。
  • –暗号化・DRM のビューアーの中や、ブラウザー内蔵の PDF ビューアーの中の内容。
  • –ストリーミング配信の動画。ファイルとしてリンクされた動画・音声だけ保存します。

よくある質問

ログインが必要なサイトからでもダウンロードできますか？

同じブラウザーでそのページを開ければ使えます。今のログイン状態をそのまま使います。ログインを代わりにすることはなく、アカウントで見られないページは開けません。

パスワードを見られたり、保存されたりしませんか？

しません。パスワード、Cookie の値、入力欄の内容は、集めることも送ることもありません。

サインアウトされたというエラーで失敗したファイルがあります。

サイト側でセッションが終わっています。サイトを開いてログインし直し、失敗したファイルを再試行してください。保存済みのファイルは消えません。

ファイルだけでなく、ページも保存できますか？

できます。ファイルは「ファイル一括ダウンロード」、ページは「ページをHTMLにまとめる」です。後者では、リンク先の PDF や Office 文書も一緒に保存できます。

見えるものをすべて保存してよいのですか？

サイトの利用規約と、資料の権利者によります。ログインしていても変わりません。保存してよいものだけを保存してください。

実際のページで Grab All Files を試せます。

無料プランは、ファイル一括ダウンロードでは1回のダウンロードで10件まで、ページのHTML化では1回に選んだ1ページを保存できます。そのページから直接リンクされたファイルは「次のファイル10件を保存」で10件ずつ保存します。Pro（$19.99・買い切り、3台まで）は1回あたりの件数上限がなく、複数ページを1つのHTMLにまとめられます。
