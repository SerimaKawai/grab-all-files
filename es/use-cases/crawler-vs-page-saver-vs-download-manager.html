Where Grab All Files is the right choice

  • ✓You must sign in to see the pages, and you can already open them in your browser.
  • ✓The pages are built by JavaScript and a plain download comes back empty.
  • ✓You want the PDFs and Office files listed first, so you can check them and keep only some.
  • ✓The job is dozens to a few hundred pages, or a long list of files on a few pages.

Where it is the wrong choice

  • –A whole site of thousands of pages, copied in one go.
  • –A copy you refresh every week, fetching only the files that changed.
  • –Video that is streamed rather than linked as a file.
  • –Pages that you cannot open in your own browser.

Why the method matters

Every difference in the table follows from one fact: what the tool asks for, and who does the asking.

Using more than one

The methods are not rivals. A common split: use a desktop website copier for a big public site, and Grab All Files for the signed-in area of the same site, or for the PDFs scattered across a few pages. The file list from Grab All Files can also be exported as CSV, with the URL of every file, if you want to pass it to another tool.

Preguntas frecuentes

Is Grab All Files a website copier?

Not in the usual sense. It saves pages through a browser tab, one at a time, and can write a site's folder layout to your computer. It suits sites of a few dozen to a few hundred pages. For thousands of pages, use a desktop website copier.

Which method works on a site I have to sign in to?

A tool that runs inside your browser, because it uses the sign-in you already have. Grab All Files and one-page saver extensions work this way. Desktop copiers often need extra setup for it.

Can I refresh a saved copy and download only what changed?

Not with Grab All Files. It has a Markdown change report that compares with your last collection of the same site, but it saves the pages again. A desktop website copier is the method built for updating.

How is it different from a download manager?

A download manager takes a list of file links and fetches them well. Grab All Files finds the files first, including ones a page loads by script, shows them in a list to check, and can also save the pages as HTML.
