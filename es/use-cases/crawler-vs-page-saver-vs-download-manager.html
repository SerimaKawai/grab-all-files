Dónde Grab All Files es la elección acertada

  • ✓Tienes que iniciar sesión para ver las páginas y ya puedes abrirlas en tu navegador.
  • ✓Las páginas las construye JavaScript y una descarga simple sale vacía.
  • ✓Quieres que primero se listen los PDF y los archivos de Office, para revisarlos y quedarte solo con algunos.
  • ✓El trabajo es un conjunto limitado de páginas, o una lista larga de archivos en pocas páginas.

Dónde es la elección equivocada

  • –Un sitio entero de miles de páginas, copiado de una vez.
  • –Una copia que actualizas cada semana, obteniendo solo los archivos que cambiaron.
  • –Vídeo que se transmite en streaming en lugar de estar enlazado como archivo.
  • –Páginas que no puedes abrir en tu propio navegador.

Por qué importa el método

Buena parte de la diferencia de la tabla viene de dónde se ejecuta la herramienta y de lo que puede ver desde ahí.

Usar más de uno

Los métodos no son rivales. Un reparto habitual: usar un copiador de sitios de escritorio para un sitio público grande, y Grab All Files para la zona con sesión iniciada del mismo sitio, o para los PDF repartidos por unas pocas páginas. La lista de archivos de Grab All Files también se puede exportar como CSV, con la URL de cada archivo, si quieres pasarla a otra herramienta.

Preguntas frecuentes

¿Grab All Files es un copiador de sitios web?

No en el sentido habitual. Guarda las páginas de una en una dentro de tu navegador y puede escribir en tu ordenador la estructura de carpetas de un sitio. Sirve para un conjunto limitado de páginas. Para miles de páginas, usa un copiador de sitios web de escritorio.

¿Qué método funciona en un sitio en el que tengo que iniciar sesión?

Una herramienta que se ejecute dentro de tu navegador, porque usa el inicio de sesión que ya tienes. Grab All Files y las extensiones que guardan una página funcionan así. Los copiadores de escritorio suelen necesitar configuración extra para esto.

¿Puedo actualizar una copia guardada y descargar solo lo que cambió?

No con Grab All Files. Tiene un informe de cambios en Markdown que compara con tu última recopilación del mismo sitio, pero vuelve a guardar las páginas. Un copiador de sitios web de escritorio es el método pensado para actualizar.

¿En qué se diferencia de un gestor de descargas?

Un gestor de descargas toma una lista de enlaces a archivos y los obtiene bien. Grab All Files primero encuentra los archivos, incluidos los que una página carga por script, los muestra en una lista para revisarlos y además puede guardar las páginas como HTML.
