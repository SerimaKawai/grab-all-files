  1. 1Abre la página inicial y elige «Combinar páginas en HTML» en Grab All Files.
  2. 2Busca páginas relacionadas y elimina o reordena los elementos antes de recopilarlos.
  3. 3Elige las opciones para imágenes y documentos enlazados, y guarda un único archivo HTML con índice.

Preguntas frecuentes

¿Puedo elegir qué páginas incluir?

Sí. Revisa los títulos antes de recopilar las páginas, elimina las que no necesites y reordena las demás.

¿Puedo consultar el resultado sin conexión?

Sí. Incorpora las imágenes para leer sin conexión o conserva las referencias en línea para reducir el tamaño del archivo HTML. Los documentos enlazados también se pueden guardar junto con él.

¿Se sube el contenido de las páginas a sus servidores?

No. Todo se procesa en tu dispositivo. Free mantiene las páginas en una sola recopilación, pide confirmación cada 10 páginas y guarda un HTML final. Pro omite esos controles y continúa hasta el límite de seguridad elegido.

¿En qué se diferencia de una herramienta para guardar una sola página, como SingleFile?

Las herramientas de este tipo conservan la página que está abierta en ese momento. Grab All Files puede encontrar páginas relacionadas, permitirte revisarlas y reordenarlas, y reunir el contenido legible seleccionado en un único archivo HTML con un índice común.
