Flujo de trabajo

  1. 1Abre una página que puedas guardar y usa «Combinar páginas en HTML». Revisa las candidatas y elige las necesarias. Free guarda una página elegida en HTML; Pro combina el contenido de varias.
  2. 2Activa «Datos para análisis con IA (Markdown con fuentes)» antes de recopilar. Elige «Un solo Markdown», «Markdown por página» o «Paquete completo» para lectura, notas separadas o reutilización estructurada.
  3. 3Recopila y revisa el resultado. Compara títulos, enlaces y texto importante con la fuente y comprueba fallos. Guarda también HTML si quieres índice y búsqueda.
  4. 4Usa «Guardar ZIP de análisis IA», extrae el ZIP y abre los Markdown en un editor compatible. Conserva source_url y captured_at y añade tus temas y fecha de consulta.
  5. 5Copia o importa archivos compatibles manualmente a tus notas. Para IA externa, elige archivos y usa «Copiar petición para la IA» con tu pregunta. Verifica las conclusiones con el texto y la fuente actual.

Preguntas frecuentes

¿Se sincroniza con Obsidian o Notion?

Exporta primero y copia o importa manualmente mediante el método compatible del destino. Revisa títulos, tablas y enlaces tras importar. La extensión no sincroniza automáticamente tu almacén o espacio; la compatibilidad de importación varía.

¿Se conservan imágenes y contenido interactivo?

Markdown puede referenciar imágenes con sus URL originales; sus archivos no siempre se incluyen. La extracción no clona todo el sitio. Comprueba imágenes importantes y contenido que requiere interacción en la página original.

¿25 MB limita el paquete completo?

El valor predeterminado de 25 MB es un objetivo para dividir el texto Markdown. No garantiza el tamaño total del ZIP ni su aceptación por otra herramienta. Extrae y selecciona o divide archivos según los límites del destino.

¿Qué pasa con PDF o Word enlazados?

El texto extraído correctamente de documentos seleccionados compatibles puede entrar en la salida para IA. Guarda los originales necesarios aparte y revisa texto ilegible o faltante. No se garantiza la extracción de escaneos; el texto de documentos no se integra en el HTML de lectura.

¿Exportar envía los datos a IA?

No. Los archivos se preparan en tu dispositivo. Tú eliges el servicio y le entregas manualmente archivos compatibles y preguntas. Conserva source_url y captured_at para verificar respuestas; la captura no prueba que la fuente siga actualizada.

¿Puedo usarlo gratis?

Sí. La versión gratuita guarda una página elegida por vez. Las imágenes de esa página no tienen límite por plan, y sus archivos enlazados directamente se guardan de 10 en 10 con «Guardar los siguientes 10» en la pantalla de resultados. Pro ($19.99, pago único, hasta 3 dispositivos) combina varias páginas seleccionadas en un HTML.

¿Y si una página me pide iniciar sesión?

La recopilación usa tu propia sesión del navegador y no recopila credenciales. Si una página aparece como «Inicio de sesión necesario», pulsa «Abrir el sitio para iniciar sesión», inicia sesión en esa pestaña y pulsa «Reanudar». Las páginas que sigan pidiendo sesión no se guardan, y el resultado indica cuántas quedaron fuera.

¿Por qué falta texto en la página guardada?

Algunos sitios añaden texto solo después de desplazarte o hacer clic. Abre «Si falta texto en una página: ajustes de contenido y JavaScript», activa «Pulsar “Mostrar más” para incluir la continuación» y vuelve a recopilar. Si se guardó otra parte de la página, usa ahí «Seleccionar en pantalla» para elegir el texto principal.
