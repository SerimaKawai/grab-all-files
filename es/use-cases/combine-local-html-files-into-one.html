Combinar varios archivos HTML en uno solo.

¿Tienes un sitio web guardado, un manual exportado o un ZIP lleno de páginas .html? Elige la carpeta o el ZIP en tu ordenador y Grab All Files une las páginas en un único archivo HTML con índice. Las páginas siguen el orden de los enlaces del propio sitio, las imágenes locales se incrustan y los enlaces entre páginas saltan dentro del archivo. Todo se ejecuta en tu navegador; no se sube nada.

Pantalla real de la extensión — HTML locales en uno

Ideal para

  • ✓Un sitio web que guardaste o copiaste hace años (index.html y decenas de páginas) y quieres conservar, leer o buscar como un solo archivo.
  • ✓Archivos de ayuda, manuales de producto o documentación exportados como una carpeta de páginas HTML.
  • ✓Compartir un documento HTML de varias páginas como un único adjunto, o imprimirlo a PDF de una vez.
  • ✓Entregar a una herramienta de IA un conjunto completo de documentos locales como un paquete de Markdown o de datos con la fuente de cada página.

Flujo de trabajo

  1. 1Abre Grab All Files, elige «Combinar páginas en HTML» y cambia el origen a «Desde una carpeta del ordenador».
  2. 2Elige la carpeta o un archivo ZIP, o arrástralo a la página. Los archivos .html, .htm y .xhtml se listan en el orden en que el sitio los enlaza desde index.html; las páginas sin enlazar van después, por nombre.
  3. 3Revisa la lista: conserva o quita páginas, cambia a «Orden por nombre de archivo», limita a «Solo esta carpeta» o usa «Excluir (uno por línea)». Elige un fin: «Conservar el sitio», «Compartir como un archivo», «Imprimir o crear un PDF» o «Dárselo a una IA».
  4. 4Crea el HTML. Revisa el informe: archivos que no se pudieron leer, enlaces a páginas que dejaste fuera e imágenes que no se pudieron incrustar.

Carpetas que la gente suele combinar

Una copia de un sitio antiguo

Un sitio guardado con «Guardar página», HTTrack o wget, o copiado de un servidor, con index.html y muchas subpáginas.

Documentación exportada

Salida HTML de herramientas de ayuda, Sphinx, Javadoc o Doxygen, o un archivo de ayuda CHM extraído a HTML.

Manuales y material de cursos

Material de formación, manuales de producto o capítulos de e-learning entregados como una carpeta de páginas.

Páginas internas guardadas sin conexión

Páginas de wiki o intranet exportadas como HTML que quieres conservar como un único documento.

Imprimir o crear un PDF de una vez

Imprime un solo archivo combinado en lugar de abrir e imprimir cada página por separado.

Dar todo el conjunto a una IA

Crea un archivo Markdown o un paquete completo para IA (corpus.md, chunks.jsonl, manifest.json) con las fuentes de las páginas.

Preguntas frecuentes

¿Puedo probarlo gratis?

Sí, con una página: en el modo carpeta, el plan Free convierte un archivo HTML elegido por ejecución en un HTML autónomo con sus imágenes locales incrustadas. Combinar varios archivos HTML en uno con un índice común requiere Pro ($19.99, pago único).

¿Se suben mis archivos a algún sitio?

No. La carpeta o el ZIP se leen en tu navegador y el HTML combinado se crea en tu dispositivo. No hace falta ningún permiso de sitio, y las imágenes en línea a las que hacen referencia las páginas se dejan como enlaces en lugar de descargarse.

¿Las páginas japonesas antiguas saldrán con caracteres ilegibles?

Las páginas sin declaración de charset, o declaradas como UTF-8 pero escritas en realidad en Shift_JIS, EUC-JP o ISO-2022-JP, se detectan automáticamente y se leen bien. Si todas las páginas tienen el mismo <title>, el índice usa el encabezado de cada página.

¿Qué pasa con las imágenes, los PDF y los enlaces entre páginas?

Las imágenes locales PNG, JPEG, GIF, WebP y AVIF se incrustan. Los enlaces entre las páginas combinadas pasan a ser saltos dentro del archivo. Los archivos enlazados, como PDF, Office o ZIP, se pueden «Copiar junto al HTML» (opción por defecto), «Incrustar en el HTML» (20 MiB por archivo y 100 MiB en total por defecto) o «Dejarlos como enlaces».

¿Qué archivos puede leer?

Archivos .html, .htm y .xhtml dentro de una carpeta o un ZIP. Las páginas con «Diseño con marcos» (frameset) se dejan fuera por defecto, pero se incluyen las páginas que hay dentro de los marcos. Los archivos MHT y de ayuda CHM no se leen directamente; extrae primero el CHM a HTML.

¿En qué se diferencia de combinar páginas de un sitio web?

El modo «Página del navegador» reúne páginas relacionadas de un sitio web en línea. El modo carpeta solo trabaja con archivos que ya están en tu ordenador, así que sirve para sitios archivados, manuales sin conexión y documentos que ya no están en línea.
