Renommer et classer les PDF : l’écran de l’extension

Fonctionnement du téléchargement de fichiers

Noms et dossiers ont deux rôles

Reconnaître le document

Utilisez un titre pertinent récupéré ou modifié, ou gardez le nom original. Vérifiez l’extension.

Retrouver l’ensemble

Classez les fichiers mixtes par type ou source, ou gardez un seul dossier si plus pratique.

Idéal pour

  • ✓Mieux reconnaître les PDF d’un manuel ou d’une liste de documents publics.
  • ✓Séparer par format un ensemble mixte de PDF, tableurs et autres fichiers.

Processus

  1. 1Analysez la page qui liste les PDF, filtrez les résultats sur PDF et cochez les fichiers à enregistrer.
  2. 2Vérifiez les titres. Cliquez sur « Récupérer les titres des PDF sélectionnés » pour lire le titre dans le PDF lui-même. Double-cliquez sur un titre, appuyez sur F2 ou utilisez le crayon (« Modifier le titre ») pour le changer ; « Réinitialiser les titres » annule vos modifications.
  3. 3Ouvrez « Détails » et choisissez « Enregistrer sous » : « Automatique (titre si utilisable) », « Titre » ou « Nom de fichier d'origine ». Pour ranger en dossiers, ouvrez « Autres actions » et, dans « Classement », choisissez « Par type », « Par domaine » ou « Sans dossiers ».
  4. 4Cliquez sur « Enregistrer la sélection » ou créez un ZIP (version gratuite : 10 fichiers par téléchargement). Vérifiez noms, extensions et dossiers ; dans Firefox, les fichiers vont dans Downloads/GrabAllFiles.

FAQ

Le vrai titre du PDF est-il toujours trouvé ?

Non. Les métadonnées ou titres de page disponibles peuvent manquer ou être génériques. Vérifiez le titre récupéré ; le mode automatique peut reprendre le nom de fichier d’origine quand aucun titre utile n’est trouvé.

Le classement par type comprend-il le sujet des documents ?

Non. Il classe par type de fichier ou domaine source, pas par sujet déduit. Un lot composé uniquement de PDF reste un seul format.

Puis-je choisir n’importe quel dossier dans tous les navigateurs ?

La destination dépend du navigateur et de ses réglages de téléchargement. Les navigateurs Chromium peuvent proposer un sélecteur de dossier ; Firefox utilise le chemin Downloads/GrabAllFiles. Vérifiez la destination obtenue.

Puis-je renommer un grand ensemble gratuitement ?

Oui. « Enregistrer sous », la modification des titres et « Classement » fonctionnent dans la version gratuite, qui enregistre jusqu’à 10 fichiers sélectionnés par téléchargement. Pour continuer, sélectionnez les fichiers suivants et cliquez à nouveau sur « Enregistrer la sélection ». Pro (19,99 $, achat unique, jusqu’à 3 appareils) supprime la limite par téléchargement.
