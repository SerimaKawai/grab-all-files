Quand Grab All Files est le bon choix

  • ✓Vous devez vous connecter pour voir les pages, et vous pouvez déjà les ouvrir dans votre navigateur.
  • ✓Les pages sont construites par JavaScript et un téléchargement simple revient vide.
  • ✓Vous voulez voir d’abord la liste des PDF et fichiers Office, pour les vérifier et n’en garder que certains.
  • ✓Le travail porte sur un ensemble limité de pages, ou sur une longue liste de fichiers répartis sur quelques pages.

Quand ce n’est pas le bon choix

  • –Un site entier de plusieurs milliers de pages, copié d’un coup.
  • –Une copie actualisée chaque semaine, en ne récupérant que les fichiers modifiés.
  • –Une vidéo diffusée en streaming plutôt que liée comme fichier.
  • –Des pages que vous ne pouvez pas ouvrir dans votre propre navigateur.

Pourquoi la méthode compte

Une grande partie des différences du tableau vient de l’endroit où l’outil s’exécute et de ce qu’il peut voir depuis cet endroit.

Utiliser plusieurs méthodes

Les méthodes ne sont pas rivales. Une répartition courante : un copieur de site pour ordinateur pour un grand site public, et Grab All Files pour la zone connectée du même site, ou pour les PDF dispersés sur quelques pages. La liste de fichiers de Grab All Files peut aussi être exportée en CSV, avec l’URL de chaque fichier, si vous voulez la confier à un autre outil.

FAQ

Grab All Files est-il un copieur de site ?

Pas au sens habituel. Il enregistre les pages une à une dans votre navigateur, et peut écrire l’arborescence de dossiers d’un site sur votre ordinateur. Il convient à un ensemble limité de pages. Pour des milliers de pages, utilisez un copieur de site pour ordinateur.

Quelle méthode fonctionne sur un site où je dois me connecter ?

Un outil qui s’exécute dans votre navigateur, car il utilise la connexion que vous avez déjà. Grab All Files et les extensions d’enregistrement d’une page fonctionnent ainsi. Les copieurs pour ordinateur demandent souvent une configuration supplémentaire.

Puis-je actualiser une copie enregistrée et ne télécharger que ce qui a changé ?

Pas avec Grab All Files. Il propose un rapport de modifications en Markdown qui compare avec votre dernière collecte du même site, mais il enregistre de nouveau les pages. Un copieur de site pour ordinateur est la méthode conçue pour la mise à jour.

En quoi diffère-t-il d’un gestionnaire de téléchargement ?

Un gestionnaire de téléchargement prend une liste de liens de fichiers et les récupère bien. Grab All Files trouve d’abord les fichiers, y compris ceux qu’une page charge par script, les présente dans une liste à vérifier, et peut aussi enregistrer les pages en HTML.
