Processus

  1. 1Ouvrez la page de départ et choisissez « Regrouper les pages en HTML » dans Grab All Files.
  2. 2Trouvez les pages associées, puis retirez ou réorganisez les éléments avant la collecte.
  3. 3Choisissez les options relatives aux images et aux documents liés, puis enregistrez un seul fichier HTML avec table des matières.

FAQ

Puis-je choisir les pages à inclure ?

Oui. Vérifiez les titres avant la collecte, retirez les pages dont vous n’avez pas besoin et réorganisez les autres.

Puis-je consulter le résultat hors ligne ?

Oui. Intégrez les images pour une consultation hors ligne, ou conservez les références en ligne afin d’alléger le fichier HTML. Les documents liés peuvent également être enregistrés avec celui-ci.

Le contenu des pages est-il envoyé à vos serveurs ?

Non. Tout est traité sur votre appareil. Free conserve les pages dans une seule collecte, demande confirmation toutes les 10 pages et enregistre un HTML final. Pro omet ces confirmations et poursuit jusqu’à la limite de sécurité choisie.

Quelle est la différence avec un outil d’enregistrement d’une seule page tel que SingleFile ?

Les outils de ce type conservent la page actuellement ouverte. Grab All Files peut trouver les pages associées, vous permettre de les vérifier et de les réorganiser, puis regrouper le contenu lisible sélectionné dans un seul fichier HTML avec une table des matières commune.
