Privacy Policy

Last updated: August 30, 2026

Grab All Files ("the Extension") is a browser extension that helps users find, inspect, download, and optionally merge files from web pages they choose. This policy explains what data the Extension handles, how it is used, where it is stored, and when it is transmitted.

1. Summary of Data Handling

The Extension does not sell personal data, run third-party analytics, inject ads, use tracking scripts, or send error/crash reports to any telemetry provider in the published build. It does handle a limited amount of browsing-related data locally in your browser in order to provide its user-facing features.

This includes, for example:

  • the current tab or URL you ask the Extension to scan,
  • recent scan history stored locally for quick access, and
  • network file records (URLs and metadata of files detected via network monitoring) stored temporarily in session storage during your browsing session.

We do not send your scan history, page HTML, file contents, or browsing activity to our servers. Optional pseudonymous usage statistics are off by default and are sent only after you explicitly enable them in the Extension.

Free plan and paid license: Free is available without an expiry. It bulk-saves up to 20 files per run and lets you choose exactly one related candidate page to save as HTML. Images and directly linked files on that page have no plan-based count cap; ordinary page links remain clickable, but their linked page bodies are not collected. A one-time Pro license removes the file cap and combines multiple selected page bodies into one HTML. Safety, authentication, permission, source-site, and device-protection limits still apply. There is no subscription.

Access to websites: The manifest declares https://*/* and http://*/* as optional site access. The Extension does not receive all-site access at installation. It requests only the origin selected by the user, following a user action and an explanation of why access is needed. Additional origins are not granted automatically. Access is used only to detect downloadable links and file responses, download selected files, and fetch user-reviewed HTML pages and allowed images for the Web Page Collector. As a limited exception, while scanning a page the extension may send an anonymous metadata request — with no cookies, no credentials, and no referrer — to a small fixed list of well-known public cloud file-storage hosts (such as Amazon S3, Google Cloud Storage, Azure Blob Storage, and Cloudflare R2) when a scanned file link points to one, solely to read that file's size and type so it can be shown in the results. These requests never carry your browser login session, are skipped entirely in session-safe scanning mode, and are only sent to that fixed provider list — never to arbitrary sites.

2. Network Requests

The Extension makes network requests only for the following purposes:

  • License verification — When a license key is entered or revalidated, the Extension sends the license key and a randomly generated device identifier (UUID) to our server to verify the license and enforce device limits.
  • License token (JWT) issuance and refresh — After a successful verification, our server returns a short-lived signed access token (ES256 JWT, 7-day TTL) that contains the license key, device identifier, granted features, and expiry. The Extension caches this token locally so most subsequent license checks happen offline. The token is refreshed by sending the same license key and device identifier to our server, typically once a day.
  • Revocation list refresh — Once a day, the Extension downloads a small signed list of revoked token identifiers (no license keys) so revocations take effect within 24 hours, even offline. This request sends no user-identifying data.
  • Device management — When you view or remove activated devices on the license screen, the Extension sends the license key, your current device identifier, and, if you remove a device, the target device identifier to our server.
  • User-requested page and file access — When you scan a page, collect selected web-page content, enter a URL, fetch file metadata, download files, or merge PDFs, the Extension connects directly to the target website you selected. These requests do not pass through our servers. Web Page Collector HTML, titles, URLs, images, profiles, and generated documents are not included in license or usage-event requests.
  • Optional usage events — Only after you explicitly opt in, the Extension sends the 18 pseudonymous interaction events listed in Section 5a to our Supabase backend. It does not send an installation event before consent.
  • Optional uninstall survey — While usage statistics remain enabled, uninstalling may open our survey page with the Extension version, UI language, number of days installed, and free/paid plan in its query string. Disabling usage statistics clears the uninstall URL and stops this navigation and metadata transfer.

Abuse prevention: The public license-verification and plan-event endpoints derive a pseudonymous rate-limit bucket from the connecting IP using a secret-keyed HMAC-SHA-256. The raw IP address is not stored by the application. The bucket is used only to enforce request limits, expires 24 hours after the last request, and is then deleted incrementally.

Requests to target websites may include cookies or other session credentials already associated with that website in your browser session if they are required for the content you asked the Extension to access. The Extension does not separately collect, copy, or sell that information.

The Extension uses browsing-related data and website content only to provide its user-facing features: scanning the current page, scanning a URL you enter, showing recent scans, checking file metadata, downloading selected files, and merging PDFs locally.

  • We do not sell this data.
  • We do not use this data for advertising, profiling, or analytics.
  • We do not transfer this data to data brokers, information resellers, or advertising platforms.
  • We do not send scan history, page HTML, or file contents to our servers.

Our use of this data is limited to the Extension's single purpose and the user-facing features described in the Chrome Web Store™ listing and in the Extension UI.

5a. Telemetry, Analytics, and Error Reporting

The published store build contains no third-party analytics — no Google Analytics, Mixpanel, Amplitude, Segment, or similar SDK — and does not send error reports, crash reports, or performance metrics. Our own optional usage statistics are off by default on every browser. No usage event, including install, is sent before you explicitly enable the setting.

If enabled, exactly these 18 event types may be sent: install, popup_first_open, picker_shown, picker_done, scan_start, scan_done, dl_click, dl_done, results_first_action, paywall_shown, download_cap_hit, upgrade_click, continue_free_click, license_view, buy_click, license_activate, collector_job_start, and collector_job_done.

Every event contains a random installation UUID, Extension version, free/paid plan, event name, and only the event-specific coarse fields needed for aggregate analysis: first-open timing; picker selection/skip counts; scan depth, detected/displayed/selected/drop counts, duration and closed error labels; attempted/success/failure download counts; the closed label and elapsed time for the first results action; plan/upgrade feature labels; license-screen source and activation outcome; or Collector page/success/failure counts, duration and terminal state. This stable UUID is pseudonymous data, not anonymous data. Events never include page contents, browsing or Collector URLs, page titles, file names, profile names, selectors, free-text errors, license keys, e-mail addresses, or collected documents. They are used only to improve the product, are not sold or used for advertising/profiling, and receive a 90-day expiry; expired records are deleted incrementally. Turning the setting off stops future events and disables the uninstall survey; previously stored events remain until their 90-day expiry or an applicable deletion request is completed.

An optional error-reporting hook (Sentry) is present in the source tree for internal debugging builds, but it is gated by a build-time secret and is never enabled in the build distributed through the Chrome Web Store™ and Microsoft Edge™ Add-ons. If a future release ever enables it, this Privacy Policy will be updated before that release ships, and any data sent will be filtered to redact license keys, e-mail addresses, JWTs, bearer tokens, UUIDs, query string values, file system paths, and URL path bodies.

プライバシーポリシー

最終更新日: 2026年8月30日

ファイル一括ダウンロード（英文表記: Grab All Files）（以下「本拡張機能」）は、ユーザーが選択したWebページからファイルを検索・確認・ダウンロードし、必要に応じてPDFをローカル結合できるブラウザ拡張機能です。本ポリシーでは、本拡張機能が取り扱うデータ、その利用目的、保存先、送信される場面について説明します。

1. データ取り扱いの概要

公開ストア配布版は第三者分析、エラー・クラッシュ・性能報告を送信しません。任意の仮名化利用統計は初期設定でオフであり、ユーザーが拡張機能内で明示的に有効化した後だけ送信します。ページ内容、URL、ファイル名、閲覧履歴は送信しません。

たとえば、以下のようなデータを扱います：

  • スキャン対象としてユーザーが選択した現在のタブまたは入力したURL
  • クイックアクセスのために端末内へ保存される最近のスキャン履歴
  • ネットワークファイル記録（ネットワーク監視で検出されたファイルのURLとメタデータ）のセッション中の一時保存

スキャン履歴、ページHTML、ファイル内容、閲覧行動を当社サーバーへ送信することはありません。

無料プランと有料ライセンス： 無料プランは期限なく利用でき、ファイルを1回20件まで保存し、関連候補から常に1ページだけ選んでHTML保存できます。そのページ内の画像・直接リンクされたファイルにはプラン上の件数制限がありません。通常ページリンクはクリック可能に残りますが、リンク先本文は収集しません。買い切りのProライセンスではファイル上限を解除し、複数ページ本文を1つのHTMLに結合できます。安全上限・認証・権限・サイト側・端末保護上の制限は適用されます。サブスクリプションはありません。

Webサイトへのアクセス：マニフェストでは https://*/* と http://*/* を任意のサイトアクセスとして宣言しています。インストール時に全サイト権限は取得せず、理由を表示したうえで、ユーザー操作により選択されたオリジンだけを要求します。外部オリジンは自動追加しません。この権限は、ダウンロード可能なリンクやファイル応答の検出、選択ファイルの保存、確認済みHTMLページと許可画像の取得にだけ使用します。限定的な例外として、スキャンしたファイルへのリンクが著名な公開クラウドファイルストレージ（Amazon S3、Google Cloud Storage、Azure Blob Storage、Cloudflare R2 など）上のファイルを指している場合、本拡張機能は、ページのスキャン中に、そのファイルのサイズと種別を読み取って検出結果に表示することだけを目的として、Cookie・認証情報・リファラーを一切含まない匿名のメタデータリクエストを、これら決められた提供元の小さな固定リストに対してのみ送信することがあります。これらのリクエストにブラウザのログインセッションが含まれることはなく、session-safe スキャンモードでは一切送信されず、送信先は上記の固定された提供元リストに限られ、任意のサイトへ送信することはありません。

2. ネットワークリクエスト

本拡張機能が行うネットワークリクエストは、次の目的に限られます：

  • ライセンス認証 — ライセンスキーの入力時または再検証時に、ライセンスキーとランダム生成されたデバイス識別子（UUID）を当社サーバーへ送信し、ライセンスの有効性とデバイス数制限を確認します。

  • 失効リストの更新 — 1日1回、失効済みトークンID（ライセンスキーは含みません）の小さな署名付きリストをダウンロードし、オフラインでも24時間以内に失効を反映できるようにします。このリクエストにはユーザー識別情報を一切送信しません。
  • デバイス管理 — ライセンス画面で有効化済みデバイスを表示または削除する際に、ライセンスキー、現在のデバイス識別子、および削除時には対象デバイス識別子を当社サーバーへ送信します。

2. Netzwerkanfragen

Die Erweiterung führt Netzwerkanfragen ausschließlich zu folgenden Zwecken aus:

  • Ausstellung und Erneuerung des Lizenz-Tokens (JWT) — Nach erfolgreicher Verifizierung gibt unser Server einen kurzlebigen signierten Zugriffstoken zurück (ES256 JWT, Gültigkeit 7 Tage), der den Lizenzschlüssel, den Geräte-Identifikator, die gewährten Funktionen und das Ablaufdatum enthält. Die Erweiterung speichert diesen Token lokal zwischen, sodass die meisten nachfolgenden Lizenzprüfungen offline erfolgen. Der Token wird üblicherweise einmal pro Tag erneuert, indem derselbe Lizenzschlüssel und Geräte-Identifikator an unseren Server gesendet wird.
  • Aktualisierung der Widerrufsliste — Einmal pro Tag lädt die Erweiterung eine kleine, signierte Liste widerrufener Token-Identifikatoren herunter (keine Lizenzschlüssel), damit Widerrufe auch offline innerhalb von 24 Stunden wirksam werden. Diese Anfrage übermittelt keine den Nutzer identifizierenden Daten.
  • Geräteverwaltung — Wenn Sie auf dem Lizenzbildschirm aktivierte Geräte einsehen oder entfernen, sendet die Erweiterung den Lizenzschlüssel, Ihren aktuellen Geräte-Identifikator und, falls Sie ein Gerät entfernen, den Geräte-Identifikator des Zielgeräts an unseren Server.

2. Solicitudes de Red

La Extensión realiza solicitudes de red únicamente para los siguientes fines:

  • Verificación de la licencia — Cuando se introduce o se vuelve a validar una clave de licencia, la Extensión envía la clave y un identificador de dispositivo (UUID) generado aleatoriamente a nuestro servidor para verificar la licencia y aplicar los límites de dispositivos.
  • Emisión y renovación del token de licencia (JWT) — Tras una verificación correcta, nuestro servidor devuelve un token de acceso firmado y de corta duración (ES256 JWT, TTL de 7 días) que contiene la clave de licencia, el identificador del dispositivo, las funcionalidades concedidas y la fecha de expiración. La Extensión guarda este token en caché localmente, de modo que la mayoría de las comprobaciones posteriores se realicen sin conexión. El token se renueva enviando la misma clave de licencia y el mismo identificador de dispositivo a nuestro servidor, normalmente una vez al día.
  • Actualización de la lista de revocaciones — Una vez al día, la Extensión descarga una pequeña lista firmada de identificadores de tokens revocados (sin claves de licencia) para que las revocaciones surtan efecto en un plazo de 24 horas, incluso sin conexión. Esta solicitud no envía datos identificativos del usuario.
  • Gestión de dispositivos — Cuando consulta o elimina dispositivos activados desde la pantalla de licencia, la Extensión envía a nuestro servidor la clave de licencia, el identificador de su dispositivo actual y, si elimina un dispositivo, el identificador del dispositivo de destino.
  • Acceso a páginas y archivos solicitado por el usuario — Cuando usted escanea una página, recopila contenido seleccionado de páginas web, introduce una URL, obtiene metadatos de archivos, descarga archivos o combina PDF, la Extensión se conecta directamente al sitio web de destino que usted haya seleccionado. Estas solicitudes no pasan por nuestros servidores. El HTML, los títulos, las URL, las imágenes, los perfiles y los documentos generados por el Web Page Collector no se incluyen en solicitudes de licencia ni de eventos de uso.
  • Estadísticas de uso opcionales — Solo después de que usted dé su consentimiento explícito, la Extensión envía a nuestro backend de Supabase los 18 eventos de uso seudónimos indicados en la Sección 5a. No se envía ningún evento install antes del consentimiento.

Prevención de abuso: Los endpoints públicos de verificación de licencia y eventos del plan convierten la IP de conexión en un bucket seudónimo de límite de solicitudes mediante HMAC-SHA-256 con clave secreta. La aplicación no almacena la IP original. El bucket se usa únicamente para aplicar límites y se elimina de forma incremental 24 horas después de la última solicitud.

Las solicitudes a los sitios web de destino pueden incluir cookies u otras credenciales de sesión ya asociadas a dicho sitio en su sesión de navegación, si resultan necesarias para acceder al contenido que solicitó a la Extensión.   • les enregistrements de fichiers réseau (URL et métadonnées des fichiers détectés via la surveillance du réseau) stockés temporairement dans le stockage de session pendant votre session de navigation.

Ultimo aggiornamento: 30 agosto 2026

Grab All Files (l'«Estensione») è un'estensione per browser che aiuta gli utenti a trovare, ispezionare, scaricare e, facoltativamente, unire file dalle pagine web da loro scelte. La presente informativa illustra quali dati l'Estensione tratta, come vengono utilizzati, dove sono archiviati e quando vengono trasmessi.

1. Sintesi del Trattamento dei Dati

L'Estensione non vende dati personali, non utilizza strumenti di analisi di terze parti, non inserisce annunci pubblicitari, non utilizza script di tracciamento e non invia segnalazioni di errore o di crash ad alcun fornitore di telemetria nella build pubblicata. Tratta tuttavia, in modo limitato, alcuni dati relativi alla navigazione localmente nel browser dell'utente, al fine di fornire le funzionalità rivolte all'utente.

Ciò comprende, ad esempio:

  • la scheda corrente o l'URL di cui Lei chiede la scansione all'Estensione,
  • la cronologia recente delle scansioni archiviata localmente per un accesso rapido, e
  • i record dei file di rete (URL e metadati dei file rilevati tramite il monitoraggio della rete) archiviati temporaneamente nello storage di sessione durante la sessione di navigazione.

Non inviamo ai nostri server la cronologia delle scansioni, l'HTML delle pagine, il contenuto dei file o l'attività di navigazione.

Piano gratuito e licenza a pagamento: Free non scade, salva fino a 20 file per esecuzione ed esattamente una pagina candidata scelta come HTML. Immagini e file collegati direttamente non hanno un limite numerico del piano; i normali link di pagina restano cliccabili, ma il contenuto delle destinazioni non viene raccolto. Pro rimuove il limite e unisce il contenuto di più pagine selezionate. Restano validi i limiti di sicurezza, autenticazione, autorizzazione, sito sorgente e protezione del dispositivo. Non ci sono abbonamenti.

Accesso ai siti web: Il manifest dichiara https://*/* e http://*/* solo come autorizzazioni facoltative. All'installazione non viene concesso l'accesso a tutti i siti. Dopo una spiegazione, l'Estensione richiede con un'azione dell'utente solo l'origine selezionata e non aggiunge automaticamente altre origini. Come eccezione limitata, durante la scansione di una pagina l'Estensione può inviare una richiesta di metadati anonima — senza cookie, senza credenziali e senza referrer — a un piccolo elenco fisso di noti host pubblici di archiviazione file su cloud (come Amazon S3, Google Cloud Storage, Azure Blob Storage e Cloudflare R2) quando il link di un file scansionato punta a uno di essi, al solo scopo di leggere la dimensione e il tipo di quel file per mostrarli nei risultati. Queste richieste non trasmettono mai la sessione di accesso del browser, vengono completamente saltate nella modalità di scansione session-safe e vengono inviate solo a quell'elenco fisso di provider, mai a siti arbitrari.

2. Richieste di Rete

L'Estensione effettua richieste di rete unicamente per le seguenti finalità:

  • Verifica della licenza — Quando viene inserita o riconvalidata una chiave di licenza, l'Estensione invia al nostro server la chiave di licenza e un identificativo del dispositivo (UUID) generato casualmente, al fine di verificare la licenza e applicare i limiti di dispositivo.
  • Emissione e rinnovo del token di licenza (JWT) — A seguito di una verifica andata a buon fine, il nostro server restituisce un token di accesso firmato e di breve durata (ES256 JWT, TTL di 7 giorni) contenente la chiave di licenza, l'identificativo del dispositivo, le funzionalità concesse e la scadenza. L'Estensione memorizza tale token localmente nella cache, in modo che la maggior parte dei successivi controlli di licenza avvenga offline. Il token viene rinnovato inviando al nostro server la stessa chiave di licenza e lo stesso identificativo del dispositivo, di norma una volta al giorno.
  • Aggiornamento dell'elenco delle revoche — Una volta al giorno l'Estensione scarica un piccolo elenco firmato di identificativi di token revocati (senza chiavi di licenza) affinché le revoche abbiano effetto entro 24 ore, anche offline. Tale richiesta non invia alcun dato identificativo dell'utente.
  • Gestione dei dispositivi — Quando Lei visualizza o rimuove i dispositivi attivati dalla schermata della licenza, l'Estensione invia al nostro server la chiave di licenza, l'identificativo del Suo dispositivo attuale e, in caso di rimozione di un dispositivo, l'identificativo del dispositivo di destinazione.
  • Accesso a pagine e file richiesto dall'utente — Quando Lei effettua la scansione di una pagina, raccoglie contenuti selezionati delle pagine web, inserisce un URL, recupera metadati di file, scarica file o unisce PDF, l'Estensione si collega direttamente al sito web di destinazione da Lei selezionato. Tali richieste non transitano dai nostri server. HTML, titoli, URL, immagini, profili e documenti generati del Web Page Collector non sono inclusi nelle richieste di licenza o negli eventi di utilizzo.
  • Statistiche d'uso facoltative — Solo dopo il Suo consenso esplicito, l'Estensione invia al nostro backend Supabase i 18 eventi d'uso pseudonimi elencati nella Sezione 5a. Prima del consenso non viene inviato alcun evento install.

Prevenzione degli abusi: Gli endpoint pubblici di verifica licenza ed eventi del piano trasformano l'IP di connessione in un bucket pseudonimo mediante HMAC-SHA-256 con chiave segreta. L'applicazione non memorizza l'IP originale. Il bucket è usato solo per applicare i limiti e viene eliminato progressivamente 24 ore dopo l'ultima richiesta.

Política de Privacidade

Última atualização: 30 de agosto de 2026

Grab All Files ("a Extensão") é uma extensão de navegador que ajuda os usuários a localizar, inspecionar, baixar e, opcionalmente, mesclar arquivos a partir de páginas da web por eles escolhidas. Esta política explica quais dados a Extensão manipula, como eles são usados, onde são armazenados e quando são transmitidos.

1. Resumo do Tratamento de Dados

A Extensão não vende dados pessoais, não executa análises de terceiros, não insere anúncios, não usa scripts de rastreamento e não envia relatórios de erro/falha a qualquer provedor de telemetria na versão publicada. Ela trata, sim, uma quantidade limitada de dados relacionados à navegação localmente em seu navegador para oferecer suas funcionalidades voltadas ao usuário.

Isso inclui, por exemplo:

  • a aba ou URL atual que você solicita que a Extensão escaneie,
  • o histórico recente de varreduras armazenado localmente para acesso rápido, e
  • registros de arquivos de rede (URLs e metadados de arquivos detectados via monitoramento de rede) armazenados temporariamente no armazenamento de sessão durante sua sessão de navegação.

Não enviamos seu histórico de varreduras, o HTML das páginas, o conteúdo dos arquivos ou sua atividade de navegação aos nossos servidores.

Plano gratuito e licença paga: O Free não expira, salva até 20 arquivos por execução e exatamente uma página candidata escolhida como HTML. Imagens e arquivos diretamente vinculados não têm limite de quantidade do plano; links de página continuam clicáveis, mas o conteúdo de seus destinos não é coletado. O Pro remove o limite e reúne o conteúdo de várias páginas selecionadas. Continuam válidos os limites de segurança, autenticação, permissão, site de origem e proteção do dispositivo. Não há assinatura.

Acesso a sites: O manifesto declara https://*/* e http://*/* somente como permissões opcionais. O acesso a todos os sites não é concedido na instalação. Após explicar o motivo, a Extensão solicita por ação do usuário somente a origem selecionada e não adiciona origens externas automaticamente. Como exceção limitada, enquanto varre uma página a Extensão pode enviar uma solicitação de metadados anônima — sem cookies, sem credenciais e sem referenciador — a uma pequena lista fixa de conhecidos hosts públicos de armazenamento de arquivos em nuvem (como Amazon S3, Google Cloud Storage, Azure Blob Storage e Cloudflare R2) quando o link de um arquivo verificado aponta para um deles, com o único fim de ler o tamanho e o tipo desse arquivo para exibi-los nos resultados. Essas solicitações nunca transportam a sessão de login do seu navegador, são totalmente ignoradas no modo de varredura session-safe e são enviadas somente a essa lista fixa de provedores, nunca a sites arbitrários.

2. Solicitações de Rede

A Extensão realiza solicitações de rede apenas para os seguintes fins:

  • Verificação de licença — Quando uma chave de licença é inserida ou revalidada, a Extensão envia a chave de licença e um identificador de dispositivo gerado aleatoriamente (UUID) ao nosso servidor para verificar a licença e aplicar os limites de dispositivos.
  • Emissão e renovação de token de licença (JWT) — Após uma verificação bem-sucedida, nosso servidor retorna um token de acesso assinado e de curta duração (ES256 JWT, TTL de 7 dias) que contém a chave de licença, o identificador do dispositivo, os recursos concedidos e a data de expiração. A Extensão armazena esse token localmente em cache, de forma que a maioria das verificações de licença subsequentes ocorra offline. O token é renovado pelo envio da mesma chave de licença e do identificador de dispositivo ao nosso servidor, geralmente uma vez por dia.
  • Atualização da lista de revogações — Uma vez por dia, a Extensão baixa uma pequena lista assinada de identificadores de tokens revogados (sem chaves de licença) para que as revogações entrem em vigor em até 24 horas, mesmo offline. Essa solicitação não envia nenhum dado de identificação do usuário.
  • Gerenciamento de dispositivos — Ao visualizar ou remover dispositivos ativados na tela de licença, a Extensão envia ao nosso servidor a chave de licença, o identificador do seu dispositivo atual e, se você remover um dispositivo, o identificador do dispositivo de destino.
  • Acesso a páginas e arquivos solicitado pelo usuário — Ao escanear uma página, coletar conteúdo selecionado de páginas web, inserir uma URL, obter metadados de arquivo, baixar arquivos ou mesclar PDFs, a Extensão se conecta diretamente ao site de destino selecionado por você. Essas solicitações não passam pelos nossos servidores. HTML, títulos, URLs, imagens, perfis e documentos gerados pelo Web Page Collector não são incluídos em solicitações de licença ou eventos de uso.
  • Estatísticas de uso opcionais — Somente após seu consentimento explícito, a Extensão envia ao nosso backend do Supabase os 18 eventos de uso pseudonimizados listados na Seção 5a. Nenhum evento install é enviado antes do consentimento.

Prevenção de abuso: Os endpoints públicos de verificação de licença e eventos do plano transformam o IP de conexão em um bucket pseudônimo de limite usando HMAC-SHA-256 com chave secreta. A aplicação não armazena o IP bruto. O bucket é usado somente para impor limites e é excluído gradualmente 24 horas após a última solicitação.

As solicitações aos sites de destino podem incluir cookies ou outras credenciais de sessão já associadas a esse site na sua sessão de navegador, caso sejam necessárias para o conteúdo que você pediu para a Extensão acessar. A Extensão não coleta, copia ou vende essas informações separadamente.
