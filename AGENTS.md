# Notes for agents (Claude, Codex, humans)

This file is excluded from the published site (`_config.yml` → `exclude`).

## Homepage: edit `_src/index.html`, never `/index.html`

- `_src/index.html` is the homepage source (all ten languages inline; `_src/` is not published).
- `/index.html` (English only) and every `/<locale>/index.html` are GENERATED by `node build-locales.mjs`.
- `/index.html` carries a `generated from _src/index.html … sha256:` stamp. If someone edits it by hand,
  the build stops instead of overwriting the edit. Move the edit into `_src/index.html`, then
  `git checkout -- index.html && node build-locales.mjs`.
- After any edit to `_src/index.html`, `security.html` or `use-cases/`: run `node build-locales.mjs`,
  then `node check-homepage-seo.mjs` and `node check-seo-integrity.mjs`, and commit the generated files too.

## Publishing

- GitHub Pages publishes every committed file that is not excluded. Keep internal docs out of the repo,
  or add them to `exclude` in `_config.yml`.
