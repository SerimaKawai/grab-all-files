Security, privacy, and permissions for Grab All Files

Grab All Files scans only the page or URL you choose — including pages you can open with your current login — and asks for site access one site at a time. File discovery, downloads, ZIP creation, CSV export, PDF merging and the Web Page Collector all run locally in your browser.

What is sent to our servers

License verification data and optional pseudonymous usage statistics are sent to the developer's backend. Usage statistics are disabled by default and sent only after explicit consent.

Site access is requested one site at a time

Installing Grab All Files does not give it access to every website. The only host permission granted at install is our license server; the all-sites patterns (https://*/*, http://*/*) are declared as optional. When you scan a page or save files from a site, your browser asks you to allow that one site. You can review or revoke access at any time: in Chrome or Edge, open Extensions → Grab All Files → Details → Site access; in Firefox, open Add-ons → Grab All Files → Permissions.

The one request that does not go to a site you chose

To show a file’s size and type, the extension may send an anonymous request (no cookies, no credentials, no referrer) to a small fixed list of well-known public file-storage hosts (such as Amazon S3, Google Cloud Storage, Azure Blob Storage and Cloudflare R2) when a scanned link points to one. These requests never carry your login session, are skipped entirely in session-safe scanning mode, and never go to arbitrary sites.
